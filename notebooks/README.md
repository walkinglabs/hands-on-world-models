# Notebook 学习路径

Notebook 不按知识点拆成几十个文件。一名学生选择一条路线后，完整路径约为 10 份：

```text
第 1–3 章的共同基础
→ 3.6 动手：重新发明一台可学习世界模型
→ 所选路线的两份教学 Notebook
→ 该路线最后一份动手
→ 第 9 章的系统评测
→ 9.4 动手：设计下一台世界模型
```
