# Notebook 学习路径

Notebook 不按知识点拆成几十个文件。一名学生选择一条路线后，完整路径约为 10 份：

```text
F0–F3 共同基础
→ PA0
→ 所选路线的两份教学 Notebook
→ PA1
→ Z0
→ PA2
```
