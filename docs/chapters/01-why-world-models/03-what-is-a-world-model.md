# 1.3　什么是世界模型：定义与判据

## 1. 观察与动作的联合分布

前面四节分别处理了状态、动作条件、多步推演与动力学学习。现在把它们放在同一张纸上：一段经历里出现的所有观察与动作，构成一个联合分布。行为克隆、视频生成、逆动力学、可控预测这些听起来毫不相干的任务，其实都是对这同一个分布提出的不同提问。搞清楚谁是条件、谁是待预测量，就能一眼看穿一篇新论文究竟在建模什么。

---

###同一份数据，四支队伍

一台桌面机械臂完成了一次抓取，采集系统记录下这样一段经历：

```text
o_0 ──a_0──> o_1 ──a_1──> o_2 ──a_2──> o_3
```

四支队伍拿到完全相同的这批数据，各自训练了一个模型：

| 队伍 | 模型输入         | 模型输出  | 通行叫法                     |
| ---- | ---------------- | --------- | ---------------------------- |
| A    | $o_{\le t}$      | $a_t$     | 行为克隆 / 策略              |
| B    | $o_{\le t}$      | $o_{t+1}$ | 被动视频生成                 |
| C    | $o_{\le t}, a_t$ | $o_{t+1}$ | 动作条件世界模型             |
| D    | $o_t, o_{t+1}$   | $a_t$     | 逆动力学（inverse dynamics） |

四个模型的网络结构可以完全一样，训练数据一模一样，差别只在于**哪些变量放在条件一侧**。这不是命名习惯的差异，而是数学对象的差异，下面会看到它带来的后果有多严重。

---

###一次经历的联合分布

把一段长度为 $T$ 的经历记作轨迹 $\tau = (o_0, a_0, o_1, a_1, \dots, a_{T-1}, o_T)$。采集这批数据的过程，等价于从一个联合分布中采样：

$$P(\tau) = P(o_0, a_0, o_1, \dots, o_T).$$

按时间顺序反复使用链式法则，这个联合分布可以精确地拆成两串因子交替相乘：

$$P(\tau) = \underbrace{P(o_0)}_{\text{初始分布}} \prod_{t=0}^{T-1} \underbrace{\pi_\beta(a_t \mid o_{\le t})}_{\text{采集策略}} \cdot \underbrace{P(o_{t+1} \mid o_{\le t}, a_t)}_{\text{环境动力学}}.$$

这个分解式是本节的全部内容。它告诉我们，数据里其实**混着两种截然不同的规律**：

- $P(o_{t+1} \mid o_{\le t}, a_t)$ 是**环境的性质**。它由物理规律决定，不管谁来操作机械臂，它都不变。
- $\pi_\beta(a_t \mid o_{\le t})$ 是**采集者的性质**。换一个操作员、换一个策略，它立刻就变。

上表里的四支队伍，A 队在学 $\pi_\beta$，C 队在学 $P(o_{t+1} \mid o_{\le t}, a_t)$。这两个量分别属于两种不同的东西，混淆它们会付出实际代价。

---

###被动视频生成为什么会把策略吃进去

B 队最值得细看。它的目标 $P(o_{t+1} \mid o_{\le t})$ 里没有出现动作，但动作并没有消失，而是被求和（边缘化）掉了：

$$P(o_{t+1} \mid o_{\le t}) = \sum_{a} \pi_\beta(a \mid o_{\le t}) \cdot P(o_{t+1} \mid o_{\le t}, a).$$

等号右边同时含有 $\pi_\beta$ 和环境动力学。也就是说，**被动视频模型学到的是「环境动力学与采集策略的乘积」**，而不是环境本身。

用具体数字看后果。设某个状态下只有两个动作：左转与右转。环境是确定性的，左转必然使横向坐标减 $1$，右转必然加 $1$。采集数据的司机有强烈的左转偏好：

$$\pi_\beta(\text{左}) = 0.9, \qquad \pi_\beta(\text{右}) = 0.1.$$

于是三个模型分别学到：

$$
\begin{aligned}
\text{C 队（世界模型）：} \quad & P(\Delta x = -1 \mid \text{左}) = 1.0, \quad P(\Delta x = +1 \mid \text{右}) = 1.0, \\
\text{B 队（视频模型）：} \quad & P(\Delta x = -1) = 0.9, \quad P(\Delta x = +1) = 0.1.
\end{aligned}
$$

C 队的模型完整保留了环境规律：给它右转，它就给出右移。B 队的模型只学到「这个路口通常向左」，你按下右转键，它依然以 $0.9$ 的概率把车画向左边——因为在它的训练目标里，右转这件事本来就只占一成权重。

$$\text{视频模型的输出} = \mathbb{E}_{a \sim \pi_\beta}\left[\text{世界模型的输出}\right].$$

这就是 1.2 节里“幽灵平均态”的分布层面根源：不是网络容量不够，而是**被优化的目标函数里根本没有留下动作这个自由度**。

一个直接推论：被动视频模型只在采集策略不变时才是准确的。一旦下游换了新策略（这恰恰是我们训练策略的目的），它的预测立即失效。这种失效被称为策略耦合，无法靠加大模型或增加数据来修复。

---

###逆动力学能补上缺口吗

D 队学的是 $P(a_t \mid o_t, o_{t+1})$：看见前后两帧，反推中间做了什么。它在两个场景里很有用：给无动作标注的互联网视频打伪标签，以及检验采集系统的时间对齐是否正确。

但它不能替代世界模型。原因在于它的条件里含有 $o_{t+1}$，而规划的时候我们恰恰**还不知道** $o_{t+1}$——那正是要预测的东西。逆动力学回答“要到那里该做什么”，前提是有人先告诉它“那里”长什么样。

这也解释了一类常见的系统设计：先用世界模型或视频模型生成一段目标未来，再用逆动力学把这段未来翻译成可执行动作。两个模型各管一半，缺一不可。

---

###从零实现：同一张表，三种查询

下面用纯 NumPy 把上面的推导跑一遍。我们先写下一个确定性环境和一个偏置策略，采样一批数据，然后分别按 B 队和 C 队的方式去估计。

```python
import numpy as np

rng = np.random.default_rng(0)
LEFT, RIGHT = 0, 1
P_BETA = np.array([0.9, 0.1])   # 采集策略：偏爱左转
DELTA = {LEFT: -1, RIGHT: +1}   # 环境：确定性

##采样 20000 条 (a_t, Δx) 记录
actions = rng.choice([LEFT, RIGHT], size=20000, p=P_BETA)
deltas = np.array([DELTA[a] for a in actions])

##C 队：动作条件世界模型 P(Δx | a)，按动作分组统计
for a, name in [(LEFT, "左"), (RIGHT, "右")]:
    sub = deltas[actions == a]
    p_minus = np.mean(sub == -1)
    print(f"世界模型 P(Δx=-1 | {name}) = {p_minus:.3f}")

##B 队：被动视频模型 P(Δx)，把动作边缘化掉
print(f"视频模型 P(Δx=-1)       = {np.mean(deltas == -1):.3f}")

##反事实检查：固定状态，只换动作，看两个模型的预测是否分叉
wm_gap = abs(np.mean(deltas[actions == LEFT] == -1)
             - np.mean(deltas[actions == RIGHT] == -1))
vm_gap = 0.0   # 视频模型的输出与动作无关，分歧恒为 0
print(f"反事实分歧：世界模型 {wm_gap:.3f}，视频模型 {vm_gap:.3f}")
```

运行输出：

```text
世界模型 P(Δx=-1 | 左) = 1.000
世界模型 P(Δx=-1 | 右) = 0.000
视频模型 P(Δx=-1)       = 0.898
反事实分歧：世界模型 1.000，视频模型 0.000
```

$0.898$ 而不是精确的 $0.9$，是有限采样的正常抖动。真正要盯住的是最后一行：**反事实分歧为 $0$ 的模型，无论画面多清晰，都不能用来规划。** 这个量会在 3.4 节被正式确立为世界模型的基本检查项之一。

---

###这张分解式怎么帮你读论文

拿到一篇新工作，先问三个问题，就能定位它在联合分布里的位置：

1. **它把什么放在条件一侧？** 有 $a_t$ 就是动作条件模型，没有就是被动生成器。
2. **它预测什么？** 像素（第 5 章）、潜在状态（第 4 章）、特征（第 6 章）、动作（第 7 章）还是三维占用（第 8 章）。预测目标决定了它服务谁。
3. **它用什么证据说明动作真的起作用？** 只报告重建质量或 FID 的工作，尚未证明自己脱离了 B 队。

后面五条设计路线，全部可以用这三个问题串起来。它们的分歧不在于用了哪种网络，而在于对同一个联合分布做了不同的切分。

---

###自测与常见陷阱

####自测题

1. **计算题**：某数据集中采集策略为 $\pi_\beta(\text{加速}) = 0.7$、$\pi_\beta(\text{刹车}) = 0.3$。加速使速度增加 $2\text{ m/s}$，刹车使速度减少 $4\text{ m/s}$，均为确定性。一个被动视频模型预测的速度变化期望是多少？
   - _计算_：
     $$\mathbb{E}[\Delta v] = 0.7 \times 2 + 0.3 \times (-4) = 1.4 - 1.2 = 0.2\text{ m/s}.$$
     它给出一个 $0.2$ 的温和加速，而真实世界里只存在 $+2$ 与 $-4$ 两种结果，$0.2$ 这个值从未发生过。
2. **思考题**：如果采集数据时使用的是均匀随机策略 $\pi_\beta(a) = 1/|\mathcal{A}|$，被动视频模型是否就等价于世界模型了？
   - _解析_：仍然不等价。均匀策略只是让边缘化的权重变均匀，$P(o_{t+1} \mid o_{\le t})$ 依然是各动作后果的平均值，输入端还是收不到动作，反事实分歧依旧为 $0$。均匀采集能改善的是覆盖度，不是可控性。
3. **判断题**：环境动力学 $P(o_{t+1} \mid o_{\le t}, a_t)$ 与采集策略无关，因此任何数据集都能把它学准。
   - _解析_：错误。这个量的**定义**与策略无关，但**估计精度**取决于数据覆盖。若某个动作在数据里从未出现，该条件分布就无从估计，这正是 1.4 节讨论的分布外问题。

####常见误区与工程陷阱

- **误区 1：用视频生成质量为世界模型背书**。FID、PSNR、人类偏好评分衡量的都是 $P(o_{t+1} \mid o_{\le t})$ 这一支，与动作可控性正交。指标漂亮和听从动作是两件独立的事。
- **误区 2：把逆动力学的伪标签当成真动作**。用逆动力学给互联网视频打上的动作标签，其误差会直接进入世界模型的条件一侧，形成误差叠加。伪标签必须单独报告准确率。
- **误区 3：忽视采集策略的记录**。数据卡里若不写清 $\pi_\beta$ 是人类遥操作、脚本策略还是随机探索，后续一旦发现模型偏向某个动作，将无法判断这是环境规律还是采集偏置。

---

###小结与下节预告

- 一段经历的联合分布可以精确分解为**初始分布 $\times$ 采集策略 $\times$ 环境动力学**，数据里始终混着策略与环境两种规律。
- 策略、被动视频生成、世界模型、逆动力学是对同一分布的四种不同查询；被动视频生成把动作边缘化，因而把采集策略吃进了模型。
- 世界模型的不可让渡特征是**条件里含有动作，且反事实分歧非零**。

四种查询都摊开之后，一个绕不过去的问题浮现了：到底满足什么条件才算世界模型？物理引擎算不算，视频生成器算不算，不重建像素的 MuZero 算不算？下一节将给出一个可以逐项检验的判据。

## 2. 世界模型的定义

“世界模型”这个词被用得越来越宽，宽到几乎失去了区分力：有人用它指视频生成器，有人用它指物理引擎，有人用它指一整套机器人系统。本节要做的事情很具体——给出一个能逐项打勾的判据，然后拿它去审四个具体系统。判据的价值不在于把谁排除在外，而在于当有人说“我们做了一个世界模型”时，你知道该问哪三个问题。

---

###桌上的四个系统

先摆出四个真实存在的系统，它们都与“预测世界”有关：

1. **MuJoCo 物理引擎**：给定当前状态和力矩，精确算出下一时刻的刚体位姿。
2. **文本到视频生成模型**：给一句话，生成一段看起来真实的视频。
3. **DQN 策略网络**：给一帧画面，直接输出该按哪个键。
4. **DreamerV3**：把画面压成潜在状态，在潜在空间里推演未来并训练策略。

凭直觉，第 4 个显然是世界模型，第 3 个显然不是。第 1 和第 2 个则众说纷纭。要把这件事说清，需要先把判据写下来。

---

###三条必要条件

我们采用如下工作定义。一个系统是世界模型，当且仅当它同时满足三条：

**条件一：它预测未来，而不是标注当前。**

形式上，它给出的是一个关于未来的分布或点估计：

$$\hat{P}(s_{t+1}, r_t \mid s_t, a_t) \quad \text{或} \quad (\hat{s}_{t+1}, \hat{r}_t) = f_\theta(s_t, a_t).$$

图像分类器 $P(y \mid x)$ 不满足这一条：它描述当前输入的属性，时间轴上没有前进。

**条件二：动作出现在条件一侧，且预测对动作敏感。**

这是 1.5 节反事实分歧的正式化。要求存在状态 $s$ 与动作对 $a \neq a'$，使得

$$\hat{P}(\cdot \mid s, a) \neq \hat{P}(\cdot \mid s, a').$$

被动视频生成器不满足这一条——不是因为它效果差，而是因为它的输入端没有动作这个接口。

**条件三：规律从数据里学出来，而不是人写下来。**

$$\theta^* = \arg\max_\theta \; \mathbb{E}_{(s,a,s') \sim \mathcal{D}}\left[\log \hat{P}_\theta(s' \mid s, a)\right].$$

物理引擎不满足这一条。它的转移规则是工程师用微分方程和碰撞算法写死的，参数需要手工标定，遇到未建模的现象（布料、液体、复杂摩擦）它不会从数据里自行改正。

三条之外还有一条**软要求**：模型的输出应当能被某个使用者消费——规划器、策略、碰撞检查器或人类操作员。一个谁都用不上的预测器在工程意义上不构成世界模型，但这一条不写进硬判据，因为它取决于系统边界怎么划。

---

###拿判据审四个系统

| 系统            | 预测未来 | 动作条件 | 从数据学 | 判定                   |
| --------------- | -------- | -------- | -------- | ---------------------- |
| MuJoCo 物理引擎 | 是       | 是       | 否       | 不是，是**手写模拟器** |
| 文本到视频模型  | 是       | 否       | 是       | 不是，是**被动生成器** |
| DQN 策略        | 否       | —        | 是       | 不是，是**无模型策略** |
| DreamerV3       | 是       | 是       | 是       | 是                     |

这张表有两处值得停下来想。

**物理引擎的落选不是贬低。** 在参数标定准确、现象已被建模的场合，物理引擎比任何学出来的模型都精确得多，第 7 章的 Sim-to-Real 全部建立在它之上。它被排除只是因为它不学习——这既是它的优点（不需要数据、不会幻觉），也是它的局限（未建模现象无法补救）。两者结合的做法叫残差学习：让网络只学模拟器算不准的那部分，这是 8.6 节的主题。

**DQN 的落选也不是贬低。** 它把“预测后果”这一步隐式地压进了 $Q(s,a)$ 里，跳过了对未来的显式推演。省掉推演换来了推理速度，代价是无法回答“如果我改做另一件事会怎样”这类问题。

---

###三件常被误认为必要的事

判据里没有出现的东西同样重要，因为它们经常被误当成门槛。

**不要求重建像素。** MuZero 完全不还原画面，它只学搜索需要的三样东西：

$$s_t = h_\theta(o_{\le t}), \qquad (\hat{r}_t, s_{t+1}) = g_\theta(s_t, a_t), \qquad (\hat{v}_t, \hat{\pi}_t) = f_\theta(s_t).$$

三条必要条件全部满足，所以它是世界模型，而且是最纯粹的一种——潜在状态里只留下了对决策有用的信息。第 6 章的 JEPA 同理，它预测特征而非像素。

**不要求状态严格马尔可夫。** 1.1 节讲过，内部状态只需是对预测“充分好”的统计量。RSSM 用固定维度的 $(h_t, z_t)$ 近似信念状态，这个近似不完美，但足以支撑规划。

**不要求可解释。** 潜在维度对不上任何物理量，不影响它是不是世界模型。可解释性是研究者的便利，不是定义的一部分。

反过来说，判据里也没有为“规模”留位置。一个 $3 \times 3$ 网格上的计数转移表，只要三条都满足，就是一台合格的世界模型——这正是 1.8 节要亲手做的东西。

---

###把条件二变成一次测量

三条里只有条件二是需要动手验证的（另外两条看设计就知道）。把它写成一个可计算的标量：固定一批状态，对每个状态取两个不同动作，测量两个预测分布的总变差距离并取平均：

$$D_{\text{cf}} = \frac{1}{|\mathcal{S}|}\sum_{s \in \mathcal{S}} \; \frac{1}{2}\sum_{s'} \left| \hat{P}(s' \mid s, a) - \hat{P}(s' \mid s, a') \right|.$$

$D_{\text{cf}} = 0$ 意味着模型完全无视动作；$D_{\text{cf}} = 1$ 意味着两个动作导致完全不重叠的未来。

```python
import numpy as np

def counterfactual_divergence(model, states, a1, a2):
    """对每个状态比较两个动作的预测分布，返回平均总变差距离。"""
    gaps = []
    for s in states:
        p1 = model(s, a1)          # 形状 [n_next_states] 的概率向量
        p2 = model(s, a2)
        gaps.append(0.5 * np.abs(p1 - p2).sum())
    return float(np.mean(gaps))

##三个模型：无视动作的、听动作的、把动作反过来用的
n = 4
def deaf_model(s, a):                       # 条件二不满足
    p = np.zeros(n); p[(s + 1) % n] = 1.0; return p

def good_model(s, a):                       # 条件二满足
    p = np.zeros(n); p[(s + (1 if a == 0 else -1)) % n] = 1.0; return p

states = list(range(n))
print(f"无视动作的模型 D_cf = {counterfactual_divergence(deaf_model, states, 0, 1):.2f}")
print(f"听从动作的模型 D_cf = {counterfactual_divergence(good_model, states, 0, 1):.2f}")
```

运行输出：

```text
无视动作的模型 D_cf = 0.00
听从动作的模型 D_cf = 1.00
```

注意 $D_{\text{cf}}$ 大只说明模型对动作有反应，**不说明反应的方向是对的**。一个把左右接反的模型同样能拿到 $D_{\text{cf}} = 1$。所以这项测量必须与真实转移对照使用，单独看它会被骗。

---

###自测与常见陷阱

####自测题

1. **判断题**：一个能够根据方向盘输入生成对应驾驶视频的模型，如果它的转移规则完全由人工编写的车辆动力学方程给出，它是世界模型吗？
   - _解析_：不是。它满足条件一与条件二，但违反条件三，属于手写模拟器加渲染器。若在其输出上再学一个残差网络来修正误差，则整个系统成为“模拟器 + 学习式世界模型”的混合体。
2. **思考题**：为什么把“能重建高清画面”写进定义会是一个坏主意？
   - _解析_：会把 MuZero 与 JEPA 这两类最重要的工作排除在外。重建像素只是获取训练信号的一种手段，而且是最昂贵的一种——它迫使模型为与任务无关的视觉细节买单（第 6 章的核心论点）。定义应当围绕“预测动作后果”这一功能，而非围绕输出的模态。
3. **计算题**：某模型在 $100$ 个状态上测得 $D_{\text{cf}} = 0.02$，而真实环境的两个动作导致完全不同的后继状态（真实 $D_{\text{cf}} = 1.0$）。这说明什么？
   - _解析_：说明动作接口几乎失效——模型把动作当成了可忽略的输入。常见原因有三：动作与帧的时间对齐错位、动作嵌入维度过小被淹没，或者训练数据里动作分布过于集中（1.5 节的采集偏置）。这属于必须在训练早期拦住的失效。

####常见误区与工程陷阱

- **误区 1：以模态论定义**。“输出视频的才是世界模型”“输出潜在向量的不算”都站不住。判据关心的是条件与预测的结构，不是输出长什么样。
- **误区 2：把演示视频当作证据**。一段流畅的演示只能证明感知质量，无法证明条件二。必须固定起点、只换动作、给出分歧数值，这是第 9 章评测体系的起点。
- **误区 3：混淆“系统里有世界模型”与“系统是世界模型”**。现代机器人栈往往同时含有策略、世界模型、模拟器和检查器。讨论时要指明说的是哪个部件，否则关于“它算不算”的争论毫无意义。

###小结与下节预告

- 世界模型的三条必要条件是：**预测未来、动作在条件一侧且预测对动作敏感、规律从数据学出**。
- 物理引擎因不学习而落选，被动视频生成器因缺少动作接口而落选，无模型策略因不显式预测未来而落选——落选都不等于无用。
- 定义**不要求**重建像素、不要求状态严格马尔可夫、不要求可解释，也不要求规模；条件二是唯一需要动手测量的一条，且必须与真实转移对照。

判据立好之后，就可以回头检阅历史了。下一篇 [1.4 经典世界模型](/chapters/01-why-world-models/04-classic-world-models) 将解剖 2018 年的 V-M-C 三元架构，并沿着 PlaNet、Dreamer 到 MuZero 的路线，看这三条条件在真实系统里分别是怎么被满足的。
