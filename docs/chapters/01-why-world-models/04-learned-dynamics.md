# 1.4 从经历学习动力学

在真实世界中，大自然绝不会附赠一份写满物理规律的手工规则代码。机器人与智能体所能拥有的，只有自己在环境中不断交互、探索所留下的历史轨迹数据。所谓学到的动力学（Learned Dynamics），就是通过统计与机器学习手段，从真实的交互经历（Experience Transitions）中提炼出转移分布。本节我们将拿走手工编写的转移表，探讨如何从零构建一台可学习的世界模型，并深入剖析复合误差与模型漏洞（Model Exploitation）两大根本挑战。

---

## 交互经历的标准化封装：转移五元组

智能体在环境中的每一次离散交互，都会产生一个标准的数据单元——**转移元组（Transition Tuple）**：

$$(s_t, a_t, r_t, s_{t+1}, d_t),$$

其中：

- $s_t$：智能体在 $t$ 时刻的当前状态（或观察 $o_t$）；
- $a_t$：智能体施加的控制动作；
- $r_t = R(s_t, a_t, s_{t+1})$：环境返回的即时标量奖励；
- $s_{t+1}$：动作作用后环境跃迁到的下一个状态；
- $d_t \in \{0, 1\}$：终止标志（Done / Terminal Flag），标记该回合（Episode）是否结束。

一个完整的交互回合 $\tau = \left( (s_0, a_0, r_0, s_1, d_0), \dots, (s_{T-1}, a_{T-1}, r_{T-1}, s_T, d_{T-1}) \right)$ 会被存入经验回放池（Replay Buffer）。世界模型的训练集，正是由成千上万条这样的转移元组汇聚而成。

```text
智能体状态 s_t ──施加动作 a_t──> 作用于环境 ──> 返回 (r_t, s_{t+1}, d_t)
                                                      │
                                                      ▼ 存入经验池
                         Replay Buffer: [ (s, a, r, s', d)₁ , (s, a, r, s', d)₂ , ... ]
```

---

## 从频次计数到极大似然估计（MLE）

在离散状态与动作空间中，最纯粹、无任何超参数的世界模型是**经验频次计数器（Empirical Frequency Counter）**。

假设智能体在状态 $s = (2,0)$ 执行动作 $a = \text{Right}$ 共记录了 $N(s, a) = 10$ 次：

- 其中有 $8$ 次成功向右移动到了 $s' = (2,1)$；
- 有 $2$ 次由于地面湿滑打滑，智能体停留在原地 $s' = (2,0)$。

根据统计学中的极大似然估计（Maximum Likelihood Estimation, MLE），在状态 $s$ 执行动作 $a$ 转移到 $s'$ 的经验概率分布为：

$$\widehat{P}(s' \mid s, a) = \frac{N(s, a, s')}{N(s, a)} = \frac{N(s, a, s')}{\sum_{s'' \in \mathcal{S}} N(s, a, s'')}.$$

代入上述数值：

$$\widehat{P}\left((2,1) \mid (2,0), \text{Right}\right) = \frac{8}{10} = 0.8,$$
$$\widehat{P}\left((2,0) \mid (2,0), \text{Right}\right) = \frac{2}{10} = 0.2.$$

```text
状态 (2,0) + 动作 Right ── (历史样本数 N = 10) ──┬── 80% 概率 ──> 转移至 (2,1) [正常前进]
                                                 └── 20% 概率 ──> 转移至 (2,0) [打滑原地]
```

这张统计表已经是一台完备的世界模型：

1. 它完全从原始数据中自主学得，没有任何人工硬编码；
2. 它具备动作条件响应能力；
3. 它忠实地捕获了物理世界固有的随机性（Stochasticity）。

## 未见状态（OOD）与模型漏洞（Model Exploitation）

当世界模型脱离人工硬编码后，立刻会面临机器学习中最严峻的两个本质困境：

### 1. 数据未覆盖与分布外问题（Out-of-Distribution, OOD）

如果智能体在探索过程中从未在状态 $s = (0,2)$ 执行过动作 $\text{Up}$（因为上方是墙壁），则：
$$N((0,2), \text{Up}) = 0.$$

- **表格计数模型**：会严谨地返回“该状态动作未定义”（$\text{Undefined / NaN}$），并发出未知警告；
- **深度神经网络模型**：由于参数化泛化的存在，神经网络**永远不会拒绝回答**。面对从未见过的输入，神经网络会强行插值或外推，输出一个极度自信却完全错误的伪预测 $\hat{s}'$。

### 2. 规划器对模型漏洞的恶意利用（Model Exploitation）

这是基于模型的强化学习（Model-Based RL）中最臭名昭著的失效模式。

假设神经网络在未覆盖区域产生了一个致命幻觉：它错误地预测“在 $(0,2)$ 向上穿墙可以瞬间获得 $+100$ 的超额奖励”。
当优化算法（如 MCTS、CEM、强化学习 Actor）在世界模型内部搜寻最优路径时，优化器的天性就是**寻找模型内部得分最高的极值点**。结果，规划器会专门把这个根本不存在的“穿墙捷径”当成最优策略。一旦部署到真机上，机器人就会一头撞在墙上。

```text
未见样本 (OOD) ──> 神经网络产生虚幻高分 ──> 规划器专门寻找极值 ──> 锁定虚假捷径 (模型漏洞)
                                                                       │
                                                                       ▼ 真机实测
                                                                  物理撞毁失败
```

**防范策略**：

- 在奖励预测中引入**悲观主义惩罚（Pessimism / Uncertainty Penalty）**：$\tilde{R}(s, a) = \hat{R}(s, a) - \beta \cdot \sigma(s, a)$；
- 限制规划时域 $H$，避免过度深入未探索区域；
- 采用集成模型（Ensemble Models）估计方差 $\sigma$。

## 复合误差（Compounding Error）的数学本质

很多人会问：“如果我的单步动力学模型在测试集上的预测准确率高达 $95\%$（单步误差仅 $5\%$），为什么连续推演 20 步后整个系统完全失控？”

我们做一个极简的独立误差概率推导。设单步动力学预测正确的概率为 $p = 0.95$，在没有任何真机闭环修正的纯开环推演下，连续 $H = 20$ 步推演中**每一步都完全正确**的概率为：

$$P(\text{全程无误}) = p^H = 0.95^{20} \approx 0.3585 \approx 35.8\%.$$

```text
预测步数 H = 1  : 准确率 = 95.0%  ███████████████████░
预测步数 H = 5  : 准确率 = 77.4%  ███████████████░░░░░
预测步数 H = 10 : 准确率 = 59.9%  ████████████░░░░░░░░
预测步数 H = 20 : 准确率 = 35.8%  ███████░░░░░░░░░░░░░
预测步数 H = 50 : 准确率 =  7.7%  ██░░░░░░░░░░░░░░░░░░
```

现实情况比这个独立假设更为残酷：**动力学误差是非独立的**。第 1 步产生的微小状态偏差 $\epsilon_1$，会导致第 2 步的输入进入轻微的 OOD 区域；第 2 步在畸变输入下产生更大的误差 $\epsilon_2$……误差像滚雪球一样呈指数级放大，这种现象被称为**协变量偏移（Covariate Shift）与复合误差**。

因此，评价世界模型时，**单步误差（One-Step Loss）是极具欺骗性的指标**，必须同时评测多步展开误差（Multi-Step Rollout Error）与闭环任务成功率。

## 世界模型失效定位的四层排查法

当一套基于世界模型的系统在任务中崩溃时，绝不要盲目调大神经网络参数量。请按照以下四层因果树逐级排查：

```text
┌─────────────────────────────────────────────────────────────┐
│                 世界模型系统失效四层排查法                   │
├─────────────────────────────────────────────────────────────┤
│ 1. 数据层 (Data)     : 存在时间戳错位？归一化泄漏？数据量不足？│
│ 2. 信息层 (POMDP)    : 观察是否缺失了速度、质量或摩擦等导数？  │
│ 3. 模型层 (Capacity) : 网络容量是否受限？是否存在严重欠拟合？  │
│ 4. 规划层 (Exploitation): 规划深度是否过大？是否钻了 OOD 漏洞？ │
└─────────────────────────────────────────────────────────────┘
```

1. **第一层：数据层（Data Quality & Alignment）**
   - 检查转移元组 $(s_t, a_t, s_{t+1})$ 是否存在 $t$ 与 $t+1$ 的错位；
   - 检查多相机与机械臂传感器的时间戳同步误差；
   - 检查训练集是否发生了跨 Episode 拼接污染。
2. **第二层：信息层（Partial Observability）**
   - 检查任务是否退化为 POMDP。如果两个物理结果不同的场景在观察端完全一致，模型不可能从单帧中学会正确转移（需补齐历史帧或隐状态）。
3. **第三层：模型层（Model Representation & Capacity）**
   - 检查模型表达能力是否足以覆盖非线性物理；检查是否用单一 MSE 拟合了多模态分布。
4. **第四层：规划与使用层（Planner & Exploitation）**
   - 检查规划时域 $H$ 是否超出了模型的置信区间；检查规划器是否在未探索的 OOD 区域找到了虚假局部极值。

## 从零实现：从离散轨迹学习概率转移模型

下面用纯 Python 演示如何从随机采样的交互数据中，学习出一张具备不确定性感知与 OOD 检测能力的概率世界模型：

```python
import numpy as np
from collections import defaultdict

class LearnedTabularWorldModel:
    """从原始轨迹中通过 MLE 统计学习的概率世界模型"""
    def __init__(self):
        # 统计计数器: counts[s, a][s_next] = 频次
        self.counts = defaultdict(lambda: defaultdict(int))
        self.sa_totals = defaultdict(int)

    def train(self, dataset: list):
        """输入数据集: list of (s, a, r, s_next, done)"""
        for s, a, r, s_next, done in dataset:
            self.counts[(s, a)][s_next] += 1
            self.sa_totals[(s, a)] += 1

    def predict(self, state: tuple, action: str):
        """
        预测给定 (state, action) 的转移分布与不确定性
        返回: (转移概率字典, 是否为 OOD 状态)
        """
        key = (state, action)
        total = self.sa_totals[key]
        if total == 0:
            # OOD 样本：数据集中从未见过
            return {}, True

        # 计算 MLE 经验概率
        probs = {s_next: count / total for s_next, count in self.counts[key].items()}
        return probs, False

# 1. 模拟环境采集 50 条含打滑随机性的真实轨迹
true_transitions = {
    ((0, 0), 'right'): [( (0, 1), 0.8 ), ( (0, 0), 0.2 )],  # 80% 成功，20% 打滑
    ((0, 1), 'right'): [( (0, 2), 0.9 ), ( (0, 1), 0.1 )],
    ((0, 1), 'down'):  [( (1, 1), 1.0 )],                   # 陷阱
}

np.random.seed(42)
dataset = []
for _ in range(100):
    for sa, outcomes in true_transitions.items():
        s, a = sa
        # 依概率采样一次真实跃迁
        next_states, probs = zip(*outcomes)
        idx = np.random.choice(len(next_states), p=probs)
        s_next = next_states[idx]
        dataset.append((s, a, -1.0, s_next, False))

# 2. 训练可学习模型
model = LearnedTabularWorldModel()
model.train(dataset)

# 3. 验证学习到的转移概率与 OOD 判定
print("===== 模型推断与不确定性检验 =====")
for query_sa in [((0, 0), 'right'), ((0, 1), 'right'), ((2, 2), 'up')]:
    s, a = query_sa
    probs, is_ood = model.predict(s, a)
    if is_ood:
        print(f"查询 ({s}, '{a}'): [警告] 数据未覆盖 (OOD)！模型拒绝盲目预测。")
    else:
        prob_str = ", ".join([f"{ns}: {p:.2f}" for ns, p in probs.items()])
        print(f"查询 ({s}, '{a}'): 统计学到的分布 -> {prob_str} (样本数: {model.sa_totals[query_sa]})")
```

运行输出：

```text
===== 模型推断与不确定性检验 =====
查询 ((0, 0), 'right'): 统计学到的分布 -> (0, 1): 0.81, (0, 0): 0.19 (样本数: 100)
查询 ((0, 1), 'right'): 统计学到的分布 -> (0, 2): 0.88, (0, 1): 0.12 (样本数: 100)
查询 ((2, 2), 'up'): [警告] 数据未覆盖 (OOD)！模型拒绝盲目预测。
```

代码清晰证明：当数据充分时，MLE 统计模型能够高精度复原真实物理转移与打滑率；在面对未见动作时，严谨的世界模型应显式标定 OOD 状态，为规划器提供不确定性安全边界。

## 自测与常见陷阱

### 自测题

1. **计算题**：某自动驾驶动力学神经网络在单步速度预测上的均方根误差（RMSE）为 $0.1\text{ m/s}$。若在开环推演中误差以每步 $1.2$ 倍的复合率非线性扩散，推演 10 步后的瞬时速度误差约为多少？
   - _计算_：
     $$\epsilon_{10} = 0.1 \times 1.2^{10} \approx 0.1 \times 6.19 \approx 0.62\text{ m/s}.$$
     单步微小的误差在 10 步后放大了 6 倍以上。
2. **思考题**：为什么直接在离线收集的固定数据集上训练世界模型，比在在线边探索边收集的数据集上更容易遭遇模型漏洞？
   - _解析_：离线数据集的状态动作覆盖范围极其狭窄（受限于采集策略）。规划器在离线模型中极易搜索到数据集边界之外的虚假高分区域；而在在线学习中，智能体一旦去真机尝试这个虚假动作，就会立刻带回真实的惩罚数据，从而迅速修复该模型漏洞（Dyna 循环）。
3. **判断题**：为了彻底消除 OOD 风险，我们应该把神经网络的训练步数（Epoch）增加 10 倍，直到训练集损失接近 0。
   - _解析_：错误。过度训练会导致严重的过拟合，使网络对训练集样本死记硬背，对稍微偏离训练分布的状态产生更加剧烈的剧烈震荡与奇点幻觉。

### 常见误区与工程陷阱

- **误区 1：在数据集中混合不同物理参数的 Episode**。例如把摩擦系数为 $0.8$ 的晴天数据与摩擦系数为 $0.2$ 的雨天数据混在一起，未提供天气条件标识。模型将被迫拟合出不符合任何一种天气的“平均物理”。
- **误区 2：使用随机打乱（Shuffle）破坏时序因果链**。世界模型的数据管线必须维护完整的时序连续片段（Chunks / Trajectories），严禁在帧级别无序打乱导致前后上下文丢失。
- **误区 3：单步评估代替闭环验证**。仅看验证集上的 One-step Loss 极低就宣布模型成功，结果在长程 Rollout 或下游控制中彻底崩溃。

## 小结与下节预告

- **转移五元组 $(s_t, a_t, r_t, s_{t+1}, d_t)$** 是学习世界模型的通用原子积木；极大似然估计提供了最直观的概率统计基准。
- **复合误差与协变量偏移** 决定了开环长程预测的脆弱性；**OOD 幻觉与模型漏洞** 是优化算法与世界模型博弈的核心矛盾。
- 诊断世界模型必须遵循“数据 $\to$ 信息 $\to$ 模型 $\to$ 规划”的四层系统化排查路径。
