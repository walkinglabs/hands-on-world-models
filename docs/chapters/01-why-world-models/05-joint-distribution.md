# 1.5　观察与动作的联合分布

前面四节分别处理了状态、动作条件、多步推演与动力学学习。现在把它们放在同一张纸上：一段经历里出现的所有观察与动作，构成一个联合分布。行为克隆、视频生成、逆动力学、可控预测这些听起来毫不相干的任务，其实都是对这同一个分布提出的不同提问。搞清楚谁是条件、谁是待预测量，就能一眼看穿一篇新论文究竟在建模什么。

---

## 同一份数据，四支队伍

一台桌面机械臂完成了一次抓取，采集系统记录下这样一段经历：

```text
o_0 ──a_0──> o_1 ──a_1──> o_2 ──a_2──> o_3
```

四支队伍拿到完全相同的这批数据，各自训练了一个模型：

| 队伍 | 模型输入         | 模型输出  | 通行叫法                     |
| ---- | ---------------- | --------- | ---------------------------- |
| A    | $o_{\le t}$      | $a_t$     | 行为克隆 / 策略              |
| B    | $o_{\le t}$      | $o_{t+1}$ | 被动视频生成                 |
| C    | $o_{\le t}, a_t$ | $o_{t+1}$ | 动作条件世界模型             |
| D    | $o_t, o_{t+1}$   | $a_t$     | 逆动力学（inverse dynamics） |

四个模型的网络结构可以完全一样，训练数据一模一样，差别只在于**哪些变量放在条件一侧**。这不是命名习惯的差异，而是数学对象的差异，下面会看到它带来的后果有多严重。

---

## 一次经历的联合分布

把一段长度为 $T$ 的经历记作轨迹 $\tau = (o_0, a_0, o_1, a_1, \dots, a_{T-1}, o_T)$。采集这批数据的过程，等价于从一个联合分布中采样：

$$P(\tau) = P(o_0, a_0, o_1, \dots, o_T).$$

按时间顺序反复使用链式法则，这个联合分布可以精确地拆成两串因子交替相乘：

$$P(\tau) = \underbrace{P(o_0)}_{\text{初始分布}} \prod_{t=0}^{T-1} \underbrace{\pi_\beta(a_t \mid o_{\le t})}_{\text{采集策略}} \cdot \underbrace{P(o_{t+1} \mid o_{\le t}, a_t)}_{\text{环境动力学}}.$$

这个分解式是本节的全部内容。它告诉我们，数据里其实**混着两种截然不同的规律**：

- $P(o_{t+1} \mid o_{\le t}, a_t)$ 是**环境的性质**。它由物理规律决定，不管谁来操作机械臂，它都不变。
- $\pi_\beta(a_t \mid o_{\le t})$ 是**采集者的性质**。换一个操作员、换一个策略，它立刻就变。

上表里的四支队伍，A 队在学 $\pi_\beta$，C 队在学 $P(o_{t+1} \mid o_{\le t}, a_t)$。这两个量分别属于两种不同的东西，混淆它们会付出实际代价。

---

## 被动视频生成为什么会把策略吃进去

B 队最值得细看。它的目标 $P(o_{t+1} \mid o_{\le t})$ 里没有出现动作，但动作并没有消失，而是被求和（边缘化）掉了：

$$P(o_{t+1} \mid o_{\le t}) = \sum_{a} \pi_\beta(a \mid o_{\le t}) \cdot P(o_{t+1} \mid o_{\le t}, a).$$

等号右边同时含有 $\pi_\beta$ 和环境动力学。也就是说，**被动视频模型学到的是「环境动力学与采集策略的乘积」**，而不是环境本身。

用具体数字看后果。设某个状态下只有两个动作：左转与右转。环境是确定性的，左转必然使横向坐标减 $1$，右转必然加 $1$。采集数据的司机有强烈的左转偏好：

$$\pi_\beta(\text{左}) = 0.9, \qquad \pi_\beta(\text{右}) = 0.1.$$

于是三个模型分别学到：

$$
\begin{aligned}
\text{C 队（世界模型）：} \quad & P(\Delta x = -1 \mid \text{左}) = 1.0, \quad P(\Delta x = +1 \mid \text{右}) = 1.0, \\
\text{B 队（视频模型）：} \quad & P(\Delta x = -1) = 0.9, \quad P(\Delta x = +1) = 0.1.
\end{aligned}
$$

C 队的模型完整保留了环境规律：给它右转，它就给出右移。B 队的模型只学到「这个路口通常向左」，你按下右转键，它依然以 $0.9$ 的概率把车画向左边——因为在它的训练目标里，右转这件事本来就只占一成权重。

$$\text{视频模型的输出} = \mathbb{E}_{a \sim \pi_\beta}\left[\text{世界模型的输出}\right].$$

这就是 1.2 节里“幽灵平均态”的分布层面根源：不是网络容量不够，而是**被优化的目标函数里根本没有留下动作这个自由度**。

一个直接推论：被动视频模型只在采集策略不变时才是准确的。一旦下游换了新策略（这恰恰是我们训练策略的目的），它的预测立即失效。这种失效被称为策略耦合，无法靠加大模型或增加数据来修复。

---

## 逆动力学能补上缺口吗

D 队学的是 $P(a_t \mid o_t, o_{t+1})$：看见前后两帧，反推中间做了什么。它在两个场景里很有用：给无动作标注的互联网视频打伪标签，以及检验采集系统的时间对齐是否正确。

但它不能替代世界模型。原因在于它的条件里含有 $o_{t+1}$，而规划的时候我们恰恰**还不知道** $o_{t+1}$——那正是要预测的东西。逆动力学回答“要到那里该做什么”，前提是有人先告诉它“那里”长什么样。

这也解释了一类常见的系统设计：先用世界模型或视频模型生成一段目标未来，再用逆动力学把这段未来翻译成可执行动作。两个模型各管一半，缺一不可。

---

## 从零实现：同一张表，三种查询

下面用纯 NumPy 把上面的推导跑一遍。我们先写下一个确定性环境和一个偏置策略，采样一批数据，然后分别按 B 队和 C 队的方式去估计。

```python
import numpy as np

rng = np.random.default_rng(0)
LEFT, RIGHT = 0, 1
P_BETA = np.array([0.9, 0.1])   # 采集策略：偏爱左转
DELTA = {LEFT: -1, RIGHT: +1}   # 环境：确定性

# 采样 20000 条 (a_t, Δx) 记录
actions = rng.choice([LEFT, RIGHT], size=20000, p=P_BETA)
deltas = np.array([DELTA[a] for a in actions])

# C 队：动作条件世界模型 P(Δx | a)，按动作分组统计
for a, name in [(LEFT, "左"), (RIGHT, "右")]:
    sub = deltas[actions == a]
    p_minus = np.mean(sub == -1)
    print(f"世界模型 P(Δx=-1 | {name}) = {p_minus:.3f}")

# B 队：被动视频模型 P(Δx)，把动作边缘化掉
print(f"视频模型 P(Δx=-1)       = {np.mean(deltas == -1):.3f}")

# 反事实检查：固定状态，只换动作，看两个模型的预测是否分叉
wm_gap = abs(np.mean(deltas[actions == LEFT] == -1)
             - np.mean(deltas[actions == RIGHT] == -1))
vm_gap = 0.0   # 视频模型的输出与动作无关，分歧恒为 0
print(f"反事实分歧：世界模型 {wm_gap:.3f}，视频模型 {vm_gap:.3f}")
```

运行输出：

```text
世界模型 P(Δx=-1 | 左) = 1.000
世界模型 P(Δx=-1 | 右) = 0.000
视频模型 P(Δx=-1)       = 0.898
反事实分歧：世界模型 1.000，视频模型 0.000
```

$0.898$ 而不是精确的 $0.9$，是有限采样的正常抖动。真正要盯住的是最后一行：**反事实分歧为 $0$ 的模型，无论画面多清晰，都不能用来规划。** 这个量会在 3.4 节被正式确立为世界模型的基本检查项之一。

## 这张分解式怎么帮你读论文

拿到一篇新工作，先问三个问题，就能定位它在联合分布里的位置：

1. **它把什么放在条件一侧？** 有 $a_t$ 就是动作条件模型，没有就是被动生成器。
2. **它预测什么？** 像素（第 5 章）、潜在状态（第 4 章）、特征（第 6 章）、动作（第 7 章）还是三维占用（第 8 章）。预测目标决定了它服务谁。
3. **它用什么证据说明动作真的起作用？** 只报告重建质量或 FID 的工作，尚未证明自己脱离了 B 队。

后面五条设计路线，全部可以用这三个问题串起来。它们的分歧不在于用了哪种网络，而在于对同一个联合分布做了不同的切分。

## 自测与常见陷阱

### 自测题

1. **计算题**：某数据集中采集策略为 $\pi_\beta(\text{加速}) = 0.7$、$\pi_\beta(\text{刹车}) = 0.3$。加速使速度增加 $2\text{ m/s}$，刹车使速度减少 $4\text{ m/s}$，均为确定性。一个被动视频模型预测的速度变化期望是多少？
   - _计算_：
     $$\mathbb{E}[\Delta v] = 0.7 \times 2 + 0.3 \times (-4) = 1.4 - 1.2 = 0.2\text{ m/s}.$$
     它给出一个 $0.2$ 的温和加速，而真实世界里只存在 $+2$ 与 $-4$ 两种结果，$0.2$ 这个值从未发生过。
2. **思考题**：如果采集数据时使用的是均匀随机策略 $\pi_\beta(a) = 1/|\mathcal{A}|$，被动视频模型是否就等价于世界模型了？
   - _解析_：仍然不等价。均匀策略只是让边缘化的权重变均匀，$P(o_{t+1} \mid o_{\le t})$ 依然是各动作后果的平均值，输入端还是收不到动作，反事实分歧依旧为 $0$。均匀采集能改善的是覆盖度，不是可控性。
3. **判断题**：环境动力学 $P(o_{t+1} \mid o_{\le t}, a_t)$ 与采集策略无关，因此任何数据集都能把它学准。
   - _解析_：错误。这个量的**定义**与策略无关，但**估计精度**取决于数据覆盖。若某个动作在数据里从未出现，该条件分布就无从估计，这正是 1.4 节讨论的分布外问题。

### 常见误区与工程陷阱

- **误区 1：用视频生成质量为世界模型背书**。FID、PSNR、人类偏好评分衡量的都是 $P(o_{t+1} \mid o_{\le t})$ 这一支，与动作可控性正交。指标漂亮和听从动作是两件独立的事。
- **误区 2：把逆动力学的伪标签当成真动作**。用逆动力学给互联网视频打上的动作标签，其误差会直接进入世界模型的条件一侧，形成误差叠加。伪标签必须单独报告准确率。
- **误区 3：忽视采集策略的记录**。数据卡里若不写清 $\pi_\beta$ 是人类遥操作、脚本策略还是随机探索，后续一旦发现模型偏向某个动作，将无法判断这是环境规律还是采集偏置。

## 小结与下节预告

- 一段经历的联合分布可以精确分解为**初始分布 $\times$ 采集策略 $\times$ 环境动力学**，数据里始终混着策略与环境两种规律。
- 策略、被动视频生成、世界模型、逆动力学是对同一分布的四种不同查询；被动视频生成把动作边缘化，因而把采集策略吃进了模型。
- 世界模型的不可让渡特征是**条件里含有动作，且反事实分歧非零**。

四种查询都摊开之后，一个绕不过去的问题浮现了：到底满足什么条件才算世界模型？物理引擎算不算，视频生成器算不算，不重建像素的 MuZero 算不算？下一篇 [1.6 世界模型的定义](/chapters/01-why-world-models/06-what-is-a-world-model) 将给出一个可以逐项检验的判据。
