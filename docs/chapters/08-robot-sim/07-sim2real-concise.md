# 8.7　现实迁移的简洁实现

> **本节目标**：在同一台机械臂上把任务难度从抓取推到插接，量出每一道 sim-to-real 关口各吃掉多少成功率；全身控制另走一条教师-学生蒸馏轨道，量出特权观察被拿掉之后掉了多少。

> **前置知识**：[7.2 行为克隆与扩散策略](/chapters/07-robot-policy/04-behavior-cloning)、[7.4 接触力与全身控制](/chapters/07-robot-policy/02-dexterous-manipulation)、[7.6 物理引擎与仿真构建](/chapters/08-robot-sim/01-physics-mujoco)。

> **层级**：本节是放大档、不是配方级实验室。不要求把两条轨道都做成完整 walkthrough；机械臂是主轨道，全身蒸馏是第二条对照轨道。

桌上放着一个边长 $40\ \mathrm{mm}$ 的立方体，夹爪最大张开 $85\ \mathrm{mm}$。抓它是个宽容差任务：末端位置差 $20\ \mathrm{mm}$ 也常常能成。

把同一台臂换成「把 $\varnothing 20.0\ \mathrm{mm}$ 的轴插进 $\varnothing 20.2\ \mathrm{mm}$ 的孔」，容差降到 $0.1\ \mathrm{mm}$。同一套代码、同一套权重，难度差两个数量级。这一节沿着这条梯度走，每一级都记下成功率掉在哪里。

---

## 环境与预算

默认栈是 MuJoCo（含 MJX）或 ManiSkill3，两者都能在单卡上跑批量环境。全节严守**单张 24 GB 显卡**，参考量级如下：

- 纯状态观察 + MJX：$2048$ 个并行环境，显存约 $6\ \mathrm{GB}$。
- $64\times 64$ RGB 观察 + GPU 渲染：并行数降到 $256$ 量级，显存约 $18\ \mathrm{GB}$。
- BC 训练（$50$ 条示范、ResNet-18 视觉编码器、batch 64）：显存约 $5\ \mathrm{GB}$，单次训练 $20$–$40$ 分钟。
- 扩散或流匹配动作头：训练显存与 BC 同量级，推理延迟随采样步数线性增长，务必实测。

安装与依赖以各自官方文档为准。第一次跑通请先用状态观察，视觉留到步骤 3。

## 步骤 1：先让接口对齐

不训任何模型。写死一段 $200$ 步的关节位置序列，在仿真里开环回放，记录每一步的关节角。这一步要确认的是单位、坐标系、控制模式（位置/速度/力矩）和控制频率四件事都写对了。

同时把总质量、各连杆惯量主轴和自由落体时间打印出来，和资产文件的标称值核对。这三个数对不上，后面所有实验都是在另一台机器人上做的。

## 步骤 2：抓取的 BC 基线

采集 $50$ 条脚本化或遥操作示范，按 [7.1](/chapters/07-robot-policy/01-multimodal-observation) 的字段对齐存好。训练三档策略做公平对照，预算固定：

1. 状态观察 + MSE 动作头（最小基线）。
2. 状态观察 + 动作分块，$K=16$。
3. 视觉 + 状态 + 动作分块。

三档都在同一批 $50$ 个初始位姿上闭环评测。若第 3 档没有明显超过第 1 档，先怀疑数据和对齐，不要先加参数。

## 步骤 3：泛化与执行前的后果检查

把物体初始位置的采样范围扩大 $2$ 倍，加入示范里没出现的桌面纹理和光照。成功率一定会掉，要记录的是掉在哪一类条件上。

然后接上 [7.3](/chapters/07-robot-policy/07-vla-rtx) 的后果模型：策略采样 $8$ 个候选 chunk，后果模型预测各自的末端位姿与碰撞概率，重排后执行第一段。这里必须同时报告碰撞率**和**任务进展——只报碰撞下降，会得到一个学会不动的模型。

## 步骤 4：插接

换成 $\varnothing 20.0/\varnothing 20.2\ \mathrm{mm}$ 的轴孔。位置控制在这个容差下不可能成功，必须启用阻抗控制：插入轴向刚度取 $200$–$800\ \mathrm{N/m}$，垂直方向保持较高刚度。策略输出改为「目标位姿 + 期望刚度」，让接触力参与对准。

再做一次跨模拟器交叉验证：在 MuJoCo 里训练的权重，直接拿到 ManiSkill3/SAPIEN 里评测（或反向）。两边的成功率之差就是接触模型差异的直接读数，也是真机迁移的一个下界估计。

## 步骤 5（选做）：真机

低成本路线是 SO-100/SO-101 加 LeRobot 生态：开源打印件、舵机、遥操作与数据格式都是现成的，硬件在百美元量级。

这一步是**选做**，门槛必须说清：3D 打印、装配、舵机标定、手眼标定加起来通常要一到两周；舵机的间隙和发热会让同一策略在一小时内表现漂移；插接对这类臂的重复定位精度是硬挑战，很可能做不成，做不成本身也是要报告的结果。不具备条件的读者把步骤 4 的跨模拟器差异作为终点，实验依然完整。

## 需要报告的指标

| 指标         | 定义                                | 抓取参考线 | 插接参考线 |
| ------------ | ----------------------------------- | ---------- | ---------- |
| 成功率       | $n=50$ 次试验的比例，附 $95\%$ 区间 | $\ge 0.85$ | $\ge 0.50$ |
| 周期时间     | 成功试验的平均耗时                  | $\le 6$ s  | $\le 15$ s |
| 峰值接触力   | 整条轨迹的接触力最大值              | $\le 20$ N | $\le 15$ N |
| 动作抖动     | 相邻动作差的 RMS                    | 报告即可   | 报告即可   |
| 推理延迟     | 单次采样的 p50 / p95 毫秒           | 报告即可   | 报告即可   |
| 跨模拟器差异 | 两个模拟器成功率之差的绝对值        | 报告即可   | 报告即可   |

$n=50$ 时成功率的半宽约 $\pm 0.14$。参考线是判断「有没有跑通」的门槛，不是论文级结论。

## 常见失败与排查

| 现象                     | 最可能的原因           | 先查什么                             |
| ------------------------ | ---------------------- | ------------------------------------ |
| 损失下降但闭环成功率不动 | 动作多模态被 MSE 平均  | 换分块或生成式动作头，看是否翻转     |
| 成功但末端高频抖动       | 动作未归一化或无平滑   | 打印动作分布，看是否贴着限位         |
| 换 seed 成功率大幅波动   | 试验次数太少           | 提高 $n$，报告置信区间               |
| 插接总在孔口停住         | 插入方向刚度太高       | 降低该方向 $K_p$，检查力反馈是否接入 |
| 换模拟器成功率掉一半     | 资产转换或接触参数不同 | 核对质量惯量，重跑步骤 1 的开环回放  |
| 真机首次执行就撞         | 手眼标定或坐标系符号错 | 低速点动验证工作空间边界             |
| 真机成功率随时间单调下降 | 舵机发热、传动间隙     | 记录温度，中途重新标定               |

## 第二条轨道：全身策略的教师-学生蒸馏

机械臂轨道量的是接触容差。腿式与全身量的是另一件事：仿真里能读到的特权信息，真机上全部没有。

一个能读到地形高度图、足端摩擦系数和外部推力的教师策略，在起伏地形上连走 $1000$ 步不跌倒。把观察换成真机唯一能拿到的那 $78$ 维——关节、IMU、指令、上一动作——用同样的算法和预算重训一遍，通常在两三百步之内就倒了。这个差距不是调参能补的，它是部分可观带来的探索困难。所以腿式控制的标准配方是分两段：先在仿真里用特权信息把控制问题解干净，再把解压缩进一个只用可部署观察的学生。理论见 [7.4](/chapters/07-robot-policy/02-dexterous-manipulation)，延迟与域随机见 [7.5](/chapters/08-robot-sim/01-physics-mujoco)。

默认栈是 Isaac Lab（GPU 并行 RL）加 MuJoCo（独立评测）。单张 $24\ \mathrm{GB}$ 卡：教师 PPO 用 $4096$ 个状态观察环境，显存约 $8\ \mathrm{GB}$，$2\times 10^{9}$ 步约 $3$–$6$ 小时；学生蒸馏 $5\times 10^{8}$ 步量级，约 $1$ 小时。观察维度按一台 $23$ 关节人形估算：可部署约 $78$ 维，特权再加约 $200$ 维。

**阶段 1：特权教师。** 用 PPO 训练 $\pi^{T}(a\mid s_t,\xi_t)$。奖励至少包含速度跟踪、姿态保持、能耗和足端滑移。有一条容易被跳过的检查：把特权通道逐个置零，看性能掉多少。如果地形高度图置零后教师几乎不变，说明它根本没在用地形，后面的蒸馏就没有信息可传。

**阶段 2：学生蒸馏。** 学生 $\pi^{S}(a\mid o_{t-H:t})$ 只吃可部署观察，用 $H=50$ 步历史经一维卷积或 GRU 压缩。**关键是数据由谁生成**：必须让学生自己 rollout，再由教师在同一状态上给出标注（DAgger 式在线蒸馏）。

$$
\mathcal{L}_{\text{distill}}=\mathbb{E}_{s\sim d_{\pi^{S}}}\bigl\lVert \pi^{S}\bigl(o_{t-H:t}\bigr)-\pi^{T}\bigl(s_t,\xi_t\bigr)\bigr\rVert_2^2
$$

期望下标是 $d_{\pi^{S}}$ 而不是 $d_{\pi^{T}}$。若只用教师轨迹做离线回归，学生一旦偏离就没有监督，就退化成 [7.2](/chapters/07-robot-policy/04-behavior-cloning) 里那个复合误差问题。做一次对照：离线回归 vs 在线 DAgger，比较跌倒率。延迟与动作重复也要在这一阶段进环境——学生是要部署的那个模型，它必须在训练时就见过真机的时序。

**阶段 3：跨模拟器交叉验证。** 把 Isaac Lab 训出的学生权重直接搬到 MuJoCo 评测，不做任何微调。资产要重新核对总质量、连杆惯量和自由落体时间。取训练过程中的 $8$ 个 checkpoint，让两个模拟器各自排序，算 Spearman 相关系数 $\rho$：

$$
\rho=\mathrm{Spearman}\bigl(\text{rank}_{\text{IsaacLab}},\;\text{rank}_{\text{MuJoCo}}\bigr).
$$

$\rho$ 高说明「在训练模拟器里更好」确实意味着「更可能迁移」。$\rho<0.5$ 时结论很不舒服但很重要：你无法用训练模拟器的分数来挑 checkpoint。

**阶段 4（选做）：真机观测对齐。** 人形需要吊架或安全绳、急停回路和两人以上在场；没有条件以阶段 3 为终点。能做的读者从最便宜的一步开始：不部署策略，只回放一段固定关节位置序列，比较前 $2$ 秒的 $e_{\text{align}}(t)=\lVert q^{\text{real}}_t-q^{\text{sim}}_t\rVert_2$。若它在 $2$ 秒内就长到 $5^\circ$ 以上，说明动力学参数或延迟没对上，此时部署闭环策略只是在赌。

这条轨道至少报告：速度跟踪 RMSE（参考线 $\le 0.15\ \mathrm{m/s}$）、跌倒率（$1000$ episode 下 $\le 0.02$）、教师-学生差距、跨模拟器 $\rho$（参考线 $\ge 0.7$）。失败按类别归档：起步失稳、单侧滑移、踏空、上身负载前倾、指令切换跌倒、长时间姿态漂移。跌倒率 $0.02$ 在 $1000$ 个 episode 下的半宽约 $\pm 0.009$，这个精度只在仿真里拿得到；真机上 $30$ 次试验的区间宽到几乎不能比较大小，报告时必须写明 $n$。

## 验收标准

机械臂主轨道：

- [ ] 步骤 1 的开环回放曲线与质量惯量核对结果都已存档。
- [ ] 三档策略在同一预算、同一批初始位姿上对照，成功率均带 $n$ 与置信区间。
- [ ] 后果检查同时报告碰撞率与任务进展，没有只报安全的结论。
- [ ] 插接实验记录了刚度设置与峰值接触力，跨模拟器差异有明确数字。
- [ ] 失败按类别统计（未抓住 / 滑落 / 碰撞 / 超时 / 卡死），每类附至少一段视频。
- [ ] 若做了真机，明确写出标定流程、试验次数与漂移观察；若未做，明确写出以跨模拟器差异替代。

全身第二条轨道（选做，做了才勾）：

- [ ] 教师的特权通道消融已记录，证明特权信息确实被使用。
- [ ] 学生用在线 DAgger 训练，并与离线回归做过对照。
- [ ] 跨模拟器交叉验证同时报告跌倒率之差与 $8$ 个 checkpoint 的 $\rho$。
- [ ] 若做了真机，先给出开环观测对齐曲线，再谈闭环；若未做，明确以阶段 3 为终点。

## 本节小结

- 抓取到插接的容差差两个数量级，同一套策略跨不过去，需要接触力进入回路。
- 跨模拟器交叉验证是没有真机时最诚实的迁移代理指标。
- 教师-学生蒸馏之所以是全身迁移的标准做法，是因为可部署观察下的 RL 在预算内训不出来；蒸馏数据必须由学生自己生成，否则复合误差原封不动地回来。
- 跨模拟器的 checkpoint 排序相关系数，比单个成功率更能说明「训练分数能不能用来选模型」。
- 仿真通过不等于真机成功；任何成功率都必须带试验次数、置信区间和失败分类。
