# 7.10　扩散策略的从零开始实现

> **本节目标**：把一份示范数据写成标准格式，在同一数据、同一预算上训练三档策略——逐步 MSE、ACT 分块、扩散或流匹配——闭环对比，亲眼看到 MSE 把「左右绕行」平均成「撞墙」。

> **本节代码**：[robot.py](https://github.com/walkinglabs/hands-on-world-models/blob/main/src/hwm/robot.py) · [data.py](https://github.com/walkinglabs/hands-on-world-models/blob/main/src/hwm/data.py)；本节配套冒烟 Notebook：`notebooks/07_robot/from-demos-to-generative-policies.ipynb`（岔路口世界，三档对照，CPU 约两分钟跑完）

> **前置知识**：[7.1 机器人数据与异构观测](/chapters/07-robot-policy/01-multimodal-observation)（动作空间与数据格式）、[7.2 行为克隆与扩散策略](/chapters/07-robot-policy/04-behavior-cloning)（分块、扩散、流匹配）、[3.1 经历与转移](/chapters/03-data-and-first-model/01-episodes-and-transitions)。

---

这是 Hugging Face 机器人课的精华一格里我们最该补的：**数据 → 训练 → 部署的完整闭环**。前面的章节把每一步拆开讲过，这一节把它们装进同一条流水线，跑通，并且用对照实验回答一个问题：生成式策略多花的算力，到底买来了什么。

答案会以一种难忘的方式出现：桌上放一块障碍，专家示范里一半从左边绕、一半从右边绕。逐步 MSE 把两种正确平均成一种错误——直穿障碍。扩散策略每次 rollout 采样到其中一种。同一个数据集，同一预算，闭环成功率差出一截。这不是玄学，是回归目标的数学性质。

## 本次会得到什么

- 一个标准格式的数据集（LeRobotDataset），知道每个字段的含义和检查方法
- 三档策略在同一数据、同一预算下的对照表：离线 MSE、闭环成功率、碰撞率
- 一个双模态场景：亲眼看到 MSE 平均化，扩散覆盖两个模态
- 一份判断清单：什么时候该换 OpenVLA-7B / π₀ / GR00T 这样的真模型，什么时候是浪费
- 一条真机路径：SO-101 从遥操作采集到部署的完整流程与安全清单

## 环境与预算

两档运行方式，结论方向一致：

- **烟雾版（CPU，十分钟）**：用仓库自带的桌面世界（`hwm.robot`）生成示范，三档策略都是小网络。目的是检查数据流和复现平均化现象，不是刷指标。
- **完整版（单卡 24 GB）**：用 LeRobot 生态里的真实数据集与策略实现。BC/ACT/扩散策略的训练都在 $20$ 分钟到数小时量级；OpenVLA-7B 的 LoRA 微调约 $10$–$15$ 小时。

```bash
python -m pip install -r requirements-neural.txt
# 完整版另需：pip install lerobot（以其官方文档为准）
```

## 步骤 1：数据——写成 LeRobotDataset

两个来源选一个：

**A. 从 Hub 拉。** 新手推荐 `lerobot/pusht`（平面推 T 块，图像加状态，几千条示范）；有 SO-101 真机的可以用 `lerobot/svla-so101-pickplace`。一行加载：

```python
from lerobot.common.datasets.lerobot_dataset import LeRobotDataset
dataset = LeRobotDataset("lerobot/pusht")
```

**B. 自己采。** SO-101 主从臂遥操作采 $50$ 条抓取示范（`lerobot-record`），或用脚本化策略在仿真里生成。

不管哪个来源，入库前过一遍 [7.1](/chapters/07-robot-policy/01-multimodal-observation) 的检查清单：

- **动作空间是什么**：delta 末端位姿、绝对关节角、还是归一化到 $[-1,1]$ 的任意量？画出来看量纲。
- **时间基准是什么**：fps 多少，图像、状态、动作三路时间戳是否对齐（零阶保持）？
- **归一化统计**：均值方差存在哪，训练与部署用的是否同一份。

烟雾版用 `hwm.robot` 的岔路口生成器（`make_fork_dataset`）造 $128$ 条示范：起点在底部中央，障碍在正中，目标在左上/右上两角，专家各以 $50\%$ 概率绕一侧。字段是状态、动作、模式标签与 6 步动作序列——比完整版少了图像与指令两路，但「对齐、分块、双模态」三个关键结构都在。

## 步骤 2：同一数据上训三档策略

固定参数量级、训练步数、评测初始状态，只换动作头：

| 档位 | 策略           | 关键超参                             | 它代表什么               |
| ---- | -------------- | ------------------------------------ | ------------------------ |
| A    | 逐步 MSE（BC） | 单步回归                             | 7.2 的最小基线           |
| B    | ACT 分块       | chunk $K=16$，时间集成               | 用一小段动作对抗复合误差 |
| C    | 扩散或流匹配   | DDPM/DDIM 采样步数，或 flow matching | 把动作当分布来建模       |

三档都必须报两个数：**离线动作 MSE** 和**闭环成功率**。[7.3 动手入口](/chapters/07-robot-policy/07-vla-rtx) 的 Tiny VLA 烟雾实验已经演示过这两者可以背离——离线 MSE 最低的策略，闭环不一定最好。如果三档的离线 MSE 排序和闭环成功率排序完全一致，说明你的任务太简单，进入步骤 3 之前先把任务调难。

## 步骤 3：闭环对比——让 MSE 当众撞墙

构造双模态场景：桌子正中间一块障碍，目标在正后方。生成专家示范时，以 $50\%$ 概率从左侧绕、$50\%$ 从右侧绕，其余全部相同。

三档策略各跑同一批 $n \geq 50$ 个初始状态，记录：

- **成功率**与**碰撞率**（带置信区间，统计学见 [7.5](/chapters/08-robot-sim/07-sim2real-concise)）
- **模式覆盖率**：成功的轨迹里，左绕和右绕各占多少

预期方向：A 档（MSE）在障碍正前方的初始位置上大量撞墙——它学到的是「左绕和右绕的平均」，即直穿；C 档每次 rollout 采样到一个模态，两档模式覆盖率形成对照。B 档介于中间：分块减少了复合误差，但 chunk 内部仍是回归，模态混合的 chunk 照样存在。

这就是 Diffusion Policy 论文在 $12$ 个任务上平均超出此前最好方法 $46.9\%$ 的微观机制：**回归目标对多模态动作取均值，生成式目标对多模态动作取采样**。你在自己的桌子上复现了它。

## 步骤 4（进阶）：换成真模型——OpenVLA-7B、π₀、GR00T

小网络跑通闭环后，才谈得上换大模型。三台的换法与代价：

| 模型           | 规模与结构                                                                  | 24 GB 上的可行做法                            | 什么时候值得换                  |
| -------------- | --------------------------------------------------------------------------- | --------------------------------------------- | ------------------------------- |
| **OpenVLA-7B** | Prismatic VLM + 动作 token 离散化                                           | 4-bit 量化加载 + LoRA（$r=32$），官方微调脚本 | 需要开放词汇指令、要吃 web 先验 |
| **π₀**         | PaliGemma 3B 骨干 + 3 亿参数 flow matching 动作专家，$50\ \mathrm{Hz}$ 输出 | LoRA 微调；全量微调超出单卡预算               | 需要高频连续动作、灵巧任务      |
| **GR00T N**    | 人形通用策略，Isaac Lab 生态                                                | 以其官方基准与部署脚本为准                    | 人形本体、跨本体迁移            |

换大模型之前先过判断清单，三条全中才换：

1. 小模型在**分布内**闭环成功率已经封顶（不是数据问题、不是对齐问题）；
2. 指令超出了训练词汇表，或需要指令里出现训练时没有的物体类别；
3. 要跨本体迁移，小模型没有可迁移的表示。

只中一条，优先回去修数据。大模型买不来对齐错了的动作空间。

## 步骤 5（进阶）：真机路径——SO-101 从采集到部署

有硬件时，把同一闭环搬到真机：

1. **采集**：SO-101 主从臂遥操作 $50$ 条，任务选一个（抓取放置即可），`lerobot-record` 直接写成 LeRobotDataset。
2. **训练**：步骤 2 的三档任选，真机数据量下 ACT 与扩散的差距会比仿真里更明显。
3. **部署**：`lerobot-eval` 或自写循环，策略推理放本地 GPU，控制频率与采集时一致。部署不是把 checkpoint 往机器人上一丢就完事——有两道手艺必须做：**延迟补偿**和**轨迹平滑**。

### 延迟补偿：机器人执行的是"过去"的动作

从相机拍到画面、GPU 算出动作、发给电机、电机走到位，这一圈要 $30$–$80\ \mathrm{ms}$。如果控制频率是 $50\ \mathrm{Hz}$（周期 $20\ \mathrm{ms}$），机器人执行的是 $2$–$4$ 步以前算出的动作。策略以为自己在控制"现在"，其实在控制"过去"。

三种补偿办法，从便宜到贵：

1. **动作分块补偿**（最便宜）：ACT/扩散策略本来就一次输出 $K$ 步动作。把前 $d$ 步丢掉（对应延迟），从第 $d+1$ 步开始执行。等于"提前算好未来要做的，等延迟过去再执行"。7.2 的 action chunking 不只是抗复合误差，也是延迟补偿。
2. **状态预测**（中等）：训练一个小模型，从当前观察预测 $d$ 步后的状态，把预测状态喂给策略。策略以为自己在"现在"决策，其实喂进去的是"未来"。
3. **RTC 异步流水线**（最贵，LeRobot 的做法）：一边算下一批动作，一边执行上一批，重叠部分做 inpainting 式引导。延迟被流水线藏起来，代价是实现复杂、要调 `execution_horizon` 和 `max_guidance_weight`。

[7.5](/chapters/08-robot-sim/07-sim2real-concise) 讲的是「仿真里怎么建模延迟」——训练时加延迟让策略见过它。这里讲的是「部署时怎么补偿延迟」——推理时怎么把延迟的影响消掉。两件事都要做：训练时见过，部署时补偿。

### 轨迹平滑：零阶保持会让机器人抖

策略每 $20\ \mathrm{ms}$ 输出一个动作，电机收到后保持不动直到下一个——这叫**零阶保持**。问题是策略输出有量化噪声：相邻两步的动作可能差很多，电机就在两个位置之间来回跳，机器人看起来在抖。

三种平滑办法：

1. **指数移动平均**（EMA，最便宜）：$\tilde a_t = \alpha\, a_t + (1-\alpha)\,\tilde a_{t-1}$。$\alpha$ 越小越平滑、越滞后。代价是动作变迟钝，抓快东西会慢半拍。
2. **B 样条插值**（中等）：把离散动作点用三次 B 样条连成连续曲线，电机跟曲线走而不是跟离散点走。平滑且不滞后太多，代价是要算插值。
3. **动作分块本身就是平滑**（免费）：ACT/扩散一次输出 $K$ 步，天然是一段连续轨迹，比逐步 MSE 的跳变小得多。这是 7.6 三档对照里 ACT 档「看起来更顺」的原因。

平滑和延迟补偿会打架：EMA 平滑引入滞后，滞后加在延迟上更糟。所以常见做法是先补偿延迟（用分块或预测把动作提前），再在补偿后的轨迹上做轻度平滑。顺序反了，越平越迟。

安全清单（逐条打勾，不打勾不上电）：

- [ ] 急停在一只手之内，且真的按过一次确认有效
- [ ] 工作空间边界已用低速点动验证过
- [ ] 首次部署速度限制到正常的 $20\%$ 以下
- [ ] 相机视角、标定、坐标系与采集时完全一致

真机报告规范沿用 [7.5](/chapters/08-robot-sim/07-sim2real-concise)：$n \geq 20$ 次试验、置信区间、失败分类（未抓住 / 滑落 / 碰撞 / 超时）、每类失败一段视频。$20$ 次试验的半宽约 $\pm 0.20$——只报一个均值不构成证据。

## 部署不是终点：纠错回流

第一次部署的成功率通常难看。HF 体系最值得整条搬来的设计在这里：rollout 时人随时可以接管纠正（`lerobot-rollout` 的 dagger 模式；HIL-SERL 的介入，见 [7.5](/chapters/08-robot-sim/07-sim2real-concise)），**纠错轨迹回流数据集，再训一轮**。

```text
部署 → 失败时人工接管 → 纠错轨迹入库 → 再训练 → 再部署
```

每轮记录**介入率**（人工接管的步数占比）。学习正在发生的证据不是 reward 曲线，而是介入率随轮次单调下降。做两轮以上回流，把每轮的介入率与成功率并排报告——这就是 DAgger 在真机上的样子，也是 7.2 那个复合误差问题的工程解法。

## 失败分析

| 症状                         | 可能原因                                 | 处理                           |
| ---------------------------- | ---------------------------------------- | ------------------------------ |
| 三档策略闭环一样差           | 数据对齐错了（时间戳、动作空间）         | 回步骤 1，开环回放一条示范     |
| MSE 档离线误差最低、闭环最差 | 复合误差，正常现象                       | 写进报告，这正是本节的对照     |
| 扩散档也撞墙                 | 采样步数太少，或数据里模态比例不是 50/50 | 画训练数据的动作分布           |
| 双模态场景里三档都不撞       | 障碍太窄，直穿本来就安全                 | 加宽障碍，让直穿必撞           |
| 换了 OpenVLA 反而更差        | 动作分词与本体不匹配，或 LoRA 欠训       | 先查动作反归一化，再查训练曲线 |

## 验收标准

- [ ] 数据集是标准 LeRobotDataset 格式，动作空间、fps、归一化统计三项检查留档。
- [ ] 三档策略同一数据、同一预算、同一批初始状态对照，闭环指标带 $n$ 与置信区间。
- [ ] 双模态场景复现平均化：MSE 档的撞墙轨迹与扩散档的模式覆盖率都有图。
- [ ] 离线 MSE 与闭环成功率的排序差异被明确写出，而不是只报其中一个。
- [ ] 若做了步骤 4/5，判断清单逐条作答；真机报告含失败分类与视频。
- [ ] 若做了纠错回流，介入率随轮次下降有曲线，且每轮成功率并排报告。

## 本节小结

- **数据 → 训练 → 部署是一条闭环**：LeRobotDataset 是入口，闭环成功率是出口，中间的离线指标只是参考。
- **MSE 把多模态平均掉**是可以亲手复现的现象，不是论文里的修辞：同一数据上，回归撞墙，生成采样。
- **换大模型是判断题不是升级瘾**：OpenVLA-7B、π₀、GR00T 各有一张入场券，三条清单全中才值得花那张显卡。
- **真机是统计学问题**：$n$、置信区间、失败分类，一个都不能少。
