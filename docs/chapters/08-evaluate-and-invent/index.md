# 第 7 章　评价与研究设计

训练损失下降，只说明模型越来越符合训练目标。本章检查目标是否合理、预测是否帮助任务，以及稳定失败能否指出下一台模型的设计。

世界模型不能只看一步误差。一步准不代表多步不漂移，预测变好不代表任务变好，跑通 smoke 不等于 24GB 已验证。本章把这几件事一条条拆开。
