# 8.4　从稳定失败设计下一台模型

PA1-A 的模型在物体被遮挡三步以后反复丢失位置。一次偶然失败不能支持新方法；多个固定 seed、相同条件下重复出现的失败，才构成研究起点。

## 先写两种解释

例如：

```text
解释 A：记忆太短，遮挡前的信息已经丢失
解释 B：状态没有显式区分对象，多个物体被混在一起
```

两种解释会提出不同改动：增加 recurrent memory，或加入 object-centric state。

## 只选择一个最小改动

同时换 Encoder、数据、损失和 Planner，成绩提高后无法判断原因。PA2 只改一个关键条件，其他训练预算与评价保持相同。

## 设计能够推翻自己的实验

如果解释 A 正确，增加历史长度应主要改善长遮挡；若短遮挡和多物体条件仍失败，证据更支持解释 B。

研究设计需要提前写出：什么结果支持解释，什么结果会让我们放弃它。

## 三个继续追问的入口

第一，补证据。视觉判断不了接触，就加入触觉；单视角误判遮挡，就加入多视角。

第二，改状态。比较像素、latent、对象与空间状态，检查每种表示保留和丢掉什么。

第三，主动接现实。模型不确定时选择一个安全、又能区分几种解释的动作，再用真实结果更新。

## PA2 的六个问题

1. 现有模型在什么条件下稳定失败？
2. 为什么不是偶然坏样例？
3. 至少两种可能解释是什么？
4. 最小改动的输入、输出和训练信号是什么？
5. 更简单的替代方案是什么？
6. 哪个结果会证明新设计没有用？

## 小结

- [ ] 新设计从可复现失败开始，不从模型名称开始。
- [ ] 至少保留两种竞争解释，并只做一个最小改动。
- [ ] 实验要能推翻自己的解释。
- [ ] 负结果若对照公平，同样完成了一次有效研究循环。
