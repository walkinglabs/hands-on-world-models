# 7.1　从简单基线到多步评价

世界模型的一步误差低于 0.01，看起来已经很好。但如果画面大部分静止，复制上一帧也可能得到相近结果。

评价从简单基线开始，才能知道复杂模型究竟增加了什么。

## 每条路线的最低基线

- 动态预测：复制上一状态、线性外推；
- 决策：无模型 Policy、短 horizon 规则；
- 视频：复制上一帧、无动作模型；
- JEPA：常数表示、随机 Encoder；
- VLA：state-only BC、直接执行；
- 空间：恒空 Occupancy、静态场景。

基线使用相同 split、数据量和评价代码。更大模型若只比弱基线，不足以说明设计有效。

## Horizon 曲线

one-step 每次从真实状态预测下一步；open-loop 只在起点读取真实状态，之后使用模型自己的输出。

```text
horizon: 1, 5, 10, 30, 100
metric:  error / success / IoU / action consistency
```

画出随 horizon 变化的曲线，比只报告一个终点数字更容易看出模型从何时开始漂移。

## 下游使用

世界模型的最终使用者可能是 Planner、Actor、人、机器人或渲染器。评价要包含相应结果：真实 return、任务成功率、动作一致性、碰撞或新视角质量。

预测指标变好而任务不变，说明新增信息没有被使用，或优化了与任务无关的部分。

## 公平预算

对照固定数据 split、随机种子集合、训练 updates 和输入分辨率。若算力不同，要同时报告 wall time、峰值显存和推理延迟。

## 小结

- [ ] 复杂模型先与复制、线性和无模型等简单基线比较。
- [ ] one-step 与 open-loop multi-step 回答不同问题。
- [ ] 最终要检查预测是否改善了实际使用者的任务。
