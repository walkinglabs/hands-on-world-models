# 1.7　经验回放与第一个模型

前面六节把零件摆上了桌：张量、编码器、记忆、压缩、空间、决策。还缺最后一件——**一段经历怎样变成可以学习的数据，数据又怎样变成第一台世界模型**。

这一节只建立四个判断。逐步跟做、真实输出和配图，在独立实验页 [2.4 动手：第一台可学习世界模型](/chapters/02-data-and-first-model/04-learn-a-table-world)。

世界模型不能只靠一堆互不相关的图片训练。它必须知道每一个动作落在哪两帧之间。

## Episode：一次经历的最小容器

1.1 节的 shape 约定，课程里写成：

```python
Episode(
    observations,   # [T + 1, ...]
    actions,        # [T, ...]
    rewards,        # [T]
    dones,          # [T]
)
```

`Episode.validate` 查四件事：至少两帧、动作数是观察数减一、reward / done 与动作等长、`dones[:-1]` 必须全假。最后一条最容易写错：`done=True` 之后环境已经重置，下一条记录不能再接在同一段里。

PixelWorld 默认 8 步，所以观察是 9 帧。机器人数据还要额外对齐语言、关节和控制频率。

## 回放缓冲区：只在段内取样

许多段放进同一个池子，训练时从里面取窗口。episode A 结束、episode B 从新的随机状态开始——若先首尾相接再切，模型会学到一条不存在的转移 \(o^{(A)}_T \to o^{(B)}_0\)。

正确顺序：先选一段足够长的 episode，再在它内部切连续片段。`ReplayBuffer.sample` 让观察比动作多取一帧，保证 \(a_t\) 仍夹在 \(o_t\) 和 \(o_{t+1}\) 之间。

## 数据切分：按段，不按帧

相邻两帧几乎相同。按帧随机划 train / val / test，一步准确率会被抬虚。`split_by_episode` 用比例整组切开：12 段、0.70 / 0.15，得到 8 / 2 / 2。旧讲义里的「200 段划成 140 / 30 / 30」对不上源码。

按段切开防的是轨迹泄漏，不是规律泄漏。确定性格子里，同一条 \((s,a,s')\) 仍可能同时出现在 train 和 test。

## 第一台模型不必有梯度

2.4 的世界是一条长度为 7 的线，20% 打滑。对每个 \((s,a)\) 计数再归一化：

$$
\hat{P}(s'\mid s,a)=\frac{n(s,a,s')}{\sum_{s''}n(s,a,s'')}.
$$

140 段从格子 3 向左大约是 \(0.79 / 0.21\)，不是整数 \(0.80 / 0.20\)。按段切开后一步准确率约 \(0.83\)——世界本身在掷骰子。未见过的键停在原地：未知不是随机猜，是承认没见过。

固定起点只换动作，两个分布必须不同。然后 MPC 只执行第一步：打滑了就对着真实位置再搜。一步准确率到不了 1，不妨碍走到终点。

这些数字和逐步代码，都在实验页里。

## 小结

- [ ] 回放缓冲区在同一 episode 内采样连续片段，不跨段拼接。
- [ ] train / val / test 按段切；源码用比例，不是固定的 140 / 30 / 30。
- [ ] \(\hat P(s'\mid s,a)=n(s,a,s')/n(s,a)\) 就是第一台可学习世界模型。
- [ ] 有限计数不会恰好等于 0.20 / 0.80；一步准确率到不了 1，不妨碍 MPC 走到终点。
- [ ] PA0 用多步、反事实和任务成功率检查模型，而不只看训练误差。
