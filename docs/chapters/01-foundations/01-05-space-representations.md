# 1.5　从相机到 BEV 与 Occupancy

相机向右移动时，图片里的静态物体会整体向左移动。只看像素变化，模型可能误以为整个房间都在移动。

要把不同视角放进同一个世界，我们需要知道相机怎样成像，以及它位于哪里。

## 内参与外参

相机内参描述焦距和成像中心。已知像素 `(u,v)` 的深度 `z`，可以把它反投影到相机坐标：

```text
x = (u - cx) * z / fx
y = (v - cy) * z / fy
```

外参描述相机相对世界的旋转与平移。两台相机看到的同一个杯子，转换到世界坐标后应落在相近位置。

## Point Cloud

许多反投影点组成点云。点云记录测到的物体表面，但没有点的地方可能是空地、未知区域或被遮挡区域，三者不能直接等同。

## BEV

鸟瞰图（BEV）从上往下整理道路、车辆和可通行区域。驾驶规划关心车辆在地面坐标中的相对位置，BEV 比透视图片更容易与路径和碰撞对齐。

Lift-Splat-Shoot 先为图像特征估计深度，把特征 Lift 到三维，再 Splat 到 BEV 网格。名称描述的就是数据流。

## Occupancy

占用网格把空间切成小格，记录每格是占用、空闲还是未知。它适合碰撞检查，也可以预测未来几帧的空间变化。

类别通常极不均衡，大部分格子为空。只报告 accuracy 会让“全部预测为空”的模型看起来很好，因此还要看 IoU、类别召回和时间一致性。

## NeRF、3DGS 与 Mesh 在哪里

NeRF 与 3DGS 更强调从新视角渲染场景，Mesh 则便于编辑和碰撞。它们与 BEV、Occupancy 保留的信息不同，第 7 章会详细比较。

## 小结

- [ ] 内参描述怎样成像，外参描述相机位于哪里。
- [ ] 点云保存测到的表面，BEV 整理地面布局，Occupancy 表示空间占用。
- [ ] 能渲染新视角不自动等于能做碰撞与规划。
