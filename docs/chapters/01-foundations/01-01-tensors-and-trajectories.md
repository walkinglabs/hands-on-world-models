# 1.1　张量、时间与轨迹

一张 `16×16` 的彩色图片可以写成 `[16,16,3]`。这里三个数字分别表示高、宽和颜色通道。

十六段各有 20 帧的视频，可以写成：

```text
[B,T,H,W,C] = [16,20,16,16,3]
```

`B` 表示并排计算多少段样本，`T` 表示时间。张量可以先理解成装有许多数字的多维盒子，shape 则说明每一维的长度。

## 维度名称比大小更重要

`[32,10,5]` 既可能表示 32 段轨迹、每段 10 步、每步 5 个状态量，也可能表示别的对象。数据卡需要同时写出长度和语义。

PyTorch 图像通常采用 `[B,C,H,W]`，视频模型也常采用 `[B,T,C,H,W]`。从 NumPy 的 `[B,T,H,W,C]` 转换时，需要显式交换维度。

```python
video = video.permute(0, 1, 4, 2, 3)
```

## `T+1` 个观察对应 `T` 个动作

四张连续图片之间只有三个动作：

```text
o0 --a0--> o1 --a1--> o2 --a2--> o3
```

因此一段 episode 的基本 shape 是：

```text
observations: [T + 1, ...]
actions:      [T, ...]
rewards:      [T]
dones:        [T]
```

`a0` 发生在 `o0` 和 `o1` 之间。如果把动作整体错开一格，模型仍可能依靠惯性预测下一帧，却无法回答换动作后的未来。

## Episode 与 transition

一条 transition 保存一次变化：

```text
(o_t, a_t, r_t, o_{t+1}, d_t)
```

许多连续 transition 组成 episode。`done=True` 以后，下一条记录不能接到另一个随机起点，否则模型会把环境重置当成普通动态。

不同长度的 episode 可以从内部采样固定长度片段，也可以 padding 后使用 mask。本课程优先采用前者，把注意力放在动态本身。

## 时间信息不能省略

同样移动 5 厘米，用时 0.1 秒和 1 秒代表不同速度。动作数据至少记录：观察时间戳、动作时间戳、控制频率、观察频率和执行延迟。

机器人与驾驶数据还可能存在动作重复、跳帧和控制器内部延迟。这些字段错了，换网络无法补救。

## 小结

- [ ] shape 需要同时标出长度与每一维的含义。
- [ ] `T+1` 个观察对应 `T` 个动作。
- [ ] transition 是一次变化，episode 是不跨重置的连续经历。
- [ ] 动作条件学习首先要求正确的时间对齐。
