# 1.3　RNN、Transformer 与 RSSM：把过去带到现在

两段视频的最后一帧完全相同：红方块都位于画面中央。第一段中方块从左边来到中央，第二段中方块从右边来到中央。

只看末帧，下一步方向无法判断。模型需要让历史参与当前状态。

## RNN 与 GRU

循环神经网络（RNN）每一步更新一份记忆：

```text
h_t = update(h_{t-1}, x_t)
```

`x_t` 是当前输入，`h_{t-1}` 是过去留下的记忆。GRU 使用门控决定保留多少旧信息、写入多少新信息，通常比简单 RNN 更容易训练长序列。

如果 GRU 只读观察，它只是记忆器。要预测动作后果，还要把动作放入更新：

```text
h_t = GRU(h_{t-1}, concat(z_{t-1}, a_{t-1}))
```

## 因果 Transformer

Transformer 可以同时处理一段 token。预测下一步时必须使用因果遮罩：第 `t` 步只能看到 `0...t`，不能看到未来答案。

它适合图像 token、动作 token 和语言 token 组成的长序列。推理时使用 KV Cache 保存已经计算过的历史，避免每一步从头计算。

## 确定记忆仍然不够

一辆车进入隧道后暂时不可见。根据速度，我们能估计大致位置，但真实位置可能有多种。

如果内部状态只有一个确定向量，多种可能容易被压成平均结果。世界模型需要同时保留长期记忆和当前不确定性。

## RSSM 的两部分状态

循环状态空间模型（RSSM）把状态分成：

```text
h_t：确定状态，由 GRU 更新，保存长期线索
z_t：随机状态，描述当前仍不确定的部分
```

训练时，posterior 根据当前观察推断 `z_t`；想象未来时，prior 只根据历史状态和动作预测 `z_t` 的分布。

两者通过 KL 损失靠近。若 KL 压力过强，模型可能完全忽略随机状态；Free Bits 为一小段 KL 留出空间，减轻这种坍缩。

## 三种工具的边界

RNN/GRU 强调逐步更新记忆；因果 Transformer 强调 token 历史；RSSM 进一步显式区分确定记忆与随机状态。

它们都不是单独完整的世界模型。完整系统还需要动作条件转移、预测目标、数据和使用预测的程序。

## 小结

- [ ] 历史用于区分末帧相同、运动趋势不同的情况。
- [ ] GRU 逐步更新记忆，因果 Transformer 只允许查看过去 token。
- [ ] RSSM 用确定状态保存线索，用随机状态表达不确定性。
