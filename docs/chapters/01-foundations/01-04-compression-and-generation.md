# 1.4　VAE、VQ-VAE 与 Diffusion：压缩和生成

把每个 `4×4` 图像区域取平均，一张 `16×16×3` 图片会缩成 `4×4×3`。数字量减少 16 倍，方块大致还在，清楚边缘却消失了。

所有压缩表示都面对同一取舍：状态越短，预测越便宜；丢掉的信息也可能越多。

## AE 与 VAE：连续 latent

自动编码器（AE）由 Encoder 和 Decoder 组成：

```text
图片 → Encoder → latent → Decoder → 重建图片
```

变分自动编码器（VAE）不只输出一个点，还输出 latent 分布的参数，并用 KL 损失让分布接近简单先验。这样更容易采样和插值。

Dreamer 可以使用连续或离散随机状态。重建帮助 latent 保留观察信息，但最终仍要检查 latent 是否支持 reward、value 与行动。

## VQ-VAE：离散 token

VQ-VAE 准备一张有限码本。Encoder 产生连续向量后，选取最接近的码本项，用整数编号表示局部画面。

```text
图像区域 → 连续向量 → 最近码本项 → token id
```

一帧图片由此变成 token 序列，可以交给 Transformer 自回归预测。

选择最近码本项不可微。直通估计器（STE）在前向使用离散结果，反向近似传递梯度。它解决训练路径，不负责提升生成质量。

## Diffusion：从噪声采样一种未来

同一历史可能有多种合理未来。若用均方误差回归像素平均值，结果容易模糊。

Diffusion 从噪声开始，经过若干步去噪得到一个样本。改变噪声，可以为同一条件产生不同结果。代价是每帧要运行多次网络，交互延迟通常高于一次自回归前向。

## 三条路线保留的信息不同

- 连续 latent 便于平滑优化和状态转移；
- 离散 token 便于使用语言模型式序列预测；
- Diffusion 适合表示丰富、多模态的视觉或动作分布。

JEPA 更进一步：它不要求解码完整像素，只预测目标特征。第 5 章会单独研究这种选择。

## 怎样检查压缩没有丢掉关键内容

除了重建误差，还应查看小物体、位置、速度和动作后果是否可恢复。若任务依赖碰撞，而 latent 丢掉了杯沿或障碍物，漂亮背景不能弥补这一缺口。

## 小结

- [ ] VAE 使用连续随机 latent，VQ-VAE 使用有限码本和离散 token。
- [ ] STE 让离散量化路径可以近似训练。
- [ ] Diffusion 用多步去噪采样多种未来，通常付出更高延迟。
- [ ] 压缩质量要由任务需要的信息来判断。
