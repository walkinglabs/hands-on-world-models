# 1.7　经验回放与第一个模型

前面几节凑齐了组件，本节把它们真正接到一起：把连续经历整理成模型能学的数据，再从数据里学出第一台世界模型。这一节只看整条管线的轮廓；每一步的展开、边界情况和实验，都留给第 2 章。

世界模型不能只靠一堆互不相关的图片训练，它必须知道每一个动作落在哪两帧之间。

## Episode 怎样保存

课程使用的最小容器，正好对应 1.1 节的 shape 约定：

```python
Episode(
    observations=[T + 1, ...],   # 比 actions 多一帧
    actions=[T, ...],
    rewards=[T],
    dones=[T],
)
```

一个验证函数会检查四件事：长度是否对齐、`dones` 的位置是否合理、动作数是否正好比观察少一、时间戳是否单调。对机器人数据，还要额外保存语言指令、关节状态、控制频率和执行延迟。

## 回放缓冲区：不能跨 episode 拼接

episode A 结束之后，episode B 从一个全新的随机状态开始。如果先把两段数组首尾相接，再截取序列，模型就可能学到一条不存在的转移：“从 A 的终点，经过一个动作，瞬间来到 B 的起点。”

正确顺序是先选定一段足够长的 episode，再从其内部截取连续片段。所谓**回放缓冲区**（replay buffer），就是按 episode 组织、支持这种“段内采样”的数据结构。

## 数据切分：不能随机拆帧

相邻两帧视频往往几乎完全相同。如果按帧随机划分 train/val/test，训练帧的近邻就会漏进测试集，得到虚高的一步准确率。

正确做法是按 episode、scene、seed 或 task template 整组切分。例如 F3 收集 200 条 episode，按 id 划成 140 / 30 / 30：

```text
train : episode 0–139
val   : episode 140–169
test  : episode 170–199
```

三组 id 互不重叠。动作条件任务还要额外检查：测试集里是否出现了训练从未覆盖过的动作区域。

## 从计数学出概率转移

在一维 LineWorld 中，机器人可以 left 或 right，环境带 20% 打滑——动作有 $80\%$ 概率按预期移动、$20\%$ 概率原地不动。我们不告诉模型这条规则，只让它统计训练数据。

对每个 $(s,a)$，统计后续出现的下一状态频次，再归一化就得到一张**概率转移表**：

$$
\hat{P}(s'\mid s,a)=\frac{\#\,(s,a,s')}{\#\,(s,a)}.
$$

有限数据不会恰好得到 $0.2$ 与 $0.8$；但样本越多，经验频率通常会越接近真实的环境概率。这台模型不使用任何梯度，却已经具备四项能力：保留多种可能结果、标出未见过的 $(s,a)$、做多步 rollout、被 MPC 调用选择动作。

## 反事实与闭环检查

固定同一起点和随机种子，只换动作。读出的两个分布 $\hat{P}(\cdot\mid s,\text{left})$ 与 $\hat{P}(\cdot\mid s,\text{right})$ 应当不同——这说明模型确实读取了动作，而不是把所有动作当一回事。

随后把规划器选出的第一步放回真实 LineWorld，保存新的 transition，更新计数表，再次规划。这就是课程的第一次“数据—模型—行动—现实修正”循环：

$$
\text{收集数据}\;\to\;\text{学模型}\;\to\;\text{规划}\;\to\;\text{执行一步}\;\to\;\text{新数据回写}.
$$

一步准确率和闭环成功率不是同一回事：打滑本就带来随机，最可能结果的一步准确率到不了 $1$，但只要模型对动作敏感、多步 rollout 合理，规划仍可能稳定到达终点。

## PA0 交出什么

PA0 会换一张新地图，并且不提供完整模型结构。提交内容应包括：接口图、数据卡、简单基线、一步与多步结果、动作反事实、下游成功率，以及一组失败案例。

如果表格方法已经解决了任务，继续换上神经网络不会加分。只有当图像、历史、不确定性或动作空间确实让表格失效时，才该进入后续路线。先找到失效点，再决定加什么——这是本课程反复强调的工作方式。

## 小结

- [ ] 回放缓冲区在同一 episode 内采样连续片段，不跨 episode 拼接。
- [ ] train/val/test 按 episode 或场景整组切分，不随机拆相邻帧。
- [ ] 用 $\hat{P}(s'\mid s,a)=\#(s,a,s')/\#(s,a)$ 得到的计数表，就是第一台可学习世界模型。
- [ ] PA0 用多步 rollout、动作反事实和任务成功率检查模型，而不只看训练误差。
