# 1.2　CNN 与 ViT：把图片变成特征

一张 `64×64×3` 图片包含 12288 个数。若为每一种图片建立转移表，状态数量很快就无法列举。

我们需要把图片变成较短的特征，同时保留物体位置、形状和运动所需的信息。

## CNN：同一个小窗口到处检查

考虑一个左半边为 0、右半边为 1 的灰度图。下面的 `3×3` 小窗口对右边给正权重，对左边给负权重：

```text
-1  0  1
-1  0  1
-1  0  1
```

窗口跨过明暗边界时输出较大。卷积神经网络（CNN）会从数据中学习许多这样的 kernel：浅层寻找边缘和纹理，后续层把局部结果组合成较大形状。

```text
输入：[B,C,H,W]
输出：[B,C',H',W']
```

CNN 在小图像上计算便宜，局部结构明确。Dreamer 常用 CNN 编码画面，机器人模型也常用它提取视觉特征。

## ViT：把图片切成 patch

另一种办法是把图片切成许多小块。一张 `16×16×3` 图片使用 `4×4` patch，会得到 16 个 patch，每个 patch 含 48 个数。

```text
[16,16,3] → 16 个 [4,4,3] patch → 16 个 token
```

视觉 Transformer（ViT）让这些 token 互相交换信息。远处两个区域可以直接建立联系，也方便把视觉 token 与语言 token 放在同一序列中。

## 为什么还需要位置编码

图片切成序列以后，模型只看到一组向量，不自动知道哪个 patch 位于左上角。位置编码把空间位置加到内容特征中。

视频还需要时间位置。JEPA 的 tubelet、互动视频的 token 预测和 VLA 的图文融合都依赖这一点。

## CNN 与 ViT 怎样选择

小图片、局部模式明显、计算预算较紧时，CNN 通常更简单。需要遮挡预测、长距离关系或语言融合时，token 接口更方便。

二者也可以组合。例如 CNN 先降低分辨率，再把特征图切成 token。选择依据是数据、任务和接口，不是模型阵营。

## 编码器保留了什么

分类模型可能只保留物体类别。世界模型还要预测位置、速度和动作后果，因此编码器不能随意丢掉这些信息。

最小检查包括：线性头能否读出位置与速度；替换动作后 latent 未来是否改变；多步 rollout 是否保留小物体。

## 小结

- [ ] CNN 复用局部窗口，适合提取局部视觉结构。
- [ ] ViT 把图片变成带位置的 patch token。
- [ ] 编码器是否合格，要由后续预测和任务检查，而不只看分类或重建。
