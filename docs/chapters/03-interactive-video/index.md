# 第 3 章　可交互视频世界

普通视频模型只负责生成「一种看起来合理的后来」。本章的要求更严格：固定同一个起点，只换一个按键，画面里的物体也要按相应方向变化。也就是说，生成的视频必须听从动作。

我们沿「数据 → 把画面变短 → 预测下一帧 → 换一条生成路线并评价」的顺序展开。先把 ViZDoom、CRAFTER 这类游戏的按键和帧接对，再用 VQ-VAE 把每帧压成离散 token 网格，然后让一个动作条件 Transformer 自回归地预测未来 token，最后把扩散模型作为另一条路线与之对照，并讨论多步漂移和实时性。
