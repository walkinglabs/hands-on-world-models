# 5.2　词元化与预测目标

一帧 `64×64×3` 的图片有 12288 个数。一秒 20 帧，十秒就是两百张图片。直接预测所有像素并非不可能，但学生应先问：这些数字是不是都值得原样保存？

视频模型通常在四种空间里工作。

| 表示        | 模型实际预测什么               | 好处                                 | 容易丢掉什么               |
| ----------- | ------------------------------ | ------------------------------------ | -------------------------- |
| 像素        | 每个位置的颜色                 | 接口直接，不依赖 tokenizer           | 计算量大，背景会淹没小物体 |
| 连续 latent | VAE 或视觉编码器产生的连续向量 | 比像素短，适合 Diffusion             | 解码器可能改变细节         |
| 离散 token  | 码本编号                       | 可像语言一样做 next-token prediction | 码本有限，细小物体可能消失 |
| 语义特征    | DINO、V-JEPA 一类特征          | 更关注物体和运动                     | 不一定能还原供人观看的画面 |

没有一种表示永远最好。玩家要看画面，就需要可解码表示；规划器只关心位置和碰撞时，语义特征可能更省；复杂相机运动若总让二维记忆失效，还要考虑第 8 章的 3D 表示。

## 离散路线：VQ-VAE

课程先实现离散路线，因为每一步都能看见：

```text
frame → Encoder → 连续特征 → 最近码字 → token 网格 → Decoder → frame
```

例如，一张 `64×64` 图片可以压成 `8×8` 个 token。Transformer 不再逐像素预测，而是预测 64 个码本编号。

最近邻选择没有普通梯度。直通估计器在前向使用选中的码字，在反向把 Decoder 的梯度近似送回 Encoder。训练同时包含重建、codebook 和 commitment loss。

这里最常见的失败是码本坍缩：很多码字从未使用。日志至少记录 token 使用数、使用分布和小物体重建。PixelWorld 的红色方块只占少量像素，一张全黑图也可能得到不高的平均 MSE，因此课程还会单独测红色物体中心。

现代 tokenizer 不只使用 VQ 码本。论文中还能看到 LFQ、FSQ 等不依赖传统码本查找的离散方式。它们属于阅读拔高；本章用 VQ-VAE 是因为 STE、码本利用率和离散预测可以在一份小实验里看清。

## 连续路线：VAE latent

Diffusion 模型常先用 VAE 把视频压成连续 latent，再在 latent 中去噪。它不必在有限码本中挑一个编号，因而更容易保留连续纹理；代价是每次生成通常需要多次网络计算。

连续 latent 也不自动优于离散 token。若小球在 VAE 重建时已经消失，后面的世界模型再强也无法把它找回来。所以 tokenizer 或 codec 要先单独验收，再训练动态。

## Diffusion 还要选择监督目标

给干净 latent `x` 加噪得到 `x_t` 后，网络可以学习不同目标：

- `x`：直接猜干净样本；
- `epsilon`：猜加入的噪声；
- `v`：把干净样本与噪声重新组合成较稳定的目标；
- flow：学习从噪声走向数据的速度场。

它们不是四种完全不同的世界模型，而是同一去噪过程的不同训练参数化。Nano World Model 的公开消融正是一次只替换这一轴。课程代码实现 `x / epsilon / v` 的 shape 和目标构造；PA 不要求把四种目标全部训练到收敛。

## 小结

- [ ] 先根据用途选择像素、连续 latent、离散 token 或语义特征，再选择生成网络。
- [ ] VQ-VAE 的重建质量、码本利用率和任务相关小物体要分开检查。
- [ ] Diffusion 的 `x / epsilon / v / flow` 是预测目标的选择，不等于四套应用方向。
- [ ] 本章必做离散 token，小型连续去噪用于理解和对照。
