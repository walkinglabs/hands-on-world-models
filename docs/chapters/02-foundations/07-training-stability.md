# 2.7　训练稳定性

同一份配方，在一个奖励量级为 $0.1$ 的控制任务上训得很稳；换到一个单步奖励能到 $10^3$ 的游戏上，价值头在几千步内发散成 NaN。网络没换，数据管线没换，只有数字的大小变了。

这类事故在普通监督学习里少见，因为那里的标签是固定的、量级是已知的。世界模型的训练同时违反了这两条：标签由模型自己产生，量级由环境决定。这一节把常见的失效模式和对应的稳定手段一条条对上。

## 目标在动：非平稳性从哪来

监督学习的数据集在训练期间不变，损失曲面也不变。世界模型的训练循环里有三处在动。

第一，**数据分布在漂移**。回放缓冲（replay buffer）里的经历由不断更新的策略产生。第 1 万步的策略只会在起点附近打转，第 10 万步的策略已经能走到远处，两批数据的状态分布几乎不重叠。模型在旧数据上收敛后，新数据一进来，损失就重新跳高。

第二，**回归目标由模型自己给出**。价值学习的目标 $y_t = r_t + \gamma V_\phi(s_{t+1})$ 里含有 $V_\phi$ 本身。这叫**自举**（bootstrapping）：参数一更新，目标跟着变，形成正反馈。若某个状态的价值被高估，它会抬高前一个状态的目标，后者再抬高更前一个，误差沿时间轴放大。

第三，**多个损失项在抢梯度**。重构、KL、奖励、价值、策略共享同一个编码器。它们的量级不同、收敛速度不同，某一项一旦爆掉，整个共享表示都被污染。

## EMA 目标网络：给自举一个慢变的参照

打断自举正反馈最直接的办法，是让目标里的 $V$ 用一份滞后的参数 $\phi^-$：

$$
\phi^- \leftarrow \tau\,\phi^- + (1-\tau)\,\phi,\qquad
y_t = r_t + \gamma\,V_{\phi^-}(s_{t+1}).
$$

这就是**指数滑动平均**（exponential moving average, EMA）目标网络。取 $\tau=0.98$，则 $\phi^-$ 大致是最近 $1/(1-\tau)=50$ 步参数的加权平均，单步更新对目标的影响被压到 $2\%$。目标不再随每个 minibatch 抖动，价值回归重新接近一个普通的监督问题。

代价是延迟：$\tau$ 太大，目标跟不上真实的价值改进，学习变慢；$\tau$ 太小，退化回原来的自举震荡。这是一个必须调的旋钮，不是一个免费的修补。

## KL 坍缩与 Free Bits

带随机潜变量的世界模型（如 RSSM）在损失里有一项 KL，把后验 $q(z_t\mid o_t,h_t)$ 往先验 $p(z_t\mid h_t)$ 拉。优化器很快会发现一个捷径：让后验完全等于先验，KL 降到 $0$，潜变量不再携带任何关于观察的信息。这就是 **KL 坍缩**（posterior collapse）——重构靠解码器硬记，动力学学了个寂寞。

**Free Bits**（自由比特）给 KL 设一个下界，只在超过阈值时才产生梯度：

$$
\mathcal{L}_{\mathrm{KL}} = \sum_{i=1}^{G}\max\bigl(\beta,\; \mathrm{KL}_i\bigr).
$$

$G$ 是潜变量的分组数，$\beta$ 通常取 $1$ nat。DreamerV3 用 $32$ 组 $\times\,32$ 类的离散潜变量，于是总 KL 在 $32$ nats 以下时梯度为零，编码器可以自由使用这些信息容量；只有想携带更多信息时才付出正则代价。若某组的 $\mathrm{KL}_i = 0.3$ nat，$\max(1,\,0.3)=1$ 是常数，梯度为 $0$，这一组就不会被继续压向先验。

## 尺度：Symlog 与 Twohot

奖励和回报的量级跨任务差几个数量级。想用同一组超参覆盖所有任务，就得先把量级抹平。**Symlog** 变换做的正是这件事：

$$
\mathrm{symlog}(x) = \mathrm{sign}(x)\,\ln\bigl(1+|x|\bigr),\qquad
\mathrm{symexp}(x) = \mathrm{sign}(x)\,\bigl(e^{|x|}-1\bigr).
$$

代入检查：$\mathrm{symlog}(1000)=\ln 1001 = 6.909$，$\mathrm{symlog}(1)=\ln 2=0.693$。原始的 $1000{:}1$ 被压成约 $10{:}1$。小值几乎不受影响，$\mathrm{symlog}(0.01)=\ln 1.01 = 0.00995$，接近恒等。反变换严格可逆：$\mathrm{symexp}(6.909)=e^{6.909}-1=1000$。与对数不同，symlog 在 $0$ 附近光滑且能处理负数，适合奖励这种可正可负的量。

压缩之后还有一层：直接回归 symlog 值仍然会被离群样本主导梯度。DreamerV3 改成**分类**——在 symlog 空间放一排等距 bin，把标量 $y$ 编码成只有相邻两格非零的 **Twohot** 目标：

$$
w_k = \frac{b_{k+1}-y}{b_{k+1}-b_k},\qquad w_{k+1} = \frac{y-b_k}{b_{k+1}-b_k},\qquad b_k \le y < b_{k+1}.
$$

取 bin $b_k=0.5,\,b_{k+1}=1.0$，$y=0.7$：$w_k=0.6$、$w_{k+1}=0.4$，期望 $0.5\times0.6+1.0\times0.4=0.7$，正好还原。损失换成交叉熵后，单个样本的梯度被 softmax 天然限幅，一个异常大的回报不会再把整个价值头拽跑。

## Unimix：不让概率真的等于零

离散潜变量与 Twohot 都要算 $-\ln p$。若 softmax 输出某一类的概率被压到 $10^{-8}$，而目标恰好落在这一类，损失就是 $18.4$，梯度相应巨大；再极端一点，概率下溢成 $0$，损失直接变成 $\infty$。

**Unimix** 把预测分布与均匀分布混合，给每一类一个概率地板：

$$
p = (1-\alpha)\,\hat{p} + \frac{\alpha}{K}.
$$

取 $\alpha=0.01$、$K=32$，最小概率是 $0.01/32=3.125\times10^{-4}$，于是 $-\ln p \le 8.07$ nats。损失有了硬上界，梯度也就有了硬上界。代价是分布永远无法真正确定——即使模型完全确信，它输出的最大概率也只有 $0.99+0.01/32 \approx 0.9903$。对世界模型来说这个偏差可以接受，换来的是不会炸。

## 梯度裁剪与混合精度里的数值陷阱

全局范数裁剪保留梯度方向、只限制长度：若阈值取 $100$ 而当前范数是 $10^4$，所有梯度乘以 $0.01$。它是最后一道防线，不是第一道——如果日志里裁剪触发率长期高于百分之几，说明真正的问题在上游（学习率、KL 项、奖励尺度），裁剪只是把症状藏起来。

混合精度另有两个坑。fp16 的最大可表示值是 $65504$，一个瞬时较大的 KL 或平方项就能溢出成 `inf`，随后污染全部参数；bf16 的指数范围与 fp32 相同，不易溢出，但尾数只有 $8$ 位，有效精度约 $3$ 位十进制。EMA 更新 $\phi^- \leftarrow \phi^- + 0.02(\phi-\phi^-)$ 里那个 $0.02$ 倍的增量，在 bf16 下可能因舍入被整个丢掉，表现为目标网络"冻住"。稳妥做法是前向用低精度，而优化器状态、EMA 参数、softmax 与 logsumexp 保持 fp32。

## 症状对照表

| 症状                                   | 可能原因                    | 对应手段                         |
| -------------------------------------- | --------------------------- | -------------------------------- |
| 价值损失单调上升、最终 NaN             | 自举正反馈 + 回报量级过大   | EMA 目标网络、symlog + twohot    |
| KL 迅速降到 0，潜变量与观察无关        | 后验坍缩                    | Free Bits 下界                   |
| 损失偶发尖峰、跟着出现 `inf`           | one-hot 概率下溢、fp16 溢出 | Unimix、softmax 用 fp32          |
| 换个任务就要重调学习率                 | 奖励与回报尺度依赖任务      | symlog 变换、回报归一化          |
| 训练曲线周期性跳高，与数据收集节奏同步 | 回放缓冲分布漂移            | 增大缓冲、混合新旧数据、降学习率 |
| 梯度裁剪触发率长期居高                 | 上游某一损失项主导          | 分项记录梯度范数，重新配权重     |

每一行的对应关系是单向的：手段能治它对应的病，不能治别的。把六种技巧一次全开却不看日志，等于放弃了定位问题的能力。

## 小结

- 世界模型训练的非平稳性有三个来源：回放数据漂移、自举目标、多损失竞争，普通监督学习的直觉在这里不适用。
- EMA 目标网络用滞后参数打断自举正反馈，Free Bits 用下界阻止 KL 坍缩，两者都以"学得慢一点"换稳定。
- Symlog 压量级、Twohot 把回归变分类、Unimix 给概率设地板，共同让一组超参覆盖量级差几个数量级的任务。
- 梯度裁剪与混合精度是防线不是解药；裁剪触发率和溢出计数应当当作诊断指标记录下来。
