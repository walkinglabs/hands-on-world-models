# 4.4　Diffusion、多步漂移与实时性

同一游戏状态可能因为粒子效果、对手策略或随机物理产生多种画面。自回归 token 模型倾向于逐个离散选择；Diffusion 可以从不同噪声采样多种连续未来。

## 条件 Diffusion

模型从噪声 latent 开始，多次去噪，同时读取历史画面和动作条件：

```text
noise + history + action → denoise step 1 → ... → future latent
```

DIAMOND、GameNGen 与 Oasis 等工作选择不同的像素或 latent 表示、去噪网络和上下文方式。课程只实现 tiny 对照，不复现工业规模视频质量。

## AR 与 Diffusion 的取舍

离散自回归模型每次生成 token，缓存后推理较直接；Diffusion 每帧要运行若干去噪步，视觉细节和多模态结果通常更强，延迟也更高。

公平对照要使用相同数据 split、更新预算和分辨率，同时报告质量与速度。

## 四组评价

1. 动作一致性：固定起点换动作，物体是否按预期改变；
2. 多步稳定：从第几步开始漂移、消失或冻结；
3. 视觉质量：边缘、小物体、文字与感知指标；
4. 实时性：每帧端到端延迟和峰值显存。

漂亮样例只能补充说明，不能替代统计结果和失败图集。

## Genie 类系统还多解决了什么

互联网视频通常没有动作标签。Genie 类路线尝试从视频中发现 latent action，再生成可交互环境。

latent action 是否对应人类可理解控制，需要额外对齐。无动作视频学到可预测运动，不等于已经获得可靠的控制接口。

## PA1-B

PA1-B 在 PixelWorld 做出可以按键控制的小世界，选做 CarRacing 迁移与 tiny diffusion 对照。提交动作反事实网格、horizon 曲线、延迟与固定失败片段。

## 小结

- [ ] Diffusion 用多步去噪表示丰富、多模态未来，通常更慢。
- [ ] AR 与 Diffusion 对照必须同时控制数据、算力和评价。
- [ ] 互动视频的核心是动作一致性、长时稳定与实时性。
