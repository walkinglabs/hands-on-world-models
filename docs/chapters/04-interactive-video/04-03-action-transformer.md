# 4.3　AR、Diffusion 与 Diffusion Forcing

视频已经压短，接下来要决定怎样生成未来。三种常见办法可以从“模型一次负责多少未来”来理解。

## AR：先生成下一小步

自回归模型把联合概率拆成一连串条件预测：

```text
历史 → 下一 token 或下一帧 → 放回历史 → 再预测下一步
```

离散 AR 使用交叉熵预测 token；连续 AR 也可以直接回归下一帧或连续 latent。B1 采用最小的离散版本：当前 token 加动作 embedding，预测下一组 token。

因果遮罩保证模型不能偷看未来。空间位置、时间位置和 token 类型也要分开编码。部署时使用 KV Cache 保存已经计算过的历史，避免每一步从头处理。

AR 的优点是因果接口清楚，适合流式生成。它的问题也很直接：训练时看到真实历史，生成时不断看到自己的预测。一步错误会变成下一步输入，这就是 train–inference gap。

## Diffusion：把一段带噪视频慢慢还原

Diffusion 可以同时给整段未来加噪，再让模型读取历史、动作和噪声等级，把它逐步还原：

```text
noisy future clip + history + actions → 多次去噪 → future clip
```

它能表达同一动作下的多种合理画面，训练也像普通监督回归一样稳定；但传统做法需要多次去噪，互动延迟较高。一次生成整段 clip 还可能使用片段内部的双向信息，不适合直接当作无限流式模型。

## AR-Diffusion：帧与帧之间自回归，每一帧内部去噪

这类方法把两者接在一起：先使用历史决定下一帧，再通过若干次去噪生成这一帧。生成完后，把新帧放进历史继续向前。

```text
过去帧 ──→ 下一帧的 Diffusion ──→ 新帧 ──→ 下一轮
   ↑             动作条件                         │
   └──────────────────────────────────────────────┘
```

它保留 AR 的流式因果性，也利用 Diffusion 处理连续、多模态画面。当前研究中的少步蒸馏、稀疏注意力、缓存、量化注意力和推测解码，主要是在解决这条路线的实时成本。课程不复现这些工业模块，只测“多一个去噪步换来多少质量、增加多少延迟”。

## Diffusion Forcing：同一片段的每一帧可以有不同噪声

普通 clip diffusion 往往给整段视频同一个噪声等级。Diffusion Forcing 允许每个时间位置拥有自己的噪声等级：历史帧可以接近干净，较远未来可以更嘈杂。

这样，同一个模型可以在几种使用方式之间切换：

- 历史干净、下一帧很嘈杂：像 next-frame prediction；
- 多个未来帧都很嘈杂：一次生成一段未来；
- 已知片段保持干净，未知片段加噪：补全或条件生成。

B2 会为 `[B,T,C,H,W]` 中每一帧单独采样噪声等级。这个 tiny 实验只展示训练接口，不声称复现 Nano World Model 或大型 Diffusion Forcing 系统。

## 三种方法怎样选

| 问题                                   | 先试什么                             |
| -------------------------------------- | ------------------------------------ |
| 需要最透明的动作因果接口               | 小型 AR baseline                     |
| 同一条件确实有多种连续画面             | latent Diffusion                     |
| 需要边生成边交互，又希望保留 Diffusion | AR-Diffusion / Diffusion Forcing     |
| 只关心规划所需特征                     | 不一定生成视频，可转向第 3 或第 5 章 |

## 小结

- [ ] AR 逐步生成，容易流式运行，也容易积累自己的错误。
- [ ] Diffusion 对一段连续表示多次去噪，能表达多种未来，但通常更慢。
- [ ] AR-Diffusion 在时间上自回归、在每个生成块内去噪。
- [ ] Diffusion Forcing 用逐帧噪声等级统一下一帧预测和整段生成。
