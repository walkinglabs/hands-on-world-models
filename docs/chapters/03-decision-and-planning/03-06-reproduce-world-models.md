# 3.6　动手复现 World Models

绪论里介绍的 V-M-C 三组件，是 2018 年第一篇被大量引用的世界模型工作。这一节把它真跑一遍：在 CarRacing 赛道上，用不到原文百分之一的规模，把「随机数据 → V 压缩 → M 想象 → C 进化 → 真实部署」的完整管线走通。

对应的脚本是 [scripts/run_carracing.py](https://github.com/walkinglabs/hands-on-world-models/blob/main/scripts/run_carracing.py)，依赖 `gymnasium[box2d]` 与 PyTorch：

```bash
pip install -e ".[neural]" gymnasium[box2d]
```

## 为什么选 CarRacing

原文的赛车实验有两个特点，特别适合做第一台亲手训练的世界模型：

- **观测就是像素**。赛道画面是 96×96×3 的图像，V 必须学会把 27,648 个像素压成 32 维 latent，压缩的意义立刻可见。
- **随机策略就能收集数据**。乱开乱撞也能跑出完整的轨迹，不需要先有一个会开车的策略。

赛道帧率约为 50 Hz，每局最多 1,000 步（约 20 秒）。原文收集了 10,000 次随机 rollout；课程脚本默认 400 次，普通笔记本 CPU 上约 1–3 小时可完成训练。

## 五步管线

脚本严格按原文顺序执行，打印 `1/5` 到 `5/5`：

**1. 随机策略收集数据。** 随机撒油门、刹车和方向，跑出若干局完整轨迹，存下每帧观测、动作和奖励。数据里没有「会开车」的例子——它们只是世界如何响应动作的原始样本。

**2. 训练 V：ConvVAE。** 把每一帧 64×64×3 的观测编码成 32 维 latent，再用 latent 重建原图。训练目标是重建误差加一个很小的 KL 正则。学成后，一张赛道截图就被压缩成 32 个数。

**3. 训练 M：MDN-RNN。** 给定 $(z_t, a_t, h_t)$，预测下一时刻的 $z_{t+1}$ 和奖励 $r_{t+1}$ 的分布。预测 $z$ 用五分量混合高斯（单一高斯会「模式平均」，把向左和向右的火球平均成中间，见绪论）；预测奖励用单高斯。训练方式是 teacher forcing：每一步都喂真实 $z$，让模型专注于单步转移。

**4. 进化 C：线性控制器。** 控制器是 $a_t = W\,[z_t, h_t] + b$ 的线性映射，参数共 867 个——与原文完全一致。用 CMA-ES 进化这些参数，适应度是 **M 的梦境里累计预测奖励**：每个候选控制器在想象中开 200 步，让 M 打分，分数高的留下来。整个过程不碰真实环境。

**5. 真实环境评估。** 把进化出的 C 接回真实赛道：V 编码真实帧 → C 出动作 → 环境反馈 → M 更新记忆，闭环运行。同时跑随机策略作为基线，并报告梦境分数，比较「想象」与「现实」的差距。

```bash
python scripts/run_carracing.py --output runs/carracing-world-model
```

## 三个对照实验

脚本的每个旗标都对应原文的一个结论：

| 命令           | 对照什么          | 预期现象                                                                                 |
| -------------- | ----------------- | ---------------------------------------------------------------------------------------- |
| 默认（带记忆） | 完整 V-M-C        | 真实分数明显高于随机基线                                                                 |
| `--no-memory`  | 去掉 M 的记忆 h_t | 控制器退化为只看当前帧，分数下降——对应原文消融实验 632 vs 906                            |
| `--tau 0.1`    | 低温梦境          | 梦境确定性高，进化容易，但控制器可能在真实环境里过拟合梦境噪声——对应原文 $\tau$ 温度实验 |

跑完输出 `runs/carracing-world-model/metrics.json`，包含梦境分数、真实分数、随机基线、VAE 重建损失、MDN 负对数似然等指标。

## 与原文的差距

规模打了折，原理没有：

| 维度        | 原文                 | 课程脚本                      |
| ----------- | -------------------- | ----------------------------- |
| 数据量      | 10,000 次 rollout    | 400 次（`--rollouts` 可调）   |
| V 的 latent | 32 维                | 32 维                         |
| M 的 hidden | 256                  | 256                           |
| C 的参数量  | 867                  | 867                           |
| CMA-ES 种群 | 64 × 16 次重复       | 32 × 1（`--population` 可调） |
| 梦境时长    | 每局最长 2,100 步    | 200 步                        |
| 训练设备    | P100 GPU + 64 核 CPU | 普通笔记本                    |

原文的 M 还负责给出每步的奖励预测，课程脚本同样实现了这一点——正因为 M 能想象奖励，C 才能只在梦里进化、完全不碰真实环境。

跑通之后，推荐接着做 [PA1-A · 做出一台 Dreamer-lite](/assignments/pa1-a)：那台模型不再进化 C，而是用可微的想象直接训练策略，你会亲身体会「进化」与「梯度下降」两条路线手感的不同。

## 小结

- [ ] World Models 的完整管线是：随机数据 → V 压缩 → M 想象 → C 进化 → 真实部署，五步缺一不可。
- [ ] C 的 867 个参数只在 M 的梦里进化，梦境 fitness 由 M 预测的累计奖励给出。
- [ ] 带记忆（[z, h] 输入）显著优于只看当前帧，这是「记忆」价值的直接证据。
- [ ] 复现的价值不在参数规模，而在理解每一步为什么存在。

原文与训练细节见 Ha & Schmidhuber (2018) [World Models](https://worldmodels.github.io/)，官方训练代码见 [WorldModelsExperiments](https://github.com/hardmaru/WorldModelsExperiments)（MIT 协议）。
