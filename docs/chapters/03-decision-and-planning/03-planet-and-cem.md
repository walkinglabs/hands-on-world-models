# 3.3　PlaNet 与 CEM

ViZDoom 里agent要绕过柱子去捡血包。连续动作空间有无数种转向角度，没法把每个动作都试一遍。RSSM 已经能从当前状态展开未来，现在的问题是：在一个连续的动作空间里，怎样找到较好的那组动作序列？

PlaNet 的答案是 CEM（cross-entropy method，交叉熵方法）：在 latent 世界里反复采样、筛选、再采样。

## 把规划变成一个优化问题

设未来 $H$ 步的动作序列是 $a_{t:t+H-1}$。我们想最大化这条序列在模型里的预测回报：

$$
J(a_{t:t+H-1}) = \mathbb{E}\!\left[\sum_{k=0}^{H-1}\gamma^k r_{t+k} + \gamma^H\, V(s_{t+H})\right]
$$

前半是 $H$ 步预测 reward 的折扣累加，后半是末端状态的 value——它估计「$H$ 步之后还剩多少回报」，避免规划器只看短期。这个问题没有解析解，动作维度高、模型非线性，梯度也难算。CEM 用采样代替求导。

## 一轮 CEM 的四步

CEM 维护一个动作分布，先宽采样，再集中到好的区域。把未来 $H$ 步动作联合建模成一个对角高斯：

$$
a_{t:t+H-1}\sim \mathcal{N}(\mu,\, \mathrm{diag}(\sigma^2))
$$

一轮迭代做四件事：

```text
从当前分布采样 N 组动作序列
→ 在 RSSM 中 rollout，算每组的 J
→ 保留 J 最高的前 K 组（精英）
→ 用精英的样本均值、方差重新拟合 μ、σ
```

重复几轮后，$\sigma$ 越来越小，$\mu$ 收敛到较好的动作序列附近。规划器只在真实环境执行**第一步**动作，然后重新读取观察，再从头规划。这就是 MPC（模型预测控制）。

## 为什么需要末端 value

horizon 有限，而真实任务可能远长于 $H$。如果只累加 $\sum \gamma^k r_{t+k}$，规划器会偏爱短期高 reward，看不见 $H$ 步之后的代价。

末端 value $V(s_{t+H})$ 把「剩余未来」压缩成一个数补回去：

$$
J = r_t + \gamma r_{t+1} + \cdots + \gamma^{H-1} r_{t+H-1} + \gamma^H V(s_{t+H})
$$

value 自身也可能错，所以实验里要和不加末端 value 的短 horizon 基线对比，确认它真的有用。

## 先用一个能验收的简单模型

直接在 RSSM latent 里规划，失败可能来自 encoder、状态、动态或 planner，一次很难分清。A2 先做一个对照：从 PixelWorld 图片用颜色阈值量出红方块的二维位置，再学一个最简单的转移模型：

$$
p_{t+1} = T_\phi(p_t,\, a_t),\qquad p_t\in\mathbb{R}^2
$$

状态只有两个数，动作也只有五种。在这个 learned dynamics 上用 beam search 试动作，再回到真实 PixelWorld 执行第一步。

这个模型仍然从观察得到状态，仍然从数据学习转移，只是状态维度极低。如果它能让真实控制明显优于随机动作，就说明「学习动态 → 模型内搜索 → 现实执行」这条链是通的。之后再换成 RSSM latent，新增的困难才主要来自表示和长时间预测。

## CEM 的优点与代价

CEM 不需要提前训练 actor，目标变了直接换 reward 重新规划。代价是每个真实动作前都要跑大量模型 rollout，环境要求高频控制时开销很大。

更隐蔽的代价是：模型有漏洞时，CEM 会**主动寻找并放大**漏洞，因为采样朝着高 J 的方向集中。限制动作范围、加不确定性惩罚、定期回到真实环境校准，都不能省。

## PlaNet 与 MPC 的关系

PlaNet 不是「预测一次就照着走到底」。它采用 MPC：每次用最新观察更新 posterior，只执行当前规划的第一步，下一步再重新规划：

```text
读取真实观察 → 更新 posterior 状态
→ CEM 在 RSSM 中搜索 H 步
→ 只执行第一步 a_t
→ 回到第一步
```

模型不完全准时，这个循环提供持续修正。这也是世界模型与纯离线视频生成的重要区别——它必须每隔几步回到现实。

## 小结

- [ ] CEM 用「采样 → 筛选精英 → 重拟合分布」在连续动作空间搜索。
- [ ] 规划目标包含末端 value，补偿有限 horizon 之外的回报。
- [ ] PlaNet 用 MPC 每步重算，适应目标变化，但计算慢，也会寻找模型漏洞。

CEM 每步都要重新搜索，太慢。下一篇看 Dreamer 怎样把好动作直接练进 actor，部署时只做一次前向。动手实验见 [A2：在想象中规划与行动](/chapters/03-decision-and-planning/07-decision-and-planning)。
