# 5.3　从图片 JEPA 到视频 JEPA

图片 patch 只覆盖空间。视频多了时间维度，同一位置在连续几帧中的小块可以组成时空管块（tubelet）。

## Tubelet

设视频 shape 为 `[T,H,W,C]`。使用 `2×4×4` tubelet 时，每个 token 覆盖 2 帧、4 像素高和 4 像素宽。

这种切分同时压缩空间与时间。时间跨度过短，只能看到局部变化；跨度过长，快速物体可能被混在同一 token 中。

## 时空 masking

V-JEPA 可以遮住某个物体跨越多帧的区域，也可以遮住较长未来片段。前者要求对象一致性，后者要求运动预测。

课程同时使用短程与长程 mask，比较模型能否读出当前位置、速度和遮挡后再次出现的位置。

## 被动观看能学到什么

无动作视频可以学习物体、运动、外观和场景变化。UCF101-mini 可用于检查表示迁移和动作类别信息。

它没有控制信号，因此不能回答“若机器人换一个动作会怎样”。被动视频 JEPA 是表示模型，不自动成为可控规划模型。

## Linear Probe

冻结 Encoder，只训练一个线性层预测位置、速度或类别。如果简单线性层就能读出这些信息，说明表示以较容易使用的形式保留了它们。

probe 成绩仍受标签和任务限制。它证明某种信息可读，不证明所有下游任务都会受益。

## 小结

- [ ] Tubelet 把空间 patch 扩展到时间维度。
- [ ] 时空 mask 的范围决定模型学习短程外观还是长程运动。
- [ ] 无动作视频可验证被动表示，不能验证动作可控性。
