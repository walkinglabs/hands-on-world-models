# 6.2　点云、BEV、LSS 与 Occupancy

相机几何把像素送回三维空间。接下来需要一种结构，让模型容易判断道路、物体和可通行区域。

## 点云

深度图或 LiDAR 产生许多三维点。点云保留测到的表面，分辨率随距离变化，也不直接区分空闲、遮挡和未知。

## BEV

鸟瞰图把地面切成规则网格，从上往下记录车道、车辆和特征。它与地图、路径和碰撞计算使用相近坐标。

高度信息可以压进通道，也可以保留多个高度层。完全压平会丢掉桥梁、路缘和悬空物体。

## LSS

Lift-Splat-Shoot 的数据流是：

```text
图像特征 + 深度分布
→ Lift 到三维 frustum
→ Splat 到 BEV 网格
→ Shoot：在 BEV 上完成检测或规划
```

深度不确定性会传播到 BEV。单帧 LSS 能构建当前空间，不自动预测未来。

## Occupancy

Occupancy 为每个体素或网格预测占用、空闲或未知。未来 Occupancy 再加入时间：

```text
过去观测 + ego plan → occupancy_{t+1:t+H}
```

若没有 ego plan，模型只能学习数据中常见车辆运动，不能回答改变自车动作后的未来。

## 评价

空格远多于占用格，accuracy 容易虚高。报告 IoU、占用召回、可通行区域错误和不同距离区间结果。

## 小结

- [ ] 点云记录表面，BEV 整理地面坐标，Occupancy 表示空间是否被占用。
- [ ] LSS 将图像特征通过深度分布放入 BEV。
- [ ] 当前 Occupancy 不等于 future Occupancy，后者还需要时间和动作条件。
