# 6.4　从静态三维重建到 4D 世界

静态场景只需回答“物体在哪里、从新视角看起来怎样”。加入时间以后，还要说明物体怎样运动、遮挡后是否仍存在，以及不同时间的几何是否一致。

## 4D 表示什么

这里的 4D 通常指三维空间加时间。模型可以直接为每个时间维护场景，也可以学习一个规范空间和随时间变化的变形场。

```text
canonical 3D + deformation(t) → scene at time t
```

对象方法则显式维护物体状态与运动，更容易加入碰撞和长时对象永久性。

## 时间变化不等于动作控制

一段会动的多视角视频可以训练 4D 重建。它只说明场景随时间变化，不说明机器人换动作后场景怎样变化。

动作条件 4D 世界还要读取控制或相机动作：

```text
current 3D state + action → future 3D state
```

## moving-shapes 小数据

课程项目内数据生成多个移动物体、多台相机和已知位姿。先检查跨视角几何，再加入时间预测，最后只改变动作测试可控变化。

Lego 用于真实静态数据迁移，不能替代动态数据。

课程的 E2a 使用一颗项目内生成的 moving sphere 做最小检查。静态基线读取 `(x,y,z)`；动态模型再读取时间与动作。固定空间坐标，只替换时间或动作，可以直接观察预测 density 是否变化。

这项实验只证明动作条件的 4D 查询接口能够训练。它没有相机射线、多视角重建、接触物理或长时间物体一致性，不能用来代替完整 4D 场景模型。

## 物理一致性

仅靠视频监督，模型可能生成穿透、漂浮或质量突变。可以在 loss 中加入软约束，把刚体结构写进状态，或让物理引擎处理已知规律、网络只学习残差。

这些方法各有代价：软约束可能被违反，硬结构限制适用范围，模拟器也可能与现实有差距。

## 小结

- [ ] 4D 在 3D 表示上加入时间与运动。
- [ ] 会随时间变化不等于会随指定动作变化。
- [ ] 物理可以作为软约束、硬结构或模拟器接口进入系统。
