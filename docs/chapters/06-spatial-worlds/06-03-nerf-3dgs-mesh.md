# 6.3　NeRF、3DGS 与 Mesh

给定带相机位姿的多视角照片，我们希望从新位置看到同一场景。NeRF、3D Gaussian Splatting 和 Mesh 都能表示三维场景，但保存方式与使用成本不同。

## NeRF

NeRF 用神经函数把三维位置与观看方向映射为密度和颜色。沿相机射线采样并做体渲染，可以得到新视角像素。

它的表示连续、画质高，训练和渲染通常需要多次网络查询。几何隐藏在神经场中，不如显式表面容易编辑。

## 3D Gaussian Splatting

3DGS 使用许多带位置、尺度、方向、透明度和颜色的高斯粒子。渲染时把粒子投影并混合到图片上，速度通常高于经典 NeRF。

它是显式粒子表示，仍不自动提供封闭表面、碰撞体或物理属性。

## Mesh

Mesh 用顶点和三角面片表示表面。它易于编辑、绑定材质，也方便交给物理引擎做碰撞。

从稀疏图片得到拓扑正确的 Mesh 并不容易，细薄结构和遮挡区域尤其困难。

## 怎样选择

关注新视角画质，可以从 NeRF 或 3DGS 开始；关注实时漫游，3DGS 更合适；关注编辑、碰撞和工程资产，Mesh 接口更直接。

同一个系统也可组合：用神经场重建外观，再提取 Mesh 供物理使用。

## 静态重建的边界

Lego 单场景实验只证明静态 3D 表示和新视角合成。它没有时间、动作和物理变化，因此不能单独称为动态世界模型。

## 小结

- [ ] NeRF 是隐式神经场，3DGS 是显式高斯粒子，Mesh 是三角表面。
- [ ] 新视角画质、实时速度与物理接口需要不同表示。
- [ ] 静态 3D 重建不是 4D 或动作条件世界模型。
