# 2.3 决策基础：强化学习与模型预测控制

> 决策与规划（Decision & Planning）是连接世界模型与实体行动的桥梁。无论是具身机器人还是自动驾驶，都依赖这一套通用基础知识。

# 2.6　价值函数与策略梯度

世界模型可以预测很多条未来，但它本身并不知道哪条未来符合任务。机器人要到达终点、避免碰撞、还要省时间——这些目标必须有一个进入比较过程的入口。

本节把三种最常用的决策接口摆在一起：价值、策略与规划器。

## Reward、Return 与 Value

**奖励**（reward）描述一步的结果，记作 $r_t$。**回报**（return）把整条未来的奖励按折扣累加：

$$
G_t = r_t + \gamma\,r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^{\infty}\gamma^k\,r_{t+k},
$$

其中 $\gamma\in[0,1)$ 是折扣因子，越远的未来权重越低。

**价值**（value）估计“从当前状态继续按当前策略行动，大约还能拿多少回报”：

$$
V(s_t)=\mathbb{E}\!\big[\,G_t\mid s_t\,\big].
$$

有了价值，规划器就不必一直把未来模拟到任务结束，只看有限几步再加上一个价值尾项即可。**TD-Learning** 用下一状态的价值当作当前目标，这种自举（bootstrapping）写成：

$$
V(s_t)\;\leftarrow\; V(s_t)+\alpha\big(r_t+\gamma V(s_{t+1})-V(s_t)\big).
$$

TD-$\lambda$ 再把不同长度的回报估计混合在一起，在偏差和方差之间取一个折中。

## Policy、Actor 与 Critic

**策略**（policy）根据当前信息直接输出动作或动作分布：

$$
a_t \sim \pi(\cdot\mid s_t).
$$

负责行动的策略叫 **Actor**，评价 Actor 选择之未来价值的叫 **Critic**。Actor-Critic 可以完全不依赖世界模型，直接在真实环境里学。

Dreamer 的特点则是把 Actor 和 Critic 都搬到世界模型生成的想象轨迹上训练——真实交互只用来收集数据，更新全在想象里完成。

## Planner 与 MPC

**规划器**（Planner）不直接记住“该做什么”，而是反复调用世界模型去比较若干条候选动作序列。

**MPC**（模型预测控制）每次预测几步、只执行第一步，再用真实观察重新规划：

$$
a_0^*=\arg\min_{a_{0:H}}\;\mathbb{E}\!\left[\sum_{t=0}^{H}\ell(s_t,a_t)\right],\quad\text{执行 }a_0^*\text{，下一步重算}.
$$

模型不完全准时，这种“边走边修正”的循环提供持续纠错，比一次性规划稳健得多。

## CEM 与 MCTS

连续动作没法全部枚举。一维小车从 $0$ 出发、希望 $5$ 步后到达 $3$，每步动作 $a\in[-1,1]$，候选序列有无穷多条。**CEM**（交叉熵方法）的做法是反复采样、保留较好的那批、再围绕它们重新采样：

1. 从分布 $\mathcal{N}(\mu,\sigma^2)$ 采 $N$ 条动作序列；
2. 用世界模型 rollout，按回报排序，留下前 $K$ 条（elite）；
3. 用这 $K$ 条重估 $\mu,\sigma$，回到第 1 步。

几轮之后，分布会集中在较好的动作序列附近。PlaNet 用的就是这种搜索。

**MCTS**（蒙特卡洛树搜索）把动作看成树的边，把更多搜索预算分配给有希望的分支。MuZero 同时学习 reward、policy 和 value，再在隐状态空间里跑 MCTS。

## 怎样选择

动作空间较小、规则明确时，枚举或树搜索很自然；连续控制适合 CEM；需要快速反应时，可以用规划数据或模型想象来训练一个 Actor，把在线搜索换成一次前向。

是否需要 Planner，取决于目标变化频率、实时预算和模型可靠性。简单稳定的任务，只用 Policy 往往就够。

## 无模型方法在表上的位置

世界模型课会碰到别人用 DQN、PPO、SAC 当基线。它们学的是 $Q$ 或 $\pi$，**不学转移**。腿式教师常用 PPO；操作仿真常用 SAC；离散游戏常用 DQN。和本章接口的关系只有一句：它们可以当 Controller，但实验若没有动作条件预测，就不要写进世界模型成绩单。

离线 RL 更窄：策略改进不许再交互。它和第 3 章「用离线数据学转移」相邻，失败模式却是 Q 高估未见动作。细则、分层语言规划、元学习与多智能体见 [附录 D](/appendices/neighboring-fields)。

内在动机把世界模型的预测误差当成探索奖励，接口在 [1.1](/chapters/01-why-world-models/01-observation-and-state)。

## 接到训练时：目标在动

价值学习的目标 $y_t = r_t + \gamma V_\phi(s_{t+1})$ 里含有 $V_\phi$ 本身。这叫**自举**（bootstrapping）：参数一更新，目标跟着变。打断正反馈最直接的办法，是让目标里的 $V$ 用一份滞后参数 $\phi^-$（EMA 目标网络）：

$$
\phi^- \leftarrow \tau\,\phi^- + (1-\tau)\,\phi,\qquad
y_t = r_t + \gamma\,V_{\phi^-}(s_{t+1}).
$$

奖励量级跨任务差几个数量级。**Symlog** 把 $1000{:}1$ 压成约 $10{:}1$，再在 symlog 空间用 **Twohot** 分类代替直接回归，单个离群回报就不会把价值头拽跑。梯度裁剪是最后一道防线：若日志里长期触发，问题在上游（学习率、KL、奖励尺度），不在裁剪本身。

| 症状                       | 可能原因                  | 对应手段                      |
| -------------------------- | ------------------------- | ----------------------------- |
| 价值损失单调上升、最终 NaN | 自举正反馈 + 回报量级过大 | EMA 目标网络、symlog + twohot |
| KL 迅速降到 0              | 后验坍缩                  | Free Bits（见 2.4）           |
| 换个任务就要重调学习率     | 奖励尺度依赖任务          | symlog、回报归一化            |

## 小结

- [ ] reward 描述一步，return $G_t=\sum\gamma^k r_{t+k}$ 描述一条未来，value 估计剩余回报。
- [ ] Policy 直接输出动作，Planner 调用模型比较候选未来；MPC 每次只执行第一步再重算。
- [ ] CEM 通过“采样—留 elite—更新分布”搜索连续动作序列，MCTS 适合树形搜索。
- [ ] DQN / PPO / SAC 是无模型基线；没有 $P(s'\mid s,a)$ 就不是世界模型实验。
- [ ] 自举、KL 坍缩与奖励尺度是把零件接起来之后才会爆的训练问题。

# 4.3　交叉熵方法与模型预测控制

ViZDoom 里agent要绕过柱子去捡血包。连续动作空间有无数种转向角度，没法把每个动作都试一遍。RSSM 已经能从当前状态展开未来，现在的问题是：在一个连续的动作空间里，怎样找到较好的那组动作序列？

PlaNet 的答案是 CEM（cross-entropy method，交叉熵方法）：在 latent 世界里反复采样、筛选、再采样。

## 把规划变成一个优化问题

设未来 $H$ 步的动作序列是 $a_{t:t+H-1}$。我们想最大化这条序列在模型里的预测回报：

$$
J(a_{t:t+H-1}) = \mathbb{E}\!\left[\sum_{k=0}^{H-1}\gamma^k r_{t+k} + \gamma^H\, V(s_{t+H})\right]
$$

前半是 $H$ 步预测 reward 的折扣累加，后半是末端状态的 value——它估计「$H$ 步之后还剩多少回报」，避免规划器只看短期。这个问题没有解析解，动作维度高、模型非线性，梯度也难算。CEM 用采样代替求导。

## 一轮 CEM 的四步

CEM 维护一个动作分布，先宽采样，再集中到好的区域。把未来 $H$ 步动作联合建模成一个对角高斯：

$$
a_{t:t+H-1}\sim \mathcal{N}(\mu,\, \mathrm{diag}(\sigma^2))
$$

一轮迭代做四件事：

```text
从当前分布采样 N 组动作序列
→ 在 RSSM 中 rollout，算每组的 J
→ 保留 J 最高的前 K 组（精英）
→ 用精英的样本均值、方差重新拟合 μ、σ
```

重复几轮后，$\sigma$ 越来越小，$\mu$ 收敛到较好的动作序列附近。规划器只在真实环境执行**第一步**动作，然后重新读取观察，再从头规划。这就是 MPC（模型预测控制）。

## 为什么需要末端 value

horizon 有限，而真实任务可能远长于 $H$。如果只累加 $\sum \gamma^k r_{t+k}$，规划器会偏爱短期高 reward，看不见 $H$ 步之后的代价。

末端 value $V(s_{t+H})$ 把「剩余未来」压缩成一个数补回去：

$$
J = r_t + \gamma r_{t+1} + \cdots + \gamma^{H-1} r_{t+H-1} + \gamma^H V(s_{t+H})
$$

value 自身也可能错，所以实验里要和不加末端 value 的短 horizon 基线对比，确认它真的有用。

## 先用一个能验收的简单模型

直接在 RSSM latent 里规划，失败可能来自 encoder、状态、动态或 planner，一次很难分清。4.7 的第二份 Notebook 先做一个对照：从 PixelWorld 图片用颜色阈值量出红方块的二维位置，再学一个最简单的转移模型：

$$
p_{t+1} = T_\phi(p_t,\, a_t),\qquad p_t\in\mathbb{R}^2
$$

状态只有两个数，动作也只有五种。在这个 learned dynamics 上用 beam search 试动作，再回到真实 PixelWorld 执行第一步。

这个模型仍然从观察得到状态，仍然从数据学习转移，只是状态维度极低。如果它能让真实控制明显优于随机动作，就说明「学习动态 → 模型内搜索 → 现实执行」这条链是通的。之后再换成 RSSM latent，新增的困难才主要来自表示和长时间预测。

## CEM 的优点与代价

CEM 不需要提前训练 actor，目标变了直接换 reward 重新规划。代价是每个真实动作前都要跑大量模型 rollout，环境要求高频控制时开销很大。

更隐蔽的代价是：模型有漏洞时，CEM 会**主动寻找并放大**漏洞，因为采样朝着高 J 的方向集中。限制动作范围、加不确定性惩罚、定期回到真实环境校准，都不能省。

## PlaNet 与 MPC 的关系

PlaNet 不是「预测一次就照着走到底」。它采用 MPC：每次用最新观察更新 posterior，只执行当前规划的第一步，下一步再重新规划：

```text
读取真实观察 → 更新 posterior 状态
→ CEM 在 RSSM 中搜索 H 步
→ 只执行第一步 a_t
→ 回到第一步
```

模型不完全准时，这个循环提供持续修正。这也是世界模型与纯离线视频生成的重要区别——它必须每隔几步回到现实。

## 第三条路：TD-MPC

CEM 每步都从零搜索，Dreamer 把搜索完全换成一次前向。**TD-MPC**（Temporal Difference Model Predictive Control）走中间：世界模型和价值函数一起训，规划时只搜很短的 $H$（常见 3–5 步），末端仍然用 $V(s_{t+H})$ 补上剩余回报。

和 PlaNet 的差别不在「用不用 MPC」，而在价值从哪来。PlaNet 的 $V$ 可以是后加的；TD-MPC 用 TD 目标把 $V$ 训进同一套 latent，搜索预算可以更小。和 Dreamer 的差别是：部署时仍做几次采样规划，不把策略焊死成纯 actor。

LeRobot 把 TD-MPC 列为和 ACT、扩散策略并列的可训练策略，不是因为名字新，而是因为它把「学转移」和「用转移做控制」收在同一个训练循环里。课程里的最小对照是：同一 RSSM、同一 $H$，比较「纯 CEM、不加 $V$」「CEM + 训好的 $V$」「只执行 actor」。只报其中一种，看不出价值函数到底有没有缩短搜索。

实现细节和稳定性技巧见 TD-MPC2；本章动手仍以 CEM 与 Dreamer 为主。若 4.7 简洁档选做这条，必须同时交出模型一步误差和真实环境 return，不能只交规划器的 $J$。

## 小结

- [ ] CEM 用「采样 → 筛选精英 → 重拟合分布」在连续动作空间搜索。
- [ ] 规划目标包含末端 value，补偿有限 horizon 之外的回报。
- [ ] PlaNet 用 MPC 每步重算；TD-MPC 把价值函数和短期 MPC 绑在一起训，搜索更短。
- [ ] 三种规划都会寻找模型漏洞，必须定期回到真实观察。

CEM 每步都要重新搜索，太慢。下一篇看 Dreamer 怎样把好动作直接练进 actor，部署时只做一次前向。动手实验见 [4.7 动手：Dreamer 的简化实现](/chapters/04-latent-dynamics/08-dreamer-concise) 的第二份 Notebook「在想象中行动」。
