# 3.3　从经历学出第一台模型

先从一维世界开始。机器人可以向左或向右，环境带有 20% 的打滑概率。我们统计每个 `(state, action)` 后出现过哪些下一状态，再把次数换成概率。

这台模型不使用梯度，却已经可以：

1. 保留同一动作的多个可能结果；
2. 标出没有见过的状态和动作；
3. 连续 rollout 多步；
4. 被 MPC 调用来选择动作。

## 反事实检查

固定同一起点和随机种子，只替换动作。模型的预测应当跟着动作发生合理变化。若向左和向右得到完全相同的未来，模型并没有真正学会动作的作用。

## 放回真实环境

规划器只执行选中的第一步，然后重新观察真实环境，把新的 transition 存入 Replay Buffer，更新模型，再次规划。至此，我们第一次接起完整循环：

```text
收集经历 → 学习模型 → 在模型中比较动作 → 回到现实执行一步 → 收集新经历
```

## PA0 交出什么

PA0 提供新的小地图，不提供完整模型结构。提交内容包括接口图、数据卡、简单基线、一步与多步结果、动作反事实、下游成功率和一组失败案例。

表格方法若已经解决任务，继续换神经网络不会加分。只有当图像、历史、不确定性或动作空间确实使表格失败时，才需要下一种组件。
