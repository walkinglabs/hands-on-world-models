# 7.1　相机怎样把三维世界变成图片

同一个杯子从左侧相机看位于图片右边，从右侧相机看位于图片左边。若直接比较像素位置，会得到两个不同的杯子位置。

相机模型把三维点、相机位置和二维像素连接起来。

## 针孔相机

三维点 `(x,y,z)` 投影到像素 `(u,v)`：

```text
u = fx * x / z + cx
v = fy * y / z + cy
```

`fx, fy, cx, cy` 构成内参，描述焦距和成像中心。

## 从像素返回三维射线

已知深度 `z` 时，可以反投影：

```text
x = (u - cx) * z / fx
y = (v - cy) * z / fy
```

没有深度时，一个像素只确定从相机出发的一条射线，不能确定物体在射线上的具体位置。

## 外参

外参用旋转 `R` 与平移 `t` 把相机坐标转换到世界坐标。多台相机的点只有先进入同一世界坐标，才可合并。

## 标定误差怎样出现

焦距、相机姿态或时间同步有小误差时，同一物体的点云会重影，BEV 中车道线也会错位。

E1 使用合成立方体和已知参数做数值检查：投影、反投影、坐标变换后，应回到原点附近。先验证几何，再训练网络。

## 小结

- [ ] 内参描述相机成像，外参描述相机在世界中的位置和朝向。
- [ ] 单个像素没有深度时只确定一条射线。
- [ ] 多视角融合前要统一坐标并检查标定与时间同步。
