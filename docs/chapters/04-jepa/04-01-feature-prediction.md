# 4.1　为什么改成预测特征

一段室外视频里，树叶、阴影和水面反光每一帧都在变化。若模型必须精确预测每个像素，大量算力会用于这些难以确定、又未必影响任务的细节。

假设任务只要求判断一个球的位置和运动方向。我们可以不重建完整画面，而是预测由另一个 Encoder 提供的特征。

## 像素预测与特征预测

像素世界模型比较生成图与真实图：

```text
predicted pixels ↔ target pixels
```

联合嵌入预测架构（JEPA）比较预测特征与目标特征：

```text
predicted features ↔ target encoder features
```

Predictor 的任务是从可见上下文推测被遮区域或未来片段的表示。

## 为什么不直接把目标设成人写状态

若数据提供物体位置、速度和类别，可以直接监督这些量。但互联网视频通常没有完整状态标签，真实任务需要的信息也可能很难事先列全。

JEPA 让目标 Encoder 从数据产生训练目标，再通过 masking、架构和下游任务控制表示保留什么。

## 付出的代价

没有 Decoder，feature 不能直接画回完整未来。我们也不能仅凭 feature loss 断言模型保留了有用信息。

因此评价要增加 linear probe、检索、动作敏感性或规划任务。所谓“有用”，必须由使用者和任务给出证据。

## 一个最小对照

PixelWorld 背景随机变色，方块运动规律保持不变。像素预测会为背景承担损失；feature 预测若学得合适，应仍能稳定读出方块位置和速度。

如果换成“预测背景颜色”的新任务，原来被丢掉的信息又会变得重要。这说明表示没有脱离任务的绝对优劣。

## 小结

- [ ] JEPA 预测目标 Encoder 的特征，不要求重建所有像素。
- [ ] 特征目标可以减少对不稳定视觉细节的依赖。
- [ ] feature loss 低不等于表示有用，仍需下游检查。
