# 7.10　动手：灵巧手的视触觉控制

> **本节目标**：把视觉、关节与触觉三路信号融成一个滑移预测器，在执行候选动作之前先问一句"这一握会不会滑"。

> **前置知识**：[7.5 操作、接触与触觉](/chapters/07-robot-vla/05-manipulation-and-touch)、[7.4 机器人世界模型](/chapters/07-robot-vla/04-robot-world-models)。

指尖胶体上的接触斑在 $60\ \mathrm{ms}$ 内向下移动了 $0.3\ \mathrm{mm}$。物体还在手里，画面上什么都没变，但滑移已经开始了。

人在这一刻会不自觉地加力。只看外部相机的机器人要等到物体离开夹持位、甚至掉出画面才知道出事——那时候已经晚了几百毫秒。这一节要做的，就是把这几百毫秒抢回来。

## 环境与预算

灵巧手默认用 $16$ 自由度的 Allegro 类模型（仿真中即可），触觉用 GelSight 类视触觉贴片。没有灵巧手的读者可以退化到两指夹爪加一枚视触觉指尖，本节的全部结论依然成立。

单张 **24 GB 显卡**，参考量级：

- 数据：$500$ 次抓持试验，每次 $3\ \mathrm{s}$，触觉与视觉重采样到 $30\ \mathrm{Hz}$，约 $4.5$ 万帧。
- 视觉分支：ResNet-18，前两个 stage 冻结。触觉分支：$64\times 64$ 灰度输入的小 CNN。关节分支：MLP 吃 $H=10$ 步历史。
- 训练：batch 64，显存约 $7\ \mathrm{GB}$，单次训练 $15$–$30$ 分钟。

## 步骤 1：三路信号的时间对齐

三个传感器的原生频率不同：关节编码器 $200\ \mathrm{Hz}$，触觉图像 $60\ \mathrm{Hz}$，外部相机 $30\ \mathrm{Hz}$。全部带时间戳落盘，再统一重采样到 $30\ \mathrm{Hz}$，关节用窗口内的均值与末值两套特征。

对齐必须验证，不能假设。做法是给一个明显的阶跃动作（快速合拢再张开），把三路信号画在同一时间轴上，检查跳变时刻是否落在同一帧。这里错一帧就是 $33\ \mathrm{ms}$，而整个任务要抢的正是这个量级。

## 步骤 2：滑移标签从哪里来

滑移的定义要写成可测量的判据。取物体相对手掌坐标系的位移，若在 $200\ \mathrm{ms}$ 窗口内超过 $2\ \mathrm{mm}$，该窗口的起点标为正样本：

$$
y_t=\mathbb{1}\Bigl\{\bigl\lVert p^{\text{obj}}_{t+\Delta}-p^{\text{obj}}_{t}\bigr\rVert_2>2\ \mathrm{mm}\Bigr\},\qquad \Delta=200\ \mathrm{ms}.
$$

仿真里物体位姿是真值，直接可读；真机上用 AprilTag 或贴点标记，并诚实记录标记本身的测量误差（通常 $0.5$–$1\ \mathrm{mm}$，和阈值同量级）。

数据要故意包含失败：随机降低夹持力、随机施加外部拉力、混入光滑材质。只用成功抓持采集的数据，正样本比例会低到 $2\%$ 以下，模型学到的将是"永远不滑"。目标是把正样本比例做到 $10\%$–$25\%$，并在损失里用 `pos_weight` 补偿剩余不平衡。

## 步骤 3：三分支融合与两个预测头

$$
\bigl(\hat p_{\text{slip}},\;\hat c_{t+1}\bigr)=f_\theta\bigl(o^{\text{vis}}_t,\;o^{\text{tac}}_{t-H:t},\;q_{t-H:t},\;a_t\bigr)
$$

$\hat p_{\text{slip}}$ 是滑移概率，$\hat c_{t+1}$ 是下一步的接触状态（接触斑面积、法向力估计、剪切位移）。训练损失是两项相加：

$$
\mathcal{L}=\underbrace{\mathrm{BCE}_{w}\bigl(\hat p_{\text{slip}},\,y\bigr)}_{\text{滑移分类}}+\lambda\underbrace{\bigl\lVert \hat c_{t+1}-c_{t+1}\bigr\rVert_2^2}_{\text{接触状态回归}}
$$

注意动作 $a_t$ 必须进模型。只吃观察的模型是一个滑移**探测器**；吃了候选动作的模型才是世界模型，才能回答"如果我这样做，会不会滑"。

## 步骤 4：执行前的后果检查

候选动作集固定为五个：保持当前夹持、加力 $+1\ \mathrm{N}$、加力 $+2\ \mathrm{N}$、降低运动速度、重新抓取。对每个候选算出 $\hat p_{\text{slip}}$，选择满足阈值且代价最低的那个。

$$
a^\star=\arg\min_{a\in\mathcal{A}}\;\mathrm{cost}(a)\quad\text{s.t.}\quad \hat p_{\text{slip}}(a)<\tau .
$$

这里有个必须一起报告的代价。加力能压住滑移，也能压坏物体——[7.5](/chapters/07-robot-vla/05-manipulation-and-touch) 里那个纸杯例子说明，某些抓法根本不存在既不滑又不坏的力。所以本节的评测除了滑移指标，还要报告**损坏率**。只报滑移下降，会得到一个把所有易碎物体都捏瘪的策略。

## 步骤 5：消融

三次重训，每次只去掉一路输入，其余预算完全相同：

1. 去触觉（只有视觉 + 关节）。
2. 去视觉（只有触觉 + 关节）。
3. 去关节历史。

预期的方向是：去触觉最伤检出率和提前预警时间；去视觉最伤对未见物体的泛化。若观察到的方向与预期相反，先查时间对齐和标签，不要先改模型。

## 需要报告的指标

| 指标         | 定义                                    | 参考线       |
| ------------ | --------------------------------------- | ------------ |
| 滑移检出率   | 误报率 $\le 0.05$ 时的 recall           | $\ge 0.70$   |
| 误报率       | 未滑样本被判为滑的比例                  | $\le 0.05$   |
| AUROC        | 与阈值无关的排序质量                    | $\ge 0.85$   |
| 提前预警时间 | 报警到真实滑移的中位时间差              | $\ge 100$ ms |
| 任务成功率   | 接入后果检查后，$n=50$ 次搬运的成功比例 | 报告并附区间 |
| 损坏率       | 易碎物体被压坏的比例                    | 报告即可     |
| 推理延迟     | 五个候选一起前向的 p95 毫秒             | $\le 20$ ms  |

提前预警时间的参考线不是随便定的：加力指令下发到接触力真正上升需要几十毫秒，加上一个控制周期，$100\ \mathrm{ms}$ 是"来得及救"的下限。预警时间为负的模型只是事后记录仪。

## 常见失败与排查

| 现象                         | 最可能的原因               | 先查什么                          |
| ---------------------------- | -------------------------- | --------------------------------- |
| AUROC 很高但提前时间接近 $0$ | 标签窗口太短，模型在读结果 | 拉大 $\Delta$，检查是否泄漏未来帧 |
| 训练集完美、测试集接近随机   | 按帧切分导致同一试验穿越   | 改为按试验切分                    |
| 检出率高、误报率也高         | 只优化了 recall            | 固定误报率再报 recall             |
| 去掉触觉后指标几乎不变       | 触觉分支没接上或已饱和     | 打印触觉分支梯度范数与输入方差    |
| 换新物体后急剧退化           | 材质与形状覆盖不足         | 扩充材质，报告按物体分组的结果    |
| 后果检查让任务变慢很多       | 候选数或采样步数过多       | 实测延迟，压缩候选集              |

## 验收标准

- [ ] 三路信号的对齐已用阶跃动作验证并留图。
- [ ] 滑移标签的判据（阈值、窗口、测量方式与误差）写清楚了。
- [ ] 正样本比例落在 $10\%$–$25\%$，数据里明确包含人为诱发的失败。
- [ ] 检出率在**固定误报率**下报告，不是自选阈值下的最好值。
- [ ] 三项消融在同一预算下完成，方向与解释都写出来了。
- [ ] 同时报告任务成功率与损坏率，没有只报滑移下降的结论。
- [ ] 按物体分组的结果单独列出，并说明哪些物体从未出现在训练集。

## 本节小结

- 触觉能看见相机看不见的前兆，但只有把候选动作一起喂进模型，探测器才变成世界模型。
- 滑移指标必须成对报告：固定误报率下的检出率，以及提前预警时间。
- 压住滑移的手段本身有代价，损坏率和成功率要一起出现在同一张表里。
