# 7.12　动手：全身策略的仿真与真机迁移

> **本节目标**：走完特权教师 → 学生蒸馏 → 跨模拟器交叉验证 → 真机观测对齐这条完整链路，并量出每一段掉了多少。

> **前置知识**：[7.6 腿式与全身控制](/chapters/07-robot-vla/06-legged-and-whole-body)、[7.7 模拟器与 Sim-to-Real](/chapters/07-robot-vla/07-simulators-and-sim2real)。

一个能读到地形高度图、足端摩擦系数和外部推力的教师策略，在起伏地形上连走 $1000$ 步不跌倒。把观察换成真机唯一能拿到的那 $78$ 维——关节、IMU、指令、上一动作——用同样的算法和预算重训一遍，通常在两三百步之内就倒了。

这个差距不是调参能补的，它是部分可观带来的探索困难。所以腿式控制的标准配方是分两段：先在仿真里用特权信息把控制问题解干净，再把解压缩进一个只用可部署观察的学生。

## 环境与预算

默认栈是 Isaac Lab（GPU 并行 RL）加 MuJoCo（独立评测）。单张 **24 GB 显卡**，参考量级：

- 教师 PPO：$4096$ 个状态观察环境，显存约 $8\ \mathrm{GB}$，$2\times 10^{9}$ 步约需 $3$–$6$ 小时。
- 学生蒸馏：$5\times 10^{8}$ 步量级，约 $1$ 小时。
- 交叉验证：MuJoCo 侧 $1000$ 个 episode，CPU/GPU 均可，$10$ 分钟量级。

观察维度按一台 $23$ 关节人形估算：可部署部分约 $78$ 维（关节位置与速度 $46$、基座角速度 $3$、重力方向 $3$、速度指令 $3$、上一动作 $23$）；特权部分再加约 $200$ 维（地形高度扫描 $187$、足端摩擦 $4$、外部推力 $3$、接触状态 $4$）。

## 阶段 1：特权教师

用 PPO 训练 $\pi^{T}(a\mid s_t,\xi_t)$，$\xi_t$ 是特权信息。奖励至少包含速度指令跟踪、姿态保持、能耗惩罚和足端滑移惩罚。若要跟踪参考动作，再加一项关节角跟踪。

这一阶段有一条容易被跳过的检查：把特权通道逐个置零，看性能掉多少。如果地形高度图置零后教师几乎不变，说明它根本没在用地形，后面的蒸馏就没有信息可传，问题出在地形课程或奖励上。

## 阶段 2：学生蒸馏

学生 $\pi^{S}(a\mid o_{t-H:t})$ 只吃可部署观察，用 $H=50$ 步历史经一维卷积或 GRU 压缩。**关键是数据由谁生成**：必须让学生自己 rollout，再由教师在同一状态上给出标注（DAgger 式在线蒸馏）。

$$
\mathcal{L}_{\text{distill}}=\mathbb{E}_{s\sim d_{\pi^{S}}}\bigl\lVert \pi^{S}\bigl(o_{t-H:t}\bigr)-\pi^{T}\bigl(s_t,\xi_t\bigr)\bigr\rVert_2^2
$$

期望下标是 $d_{\pi^{S}}$ 而不是 $d_{\pi^{T}}$。若只用教师轨迹做离线回归，学生一旦偏离就没有监督，就退化成 [7.2](/chapters/07-robot-vla/02-imitation-and-policies) 里那个复合误差问题。做一次对照实验把这件事量出来：离线回归 vs 在线 DAgger，比较跌倒率。

延迟与动作重复也要在这一阶段进环境（见 [7.7](/chapters/07-robot-vla/07-simulators-and-sim2real) 的 wrapper）。学生是要部署的那个模型，它必须在训练时就见过真机的时序。

## 阶段 3：跨模拟器交叉验证

把 Isaac Lab 训出的学生权重直接搬到 MuJoCo 评测，不做任何微调。资产要重新核对总质量、连杆惯量和自由落体时间——这三个数不一致，后面的差异无法归因。

单看一个数字不够。取训练过程中的 $8$ 个 checkpoint，让两个模拟器各自排序，算 Spearman 相关系数 $\rho$：

$$
\rho=\mathrm{Spearman}\bigl(\text{rank}_{\text{IsaacLab}},\;\text{rank}_{\text{MuJoCo}}\bigr).
$$

$\rho$ 高说明"在训练模拟器里更好"确实意味着"更可能迁移"，选模型的流程才站得住。$\rho<0.5$ 时结论很不舒服但很重要：你无法用训练模拟器的分数来挑 checkpoint，只能每个都独立评测。

## 阶段 4：真机观测对齐（选做）

真机部分是**选做**，且必须先说清门槛：人形机器人需要吊架或安全绳、急停回路和两人以上在场；跌倒的维修成本经常高于一次实验的价值。没有条件的读者以阶段 3 为终点，实验依然完整。

能做的读者从最便宜的一步开始：**开环观测对齐**。不部署策略，只回放一段固定的关节位置序列，同时记录真机与仿真的关节轨迹和 IMU 角速度，比较前 $2$ 秒的偏离。

$$
e_{\text{align}}(t)=\bigl\lVert q^{\text{real}}_t-q^{\text{sim}}_t\bigr\rVert_2
$$

这条曲线是后面一切的前提。若它在 $2$ 秒内就长到 $5^\circ$ 以上，说明动力学参数或延迟没对上，此时部署闭环策略只是在赌。用这段数据做一次系统辨识（拟合电机增益、阻尼、`armature`、延迟），收紧域随机化区间，再回阶段 1。

## 需要报告的指标

| 指标           | 定义                                    | 参考线         |
| -------------- | --------------------------------------- | -------------- |
| 速度跟踪误差   | 指令与实测基座速度的 RMSE               | $\le 0.15$ m/s |
| 关节跟踪误差   | 参考动作跟踪任务的关节角 RMSE           | $\le 5^\circ$  |
| 跌倒率         | $1000$ 个 episode 中提前终止的比例      | $\le 0.02$     |
| 教师-学生差距  | 同一评测下两者跌倒率与跟踪误差之差      | 报告并解释     |
| 跨模拟器一致性 | 跌倒率之差；$8$ 个 checkpoint 的 $\rho$ | $\rho \ge 0.7$ |
| 观测对齐误差   | 开环回放 $2$ 秒时的 $e_{\text{align}}$  | $\le 5^\circ$  |
| 能耗           | 单位距离的关节功率积分                  | 报告即可       |

参考线是"跑通"的门槛。跌倒率 $0.02$ 在 $1000$ 个 episode 下的半宽约 $\pm 0.009$，这个精度只在仿真里拿得到；真机上 $30$ 次试验的区间宽到几乎不能比较大小，报告时必须写明 $n$。

## 失败图集

跌倒率是一个数字，失败图集才是可以据此改进的证据。要求按类别归档，每类至少 $5$ 段视频，并标注触发条件与失败发生的时间戳：

- 起步阶段失稳（指令从零跳到目标速度的瞬间）。
- 单侧足端滑移（低摩擦贴片或斜面）。
- 踏空（高度差被低估，对应 [7.6](/chapters/07-robot-vla/06-legged-and-whole-body) 的落脚点预测）。
- 上身负载引起的前倾（移动操作场景）。
- 指令切换瞬间跌倒（前进转侧移）。
- 长时间行走后的姿态漂移（数分钟量级）。

## 常见失败与排查

| 现象                             | 最可能的原因                 | 先查什么                         |
| -------------------------------- | ---------------------------- | -------------------------------- |
| 教师很好，学生怎么调都差         | 用了离线回归而非 DAgger      | 换成学生 rollout + 教师标注      |
| 特权通道置零后教师不变           | 教师没在用特权信息           | 检查地形课程与奖励是否真的需要它 |
| 仿真完美，换模拟器跌倒率翻倍     | 资产或接触参数不同           | 核对质量惯量，做开环回放         |
| 8 个 checkpoint 的 $\rho$ 接近 0 | 训练模拟器分数不可用于选模型 | 改为每个 checkpoint 独立交叉评测 |
| 动作高频振荡、电机发烫           | 延迟未建模或动作平滑不足     | 实测总延迟，进 delay wrapper     |
| 步态好看但走不动                 | 运动先验权重过大             | 降低模仿项，检查速度跟踪奖励     |
| 真机开环回放很快就偏             | 电机增益或 `armature` 未辨识 | 先做系统辨识，再谈闭环部署       |

## 验收标准

- [ ] 教师的特权通道消融结果已记录，证明特权信息确实被使用。
- [ ] 学生用在线 DAgger 训练，并与离线回归做过对照。
- [ ] 延迟与动作重复在训练环境中建模，延迟值来自实测而非假设。
- [ ] 跨模拟器交叉验证同时报告跌倒率之差与 $8$ 个 checkpoint 的 $\rho$。
- [ ] 失败图集按六类归档，每类附视频与触发条件。
- [ ] 若做了真机，先给出开环观测对齐曲线与系统辨识结果，再谈闭环；若未做，明确以阶段 3 为终点。
- [ ] 所有成功率与跌倒率都带试验次数，仿真与真机的 $n$ 分别写明。

## 本节小结

- 教师-学生蒸馏之所以是标准做法，是因为可部署观察下的 RL 在预算内训不出来；代价是学生继承教师的上限与错误假设。
- 蒸馏数据必须由学生自己生成，否则复合误差原封不动地回来。
- 跨模拟器的 checkpoint 排序相关系数，比单个成功率更能说明"训练分数能不能用来选模型"。
