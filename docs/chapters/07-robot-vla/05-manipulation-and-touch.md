# 7.5　操作、接触与触觉

一根直径 $20.00\ \mathrm{mm}$ 的轴要插进直径 $20.05\ \mathrm{mm}$ 的孔。单边间隙是 $0.025\ \mathrm{mm}$，也就是 $25$ 微米。而一次做得不错的手眼标定，残余误差通常在 $1\ \mathrm{mm}$ 量级——比允许的间隙大了 $40$ 倍。

导航任务里，走廊宽 $1.2\ \mathrm{m}$、机器人宽 $0.6\ \mathrm{m}$，几厘米的定位误差无伤大雅。**插接**（peg-in-hole）不给这个余量。位置控制注定不够，必须让接触力参与进来。

## 接触是不连续的

无接触时物体之间没有力；一旦贴上，力可以在极小的位移里长得很大。把接触间隙记作 $\varphi(q)\ge 0$、法向力记作 $\lambda\ge 0$，两者满足**互补条件**：

$$
\varphi(q)\ge 0,\qquad \lambda\ge 0,\qquad \lambda\,\varphi(q)=0.
$$

意思是二者不能同时为正：要么分开且无力，要么接触且有力。这个约束让接触动力学在几何上是分片的，在数值上是刚性的。取接触刚度 $K_c=5\times 10^{5}\ \mathrm{N/m}$，穿透 $0.1\ \mathrm{mm}$ 就对应 $50\ \mathrm{N}$ 的力——网格差一格，力差一个数量级。

切向方向由库仑摩擦约束，可行力落在**摩擦锥**内：

$$
\lVert f_t\rVert_2\le \mu\,f_n .
$$

## 摩擦锥里可能根本没有解

机械手捏住一个纸杯，杯子连水共 $0.5\ \mathrm{kg}$，重力 $4.905\ \mathrm{N}$ 要靠指尖的摩擦托住。取 $\mu=0.5$，需要的法向力是 $f_n\ge 4.905/0.5=9.81\ \mathrm{N}$。而纸杯壁开始塌陷的临界压力大约在 $8\ \mathrm{N}$。

```python
import numpy as np

MU = 0.5            # 指尖与纸杯壁的摩擦系数
CRUSH_N = 8.0       # 杯壁塌陷阈值（牛）

def grasp_margin(f_normal, tangential_load):
    """返回摩擦锥余量：正数表示不滑，负数表示会滑。"""
    return MU * f_normal - tangential_load

weight = 0.5 * 9.81
for f_n in [4.0, 8.0, 9.8, 12.0]:
    margin = grasp_margin(f_n, weight)
    print(
        f"f_n={f_n:5.1f} N  余量={margin:+6.2f} N  "
        f"滑={'是' if margin < 0 else '否'}  "
        f"压瘪={'是' if f_n > CRUSH_N else '否'}"
    )

f_min = weight / MU
print("不滑所需最小法向力:", round(f_min, 2), "N；塌陷阈值:", CRUSH_N, "N")
print("存在可行夹持力:", f_min <= CRUSH_N)
```

最后一行打印 `False`。这不是控制器调得不好，是这个抓法在物理上无解：要么滑落，要么压瘪。可行的做法是换抓取姿态（托住杯底把切向载荷变成法向载荷）、增大接触面积，或者换更软的指尖把 $\mu$ 抬上去。任何只调增益的尝试都会在两个失败之间来回。

## 力控与阻抗控制

纯位置控制的等效刚度很高。取 $K_p=5\times 10^{4}\ \mathrm{N/m}$，$1\ \mathrm{mm}$ 的位置误差就换来 $50\ \mathrm{N}$ 的推力，足够把轴顶弯。**阻抗控制**（impedance control）主动把这个刚度调低，让末端表现得像一套弹簧阻尼：

$$
f=K_p\,(x_d-x)+K_d\,(\dot x_d-\dot x).
$$

同样的 $1\ \mathrm{mm}$ 误差，取 $K_p=500\ \mathrm{N/m}$ 只产生 $0.5\ \mathrm{N}$。插接因此可以"撞着找"：沿孔口螺旋搜索，让接触力自己把轴导进去，而不要求视觉先把位置算准到 $25$ 微米。

代价是跟踪精度变差。低刚度方向上，外力会把末端推开，自由空间里的轨迹误差随之变大。实践中按方向分配：插入轴向保持较低刚度，垂直方向保持较高刚度。

## 触觉传感能看见什么

**视触觉**（visuotactile）传感器如 GelSight 类，用一块弹性体加内置相机，把接触面的形变拍成图像。一块 $20\ \mathrm{mm}\times 15\ \mathrm{mm}$ 的胶体配 $640\times 480$ 相机，空间分辨率大约 $30$ 微米每像素——正好落在插接间隙的量级上。位置传感器看不见的东西，触觉图像看得见。

指尖六轴力/力矩传感器给的是另一类信号：低维、高频（$1\ \mathrm{kHz}$ 量级），适合直接进控制回路；视触觉图像维度高、频率低（$30$–$60\ \mathrm{Hz}$），适合进感知网络。两者不互相替代。

## 滑移检测与滑移预测

**滑移**（slip）在触觉图像上表现为接触斑内部的剪切位移场。设两帧之间接触区域的平均切向位移为 $\Delta u$，最朴素的检测就是阈值判断，例如 $\Delta u>0.2\ \mathrm{mm}$ 判为已滑。

检测是事后的，控制需要的是提前。把上一节的摩擦锥余量写成可学习的量，就得到滑移**预测**：给定当前触觉、关节和候选夹持力，预测 $\Delta t$ 之后是否越出摩擦锥。

$$
\hat p_{\text{slip}}=\sigma\bigl(g_\phi(\text{tactile}_t,\;q_t,\;a_t)\bigr).
$$

评价必须同时报告两个数：**检出率**（recall，真滑被抓住的比例）和**误报率**（false positive rate，没滑却报警的比例）。只报检出率，一个永远喊"要滑了"的模型就能拿到 $1.0$——代价是机器人一直在加力，把纸杯压瘪。

## 从三维到抓取姿态

北大课把「看见物体」写成抓取的先修。最小接口是：从 RGB 或 RGB-D 得到物体位姿或一组候选抓取 $\mathrm{grasp}\in\mathrm{SE}(3)$，再交给阻抗控制去执行。物体中心表示（把杯子和背景拆开）是这一步的状态结构，不是新的损失函数。

这条感知链有具体的工具：YOLO 先框出"画面里哪个位置有杯子"，SAM 再把杯子的像素轮廓抠出来，深度估计给出杯子的三维坐标。这三步是抓取的"眼睛"，世界模型是抓取的"预演"——前者回答"东西在哪"，后者回答"这样抓会怎样"。本书不单独教 YOLO/SAM，因为它们是已知的感知前端，不是世界模型；但选题碰到真机抓取时，必须写清感知前端用的是哪个模型、误差多少，因为抓取容差只有几毫米，检测框偏一截，世界模型再准也没用。

评价抓取必须报：位姿误差、接触后是否稳定、以及换物体实例后是否还成立。只报检测 mAP，不能说明手抓得住。和本节摩擦锥的关系是：几何抓取可行，力域仍可能无解——两个检查都要过。

## 灵巧手的高维动作空间

两指夹爪的动作是一个数。Allegro Hand 有 $16$ 个驱动自由度，Shadow 类灵巧手到 $20$ 以上。即使每个关节只分三档，$16$ 维就有 $3^{16}\approx 4.3\times 10^{7}$ 种组合。

维度带来两个具体困难。一是遥操作示范难采：人手到机器人手的映射不唯一，动捕手套的指尖误差常与接触间隙同量级。二是探索空间大，纯 RL 需要的样本量远超真机可承受的次数，所以灵巧操作的策略几乎都先在仿真里训。

降维的常用手段是**协同**（synergy）：用主成分把 $16$ 维压到 $5$–$6$ 维的常用手型子空间。代价是丢掉了子空间外的手型，而恰好有些精细操作只存在于那里。

## 世界模型在这里预测什么

操作任务里的世界模型不必预测好看的像素。它要预测的是**接触后果**：这个候选动作执行后会不会滑、会不会卡死、接触力会到多大、物体位姿会转多少。

$$
\bigl(\hat p_{\text{slip}},\;\hat f_{\max},\;\hat T_{\text{obj}}\bigr)=f_\theta\bigl(o_t^{\text{vis}},\;o_t^{\text{tac}},\;q_t,\;a_t\bigr).
$$

这个模型的训练数据必须包含失败：滑落、压瘪、卡死的轨迹和成功轨迹一样重要。只用成功示范训出来的后果模型，会对所有动作都判"安全"。

诚实的边界有两条。第一，接触参数（摩擦、刚度、质量分布）在真机上会漂移，一批新的纸杯就可能让 $\mu$ 变化 $30\%$，所以后果模型要么估计不确定性，要么定期用真机数据校准。第二，仿真里通过不等于真机成功——接触求解器的选择本身就会改变结论，这是 [7.7 模拟器与 Sim-to-Real](/chapters/07-robot-vla/07-simulators-and-sim2real) 要处理的问题。

## 小结

- [ ] 插接的容差在几十微米量级，位置控制加视觉标定达不到，必须让接触力进回路。
- [ ] 接触的互补条件让动力学分片且刚性；摩擦锥约束下，某些抓法根本没有可行夹持力。
- [ ] 阻抗控制把等效刚度从 $5\times 10^{4}$ 降到 $5\times 10^{2}\ \mathrm{N/m}$ 量级，换来"撞着找"的能力，代价是自由空间跟踪精度。
- [ ] 滑移预测必须同时报检出率与误报率；灵巧手的高维动作靠协同降维，代价是丢掉子空间外的手型。
- [ ] 从三维到抓取要过位姿与力域两道检查；检测 mAP 不能代替抓稳。
