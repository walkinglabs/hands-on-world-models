# 5.1　机器人数据与行为克隆

图片分类数据是一张图配一个类别。机器人示范还要说明在第几步看到了什么、接到什么指令、关节处于什么状态，以及随后执行了什么动作。

## 一条机器人 episode

```text
images:       [T+1,C,H,W]
proprio:      [T+1,P]
instruction:  text 或 token
actions:      [T,A]
success/done: [T]
timestamps:   [T+1] 与 [T]
```

`proprio` 是机器人自身状态，例如关节角、末端位置和夹爪开合。动作可能是关节增量、末端速度或目标位姿，数据卡必须写清坐标系和单位。

## 先只用 state 做行为克隆

行为克隆（BC）把专家示范当作监督学习：

```text
当前状态 → 预测专家动作
```

从 state-only BC 开始，可以先检查动作归一化、时间对齐和控制接口。随后再加入图片，观察视觉是否真的提高成功率。

## 为什么动作 MSE 不等于成功

同一个物体可以从左侧或右侧绕开，两种动作都能成功。MSE 会把其中一种当成另一种的错误，甚至鼓励输出两者平均的碰撞路线。

因此动作误差只能作为辅助。主指标是任务成功率、碰撞率和执行稳定性。

## 分布偏移

训练数据来自专家附近的状态。模型一旦犯小错，就会进入专家很少访问的区域，后续错误继续积累。

短 horizon、重新规划、加入失败轨迹或 DAgger 类数据收集可以缓解这一问题。本课程先保存失败 episode，判断问题来自视觉、动作多模态还是分布偏移。

## 小结

- [ ] 机器人数据同时包含图像、自身状态、指令、动作和时间。
- [ ] state-only BC 是检查控制接口的最小基线。
- [ ] 动作 MSE 不能替代真实任务成功率。
