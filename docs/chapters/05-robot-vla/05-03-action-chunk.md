# 5.3　Action Chunk 与多种可行动作

逐步预测单个动作时，传感器噪声可能让相邻输出不断改变方向，机械臂出现抖动。一次预测一小段动作，可以让短期运动更连贯。

## Action Chunk

```text
当前上下文 → [a_t, a_{t+1}, ..., a_{t+K-1}]
```

执行时可以只走 chunk 的前几步，再根据新观察重新预测。`K` 太短，动作不连贯；太长，模型来不及根据现实修正。

## 多种动作都可能正确

机械臂可以从杯子左侧或右侧接近。单一高斯或 MSE 回归容易输出中间路线。

Diffusion action head 从噪声生成完整 action chunk，可以表示多个模式。Flow matching 也可以学习从简单分布到动作分布的连续变换。

## 候选动作怎样评价

同一上下文采样多组 action chunk，先检查合法范围、速度和碰撞，再由模型或控制器选择。

采样多样性本身不是目标。若所有候选都无法完成任务，分布再丰富也没有帮助。

## 延迟与频率

动作头必须在控制周期内输出。报告总延迟时要包括视觉编码、语言融合、采样步数和后处理。

Diffusion 步数越多，动作分布可能更精细，延迟也增加。课程使用小步数对照，并记录成功率—延迟曲线。

## 小结

- [ ] Action Chunk 一次输出短动作序列，减少逐步抖动。
- [ ] Diffusion 或 flow action head 可以表示多个可行动作模式。
- [ ] 动作多样性还要接受成功、碰撞和延迟检查。
