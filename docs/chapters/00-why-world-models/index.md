# 第 0 章　机器看见的为什么不等于世界

这一章暂时不用神经网络。我们先问一张照片遗漏了什么，再用连续观察形成内部状态，学习世界怎样变化。只有任务需要行动时，动作、规划器和策略才继续加入。

五篇小章按顺序阅读。每篇只增加一个困难，前一篇的办法会成为后一篇的起点。

## 本章文章

1. [一张照片为什么不够](./00-01-current-observation.md)：区分观察与状态，说明历史为何出现。
2. [没有执行的动作，结果从哪里来](./00-02-action-conditioned-future.md)：从普通续写走到动作条件预测。
3. [从一步预测到多步规划](./00-03-rollout-planning-policy.md)：在九格世界中区分世界模型、规划器和策略。
4. [拿走转移表以后怎么办](./00-04-learned-dynamics.md)：从连续经历学习概率转移，并检查模型错误。
5. [回到经典《World Models》](./00-05-classic-world-models.md)：把我们得到的部件与 V–M–C、PlaNet 和 Dreamer 对照。

## 本章实验

[F0：重新发明一台世界模型](/labs/f0) 把五篇文章放进同一份 Notebook。它使用 CPU，在九格世界中比较一步动作、不同规划深度和模型漏洞。

## 学完以后

我们应当能画出下面三个接口，并说明一个简单任务为什么可能只需要其中一两个：

```text
世界模型：当前状态 + 候选动作 → 可能的未来
规划器：当前状态 + 目标 + 世界模型 → 选择动作
策略：当前信息 → 直接输出动作
```
