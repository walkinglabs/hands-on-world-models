# 0.2　动作条件预测

我们已经保留了最近几帧，并估计出汽车正在接近弯道。现在需要在三个动作中选择一个：保持速度 $a^{(1)}$、轻踩刹车 $a^{(2)}$ 或急刹车 $a^{(3)}$。

真实世界只会执行其中一个动作。其他两个动作会发生什么，摄像机没有拍到。所谓**动作条件预测**（action-conditioned prediction），就是回答"如果我在状态 $s_t$ 下执行动作 $a_t$，未来会怎样"。

## 普通续写回答的是"通常后来怎样"

给一段道路视频，视频模型可以继续生成一种常见未来。例如，大多数训练片段中的司机都轻踩刹车，模型就可能继续生成减速转弯。

形式化地说，普通续写在学的是边缘分布：

$$P(o_{t+1}\mid o_{\le t}),$$

也就是"不管做什么动作，过去这种画面之后通常出现什么"。

但规划需要三个分别受动作约束的未来：

```text
当前状态 + 保持速度 a¹ → 未来 A
当前状态 + 轻踩刹车 a² → 未来 B
当前状态 + 急刹车   a³ → 未来 C
```

若模型忽略动作，只生成训练数据中最常见的后来，我们无法比较三个选择。

## 动作要进入转移

设当前内部状态为 $s_t$，候选动作为 $a_t$。最小预测接口写成：

$$s_{t+1} = \mathrm{next\_state}(s_t,\, a_t).$$

动作不是结果出来以后附加的标签，而是导致变化的条件。训练数据也必须保存"在什么状态下做了什么，随后发生什么"，即一组三元组：

$$(s_t,\ a_t,\ s_{t+1}).$$

若动作与帧错开一步，模型仍可能拟合运动趋势，却无法回答更换动作后的未来。第 1 章会具体检查时间对齐。

## 不同动作并不保证唯一结果

湿滑路面上急刹车，汽车可能稳定减速，也可能打滑。预测接口因此不应只输出一个 $s_{t+1}$，而应输出一个分布：

$$P(s_{t+1}\mid s_t,\, a_t).$$

这里的 $P$ 表示多种结果及其可能性。一个只输出平均位置的模型，会把"向左打滑"和"向右打滑"两种结局平均成一条现实中不会出现的直线：

$$\frac{s_{\text{左}}+s_{\text{右}}}{2}\ \longrightarrow\ \text{现实中不存在的状态}.$$

需要保留多峰分布的任务，就要让模型直接输出分布本身。这一思想在第 0.5 节会以 MDN-RNN 的形式再次出现。

## 什么算动作条件模型

判断一个模型是否"动作条件"，最严格的办法是做一次反事实检查（counterfactual check）：固定同一个起点 $s_t$、历史、路面和随机源，只替换动作：

$$a_t = a^{(1)} \Rightarrow \hat s^{(1)}_{t+1},\quad
a_t = a^{(2)} \Rightarrow \hat s^{(2)}_{t+1},\quad
a_t = a^{(3)} \Rightarrow \hat s^{(3)}_{t+1}.$$

如果 $\hat s^{(1)}_{t+1}, \hat s^{(2)}_{t+1}, \hat s^{(3)}_{t+1}$ 三者各不相同且方向合理（急刹车比保持速度减速更多），模型才显示出动作敏感性。

从数据集中任取两段不同视频进行比较不够严格，因为物体、速度和路面也可能同时变化。

## 小结

- [ ] 普通视频续写学习 $P(o_{t+1}\mid o_{\le t})$，动作条件预测回答 $P(s_{t+1}\mid s_t,a_t)$。
- [ ] 动作必须进入状态转移，也必须在数据中以三元组 $(s_t,a_t,s_{t+1})$ 与相邻观察正确对齐。
- [ ] 同一动作可能有多种结果，模型需要在适当任务中保留不确定性。
