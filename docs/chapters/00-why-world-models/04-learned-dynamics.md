# 0.4　从经历学习动态

网格世界原来带有一个 `next_state` 函数。程序员已经写好：在每个格子执行每个动作以后，机器人会到哪里。所谓**学到的动态**（learned dynamics），就是用数据替代这张人写的表。

现实环境没有附送这张表。机器只能保存自己真正经历过的变化，再从中估计规律。

## 一条经历怎样保存

一次变化至少包含五项，通常打包成一个**转移元组**（transition）：

$$(o_t,\ a_t,\ r_t,\ o_{t+1},\ d_t),$$

其中 $o_t$ 是观察、$a_t$ 是动作、$r_t$ 是奖励、$o_{t+1}$ 是下一步观察、$d_t$ 标记是否结束（done）。连续变化组成一个 **episode**（一段完整经历）。多个 episode 放入训练集或 Replay Buffer，供模型重复采样。

## 从计数开始

假设机器人位于位置 $2$，执行 `right` 共 $N=10$ 次，其中 $8$ 次来到位置 $3$，$2$ 次因为打滑留在位置 $2$。最朴素的估计就是数频次：

$$P(s_{t+1}=3\mid s_t=2,\, a_t=\text{right}) = \frac{8}{10}=0.8,$$

$$P(s_{t+1}=2\mid s_t=2,\, a_t=\text{right}) = \frac{2}{10}=0.2.$$

更一般地，若某个 $(s,a)$ 在数据里出现了 $N(s,a)$ 次，其中转移到 $s'$ 的次数为 $N(s,a,s')$，则极大似然估计给出：

$$\widehat{P}(s'\mid s,a) = \frac{N(s,a,s')}{N(s,a)}.$$

0.6 实验里只用了 $3$ 条样本，其中 $2$ 条走到 $(2,1)$、$1$ 条打滑回到 $(2,0)$，于是学到的分布是 $\widehat{P}((2,1)\mid (2,0),\text{right})=\tfrac{2}{3}$、$\widehat{P}((2,0)\mid (2,0),\text{right})=\tfrac{1}{3}$。

这张计数表已经是一台从数据学习的世界模型。它没有神经网络，却同时满足三个条件：结果依赖当前状态、结果依赖动作、结果可以有多种可能。

## 未见过的动作怎么办

如果训练数据从未包含"位置 $4$ + right"，计数表会返回空——$\widehat{P}(\cdot\mid 4,\text{right})$ 无定义。这个答案无法直接用于规划，却诚实说明没有证据。

神经网络通常对任何输入都会输出结果，哪怕 $(s,a)$ 在训练分布之外（out-of-distribution，OOD）。规划器可能专门找到模型没见过、却错误预测为高回报的动作。模型漏洞由此出现：

$$\text{OOD 输入} \;\xrightarrow{\text{神经网络}}\; \text{看似合理的高回报预测} \;\xrightarrow{\text{规划器}}\; \text{不存在的"捷径"}.$$

最简单的处理包括：限制规划范围、缩短 horizon、惩罚不确定区域、收集新数据，以及每执行一步就回到现实修正。

## 一步误差为何不够

模型每一步有 $0.95$ 的概率预测正确，并不表示连续 $20$ 步仍可靠。在一个简化的独立误差假设下，$20$ 步全部正确的概率是：

$$0.95^{20} \approx 0.36.$$

换句话说，即便单步相当准，开环展开 $20$ 步也只有约三分之一的机会全程不出错。真实模型的错误并不独立（常常越走越偏），但这个计算说明小误差会在 rollout 中积累。评价至少要同时报告 one-step 与 open-loop multi-step 结果。

## 失败先分四类

规划失败时，先按顺序检查：

1. **数据**是否错位、泄漏或跨 episode；
2. **任务**是否缺少速度、摩擦等必要信息；
3. **模型**是否无法表示规律；
4. **规划器**是否搜索太远或离开训练分布。

更大的网络只能处理第三类中的一部分。

## 小结

- [ ] **learned dynamics** 从连续经历估计动作与结果之间的规律 $\widehat{P}(s'\mid s,a)$。
- [ ] 计数表已经可以表达随机转移和未知区域。
- [ ] 一步预测好不等于多步规划可靠；$0.95^{20}\approx 0.36$ 是一个直观提醒。
- [ ] 模型失败可能来自数据、信息、模型或规划使用方式。
