# 《动手学世界模型》课程总纲

本课程先建立共同基础，再选择一条设计路线，最后完成系统评测与最小研究循环。章节标题只保留主概念；要求写代码、运行实验或完成项目的 Page 统一使用“动手：”前缀。

## 附录

### 附录 A　数学、代码与术语速查

概率、梯度、KL、熵、PyTorch–JAX/Flax 接口和中英文术语。

### 附录 B　数据、算力与交付标准

数据切分、泄漏检查、算力配置、实验复现与交付规范。

## 课程规模

最终规模为 **9 章、60 个正文 Page、3 个附录**。学生的实际学习路径约为：共同基础 21 页、一条设计路线 5–11 页、研究设计 3 页。
