# 《动手学世界模型》课程总纲

本课程融合了严谨的学术形式化推导与从零开始的代码实践。先建立世界模型的数学与表征基础，再深入五大前沿范式路线，最后完成系统评测与最小研究循环。章节标题严格采用学术界标准术语；要求写代码、运行实验或完成项目的 Page 统一使用“...的从零开始实现”或“...的简洁实现”后缀。
