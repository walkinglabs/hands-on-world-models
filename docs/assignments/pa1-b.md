# PA1-B · 做出一个听从按键的视频小世界

目标是在 PixelWorld 上接起 tokenizer、动作条件动态和多步解码，再迁移到 CarRacing 小数据。

## 必做

1. 按 episode 切分数据，并画出帧—动作—下一帧样例；
2. 训练 VQ-VAE，报告重建误差、码本使用率与小物体重建；
3. 训练动作条件 token 模型；
4. 固定起点逐一替换动作，测量真实物体位移是否正确；
5. 连续生成 1、5、15、30、100 步，画动作一致性与漂移曲线；
6. 与复制上一帧和去掉动作的模型比较；
7. 记录每帧延迟、峰值显存、总时间与 checkpoint 哈希。

## 选做

在同一数据 split、更新数与计算预算下，训练 tiny conditional diffusion，比较画面细节、动作一致性与延迟。

## 24GB 目标

`64×64 RGB`、每帧最多 64 个 token、小型 Transformer、短上下文、单卡峰值 reserved 目标不超过 22GB。这是设计目标，当前未实测。

## 不接受的结论

- 只交一张最好看的图；
- logits 会随动作改变，就声称画面已可控；
- 使用无动作视频，却声称学到了真实控制；
- 只报 one-step loss，不运行自回归多步。
