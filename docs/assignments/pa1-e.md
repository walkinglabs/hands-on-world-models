# PA1-E · 动手：空间世界二选一

先完成 E1，再选择 E2a 或 E2b。不要把两个项目各做一半。

## E2a：3D/4D

1. 在 Lego 小场景训练 tiny NeRF 或 3DGS；
2. 报告 novel-view 质量、深度/几何误差与渲染速度；
3. 在项目内多视角 moving-shapes 加入时间；
4. 若声称动作条件，固定历史替换动作并报告未来差异；
5. 明确静态、动态与可控三种结论边界。

## E2b：自动驾驶空间

1. 在标定 toy 与 nuScenes-mini 实现 tiny LSS/BEV；
2. 预测当前与未来 Occupancy；
3. 与复制最后一帧、匀速外推比较；
4. 报告 IoU horizon 曲线、动态物体召回和动作敏感性；
5. 没有 ego plan 只能称 open-loop；没有模拟器不能报告闭环碰撞率。

## 共同 24GB 目标

降低场景、相机数、分辨率、射线/高斯或 BEV 网格规模，单卡 reserved 目标不超过 22GB。每个分支都需要独立实测，当前记录为 0。
