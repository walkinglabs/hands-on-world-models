# 前言

这本书默认我们会读简单的 Python 代码，但不要求预先学完强化学习、视觉、机器人或三维几何。

遇到向量、概率、梯度或 PyTorch 写法时，正文会先给一个小例子。以后还会把这些内容整理成文末小抄，而不是单独设置一大章。

## 学习顺序

第一次学习时，按下面的顺序即可：

1. 阅读第 0 章，并运行 F0；
2. 完成第 1–2 章和 PA0；
3. 从第 3–7 章选择一条路线；
4. 完成该路线的两份教学 Notebook 和 PA1；
5. 回到第 8 章，用 Z0 评价模型并完成 PA2。

五条路线对应第 3–7 章，按编号依次展示：决策与规划（3，路线 A）、互动视频（4，路线 B）、JEPA（5，路线 C）、VLA 与机器人（6，路线 D）、空间世界（7，路线 E）。这个顺序不是先修链：完成第 0–2 章以后，可以直接进入其中任何一章。

## 每次先运行 smoke

每份 Notebook 都会提供一个很小的 smoke 配置。它的目标不是得到最好成绩，而是确认：

- 数据可以读取；
- shape 和时间对齐正确；
- loss 能够下降；
- 图、表和 checkpoint 可以生成；
- 整条路径没有明显错误。

完成 smoke 后，再切换到 24GB 目标配置。目标配置只有在提交完整日志和峰值显存以后，才会标记为真机已验证。

## 代码不是答案册

Notebook 中会留出预测、填空和小实验。建议先写下自己的判断，再运行下一格。

如果结果与判断不同，先保留这个差异。课程最重要的训练不是一次把答案猜对，而是能从可见失败中说清：原来的办法缺了什么。

## 三种符号

课程页面会使用三种状态：

- **必做**：当前学习路径需要完成；
- **选做**：用于比较另一种设计，不影响主线；
- **论文拔高**：理解核心问题以后继续阅读，不要求本地复现规模结果。
