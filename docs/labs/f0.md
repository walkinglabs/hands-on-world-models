# F0 · 在九格世界里重新发明世界模型

F0 与第 0 章配套。它不需要 GPU，也不依赖 PyTorch。我们只使用 Python 标准库、整数和字典，把世界模型的最小闭环写出来。

## 本次会得到什么

运行结束后，我们会得到：

- 一张九格地图和规划路径；
- 深度为 1、3、6 时的规划结果；
- 同一起点只替换动作的反事实比较；
- 从轨迹中学习得到的概率转移表；
- 模型预测与真实执行不一致时的修正记录。

## 怎样运行

仓库中的 Notebook 位于：

```text
notebooks/00_reinvent/F0-invent-a-world-model.ipynb
```

安装 Jupyter 后，在仓库根目录运行：

```bash
jupyter lab
```

九格世界的可复用实现位于 `src/hwm/gridworld.py`。即使暂时不运行 Notebook，也可以先执行单元测试：

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

## Notebook 的六次停顿

F0 不会一开始就显示完整答案。我们会在六处先停下来：

1. 只看当前位置时，应该向哪里走；
2. 加入一步转移后，原来的选择为什么改变；
3. 一步安全时，三步以后是否仍然安全；
4. 两条路线都到终点时，怎样比较；
5. 转移表被拿走后，规律从哪里来；
6. 模型想错以后，为什么只执行第一步并重新观察。

每一次停顿都只增加一个部件。完成以后，再回到[第 0 章](/chapters/00-why-world-models/)核对我们得到了哪些概念。
