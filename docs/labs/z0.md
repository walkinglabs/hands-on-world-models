## 测试一：多步 horizon 曲线

**问题**：模型的一步预测很准，但多步预测呢？

**方法**：从同一帧出发，让模型预测 1、5、10、20、50 步后的状态，对比真实轨迹。计算每一步的 MSE 或 token accuracy。

```python
# 多步 horizon 测试的核心逻辑
from hwm.evaluation import horizon_errors

errors = horizon_errors(
    predict_fn=model.rollout,      # 模型的 rollout 函数
    ground_truth=episodes[0],       # 真实轨迹
    start_step=0,                   # 起点
    horizons=[1, 5, 10, 20, 50]    # 测试的步数
)
# errors 是一个列表，每个元素是对应 horizon 的 MSE
```

  <div style="font-size:0.9em; color:var(--vp-c-text-2); margin-top:8px;">Z0 测试一：多步 horizon 曲线。horizon 越长，误差越大——这就是复合误差。</div>
</div>

**运行这一步，你会看到什么？** Notebook 会打印 horizon 曲线。你会发现，horizon 越长，误差越大——**这就是复合误差**。如果曲线在 10 步后急剧上升，说明模型的多步一致性很差。

**一个值得做的实验**：比较不同温度 τ 下的 horizon 曲线。τ 越小，梦境越确定，短期误差小但长期可能过拟合；τ 越大，梦境越接近真实噪声，短期误差大但长期更稳。

## 测试二：固定起点的反事实动作

**问题**：模型真的理解动作因果关系吗？还是只是记住了「通常会发生什么」？

**方法**：固定同一起点，替换动作序列，观察预测轨迹是否随之改变。如果换动作后预测不变，模型没有学到动作条件动态。

```python
# 反事实测试的核心逻辑
from hwm.evaluation import counterfactual_sensitivity

sensitivity = counterfactual_sensitivity(
    predict_fn=model.rollout,
    start_state=episodes[0][0],       # 固定起点
    base_actions=[0, 1, 2, 3],        # 基准动作序列
    alt_actions=[3, 2, 1, 0]          # 替代动作序列
)
# sensitivity > 0 表示换动作后轨迹确实改变了
```

## 测试三：单变量 OOD

**问题**：模型在训练分布内表现良好，但在分布外呢？

**方法**：改变一个变量（如方块速度、物体颜色、光照强度），观察预测质量的变化。

**运行这一步，你会看到什么？** Notebook 会打印 OOD 变量与预测误差的关系。你会发现，某些变量变化时误差急剧上升——**这就是模型的泛化边界**。

## 测试四：不确定性校准

**问题**：模型说「我有 90% 的把握」时，真的 90% 正确吗？

**方法**：收集模型的预测置信度（如 softmax 概率、高斯方差），对比真实准确率。如果置信度 90% 的预测只有 60% 正确，说明模型过度自信。

## 测试五：Planner 漏洞

**问题**：Planner 会不会利用模型的漏洞，找到一条只在模型里畅通的路线？

**方法**：让 Planner 在模型里规划一条最优轨迹，再在真实环境里执行。如果真实回报远低于模型预测，说明 Planner 利用了模型漏洞——**这就是模型利用（model exploitation）**。

**运行这一步，你会看到什么？** Notebook 会打印模型预测回报与真实回报的差距。如果差距很大，说明模型有漏洞。

## 已知简化与坑

- **Z0 的 toy 过于简单**。解析 toy 的失败模式可能不反映真实模型的失败。
- **OOD 测试只改变一个变量**。真实世界的 OOD 是多变量的，单变量测试只是起点。
- **校准曲线需要大量样本**。教学版用少量样本，校准估计可能不准。
- **Planner 漏洞测试依赖 Planner 质量**。如果 Planner 本身很弱，可能找不到模型漏洞。

## 扩展练习

完成 Z0 后，按从便宜到昂贵的顺序推荐：

1. **迁移到自己的 PA1 模型**：把 Z0 的六项测试应用到你的 PA1 模型，观察失败模式。
2. **多变量 OOD**：同时改变多个变量（如速度 + 颜色 + 光照），观察误差的交互效应。
3. **时间 OOD**：在训练数据的时间范围之外测试，观察模型的长期泛化能力。
4. **对抗测试**：故意构造让模型出错的输入，观察模型的鲁棒性。

## 本节小结

- **多步 horizon 曲线暴露复合误差**：horizon 越长，误差越大。
- **反事实动作测试因果理解**：换动作后预测不变，说明模型没学到动作条件动态。
- **单变量 OOD 测试泛化边界**：某些变量变化时误差急剧上升。
- **不确定性校准测试置信度可靠性**：过度自信的模型不可信。
- **Planner 漏洞测试模型利用**：模型预测回报远高于真实回报，说明有漏洞。
- **run manifest 是复现的基础**：没有 manifest，实验无法复现。

从 3.6 的 World Models 到这一节的审问测试，世界模型的「评价」在不断深化：loss 下降 → 多步一致 → 反事实推理 → OOD 泛化 → 不确定性校准 → Planner 漏洞。每一种测试都暴露一种失败模式，而你的任务是在具体场景里选择最相关的测试。
