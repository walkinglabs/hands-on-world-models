# 动手学世界模型

> 从看见、记住和预测，到在想象中规划与行动。

这是一本面向初学者的中文开源教材。我们不会从一张论文结构图开始，也不会要求读者先背完 CNN、ViT、RSSM、MPC 和 JEPA。我们从一个更朴素的问题开始：**机器为什么需要在真正行动以前，先想一想会发生什么？**

第一阶段只维护中文内容，不建立尚未完成的英文占位。等中文主线和实验真正稳定以后，再讨论翻译。

本书的目标不只是带你复现 Dreamer。我们希望你学会从一次具体失败中判断机器缺少什么能力，再自己选择表示、记忆、预测和规划方法。学到最后，你应该有机会提出“下一台世界模型应该是什么”，而不只是重复已有模型的名字。

## 为什么还需要世界模型

CNN 能从图片里认出弯道，RNN 能记住汽车刚才怎样运动，Transformer 能预测一段序列，视觉语言模型也能说出“高速过弯应该减速”。这些能力都很重要，但它们单独并不保证机器能回答：

```text
如果现在轻踩刹车，两秒后会怎样？
如果急刹，会不会失控？
如果继续转向，车身会偏到哪里？
```

一个动作还没有执行，它的结果就不在当前画面里。如果我们还想比较几个动作，只有三种办法：

1. 把每个动作都在现实中试一遍；
2. 使用工程师写好的方程或模拟器；
3. 从过去的经历中，学出一套“动作怎样改变世界”的规律。

第一种方法在机器人和驾驶中可能太贵或太危险。第二种方法本身就是一个人工写成的世界模型。本书研究的，主要是第三种学习型世界模型。

世界模型不是一种和 CNN、RNN、Transformer 并列的新网络。它是一项系统职责：

```text
整理过去，估计现在
→ 放入一个尚未执行的动作
→ 推测接下来可能发生什么
→ 比较几种未来
→ 执行一步
→ 用真实结果修正原来的判断
```

CNN、ViT、RNN、Transformer、VAE、Diffusion 都可以成为这套系统里的零件。我们学习这些零件，不是为了收集缩写，而是为了知道它们各自补上了什么缺口。

## 这门课怎样教

我们借鉴《动手学深度学习》的组织方式，也参考 Stanford CS336、南京大学计算机系统基础课程及 [Hands-On Modern RL](https://github.com/walkinglabs/hands-on-modern-rl) 的工程训练思路。每个主题都尽量沿着同一条路展开：

```text
一个具体问题
→ 先试最简单的方法
→ 改变一个条件，让缺点出现
→ 说清缺少的能力
→ 从零实现一个最小部件
→ 用小数据训练
→ 接进完整系统
→ 检查它在哪些地方仍然失败
```

课程有五个约定：

- **先看现象，再给术语。** 先让模型失败，再解释为什么需要 RSSM、VQ-VAE 或 CEM。
- **一份 Notebook 做成一件事。** 不把每个名词拆成一个文件，也不把十篇论文塞进一次实验。
- **共同基础之后再选路线。** 第 0–2 章人人学习；第 3–7 章选择一条完成即可。
- **论文是拔高，不是路障。** 小模型讲清核心思想，大规模训练细节交给论文阅读。
- **结果必须接受行动检验。** 一步损失低、视频好看或动作 MSE 小，都不能单独证明模型真的有用。

## 共同基础学什么

前两章不是一张缩写表，而是把零件按它们在系统里的位置放好。

| 遇到的问题                 | 需要的能力           | 会认识的工具                                       |
| -------------------------- | -------------------- | -------------------------------------------------- |
| 图片太大，无法直接建转移表 | 把观察变成较短表示   | CNN、ViT、位置编码                                 |
| 一张图看不出速度和遮挡     | 用历史更新状态       | RNN、GRU、因果 Transformer、RSSM                   |
| 未来不只有一个答案         | 表示不确定性         | 概率分布、随机 latent、Diffusion                   |
| 像素预测太贵或太琐碎       | 压缩观察或改预测目标 | AE、VAE、VQ-VAE、JEPA                              |
| 二维画面没有明确空间结构   | 表示相机和三维空间   | 相机内外参、点云、BEV、Occupancy、NeRF、3DGS、Mesh |
| 能预测却不会挑动作         | 评价和选择未来       | reward、value、TD、Actor-Critic、MPC、CEM、MCTS    |
| 训练容易坍缩或发散         | 让系统稳定工作       | Replay Buffer、EMA、Free Bits、Symlog、梯度裁剪    |

这一步只要求知道每种工具的输入、输出和用途。选定路线后，我们才在真实上下文里再次实现需要的组件。例如，ViT 会在共同基础里认识一次，在 JEPA 或 VLA 路线里再深入；RSSM 会在共同基础里看懂接口，在 Dreamer 路线里完整实现。

## 五条路线怎样选

五条路线不是按公司或论文名字硬分的。它们分别选择了不同的“世界表示”和“使用方式”。最简单的选择方法，是先问自己希望模型输出什么。

| 路线           | 机器主要预测什么                 | 预测拿来做什么                     | 课程作品                                    |
| -------------- | -------------------------------- | ---------------------------------- | ------------------------------------------- |
| A 决策与规划   | 下一隐藏状态、奖励和任务是否继续 | 在模型里试动作并提高真实环境得分   | Dreamer-lite；Mini-MuZero 选修              |
| B 可交互视频   | 下一帧、视觉 token 或连续 latent | 生成听从按键、能连续运行的画面     | IRIS-like 键盘小世界                        |
| C JEPA         | 被遮部分或未来的抽象特征         | 学到保留物体与运动的表示           | Tiny Video-JEPA；Action-JEPA 选修           |
| D VLA 与机器人 | 机器人动作；可选预测动作后果     | 执行语言指令并在行动前检查候选动作 | Tiny VLA + world-model checker              |
| E 空间世界     | 三维结构、占用或未来 BEV         | 保持跨视角一致，支持漫游或驾驶预测 | Tiny 3D/4D world 或驾驶 occupancy predictor |

几条边界会贯穿全书：

- VLA 直接输出动作，但不一定预测动作后果；它和世界模型可以组合，却不是同一个东西。
- 无动作视频可以学习视觉规律，却不能单独证明模型理解“换一个动作会怎样”。
- NeRF 和 3DGS 能重建空间，但静态重建本身还不是动态世界模型。
- 离线预测未来 BEV，不等于已经完成自动驾驶闭环规划。
- 生成画面逼真，不等于物理正确，更不等于可以安全行动。

## Notebook 与大作业

我们控制文件数量，让学生把时间花在理解和调试上，而不是在目录里迷路。

| 阶段     | 内容                                         | 数量 |
| -------- | -------------------------------------------- | ---: |
| 重新发明 | F0：在九格世界里写出转移、rollout 和规划     |    1 |
| 共同基础 | F1–F3：认识组件、整理轨迹、学出表格小世界    |    3 |
| PA0      | 不照论文结构图，独立完成第一台可学习世界模型 |    1 |
| 选择路线 | 每条路线用两份 Notebook 完成“零件 → 小整机”  |    2 |
| PA1      | 在所选路线训练一个 24GB 以内的小模型         |    1 |
| 统一评价 | Z0：多步、反事实、OOD 和下游效用检查         |    1 |
| PA2      | 从失败出发，提出并验证“下一台模型”的最小想法 |    1 |

一名学生完成一条路线，预计实际学习约 10 份 Notebook，而不是把所有路线全部训练一遍。

三次大作业由小到大：

- **PA0：重新发明。** 在小世界中明确状态、动作、转移、奖励和规划器。
- **PA1：让一台小模型真正工作。** 选择一条路线，接好数据、模型、训练和评价闭环。
- **PA2：从失败设计下一台模型。** 找到一个可复现的失败，提出最小改动，做公平对照，并诚实报告负结果。

## 数据与 24GB 显存约定

每条路线都按同一座小台阶前进：

```text
T0 手写样本和 shape 检查
→ T1 项目内可生成的小数据
→ T1 把零件接成小模型
→ T2 真实小数据迁移
→ T3 下游任务或闭环评价
```

所有必做模型都以单张 24GB 显卡为上限设计，并计划提供 smoke 与 24GB 两档配方。这里的“设计上限”不等于“已经实测”。一次实验只有在干净环境中完整运行，并记录显卡、峰值显存、时间、随机种子、曲线和 checkpoint 哈希以后，才会标记为“24GB 已验证”。

## 建议基础

默认读者会一点 Python，能够读懂列表、函数、类和简单的 PyTorch 代码。向量、概率、梯度和常用 Python 写法不单独占一章，而会放在“小抄”中随用随查。

你不需要预先学完强化学习、计算机视觉、三维几何或机器人学。进入一条路线时，本书会补齐那条路线真正需要的二次基础。
